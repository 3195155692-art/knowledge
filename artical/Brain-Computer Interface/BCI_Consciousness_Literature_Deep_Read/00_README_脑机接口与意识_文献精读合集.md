> **Brain-Computer Interface (BCI) × Consciousness**

1. cognitive motor dissociation（CMD）； 认知-运动分离
2. covert consciousness； 隐蔽意识

## 三、整个领域的主线

```text
传统 BCI
运动意图 → 设备控制
        ↓
Speech BCI
语言意图 → 文字/声音
        ↓
Consciousness BCI
脑信号 → covert cognition
        ↓
Neural decoding
脑信号 → semantic representation
        ↓
Conscious-content decoding
脑信号 → 具体体验内容
        ↓
Communication
意识内容 → 语言/声音
        ↓
Closed-loop
检测 → 干预 → 再检测
```

## 四、最值得汇报的核心观点

### 观点 1

> **行为无反应不等于认知不存在。**

NEJM 2024 的多中心研究在 241 名无可观察指令反应患者中检测到 60 名（25%）存在 CMD。

### 观点 2

> **意识检测正在从 state detection 向 content decoding 发展。**

Fischer 2025 明确提出 neural decoding 可作为 covert consciousness assessment 的新范式。

### 观点 3

> **semantic decoding 是连接 BCI 与意识研究的关键桥梁。**

Tang 2023 已经展示了从非侵入式 fMRI 中重建连续语言语义的可行性。

### 观点 4

> **Speech BCI 已经从离线文字解码进入实时自然语音输出。**

Littlejohn 2025 和 Wairagkar 2025 分别展示了 streaming speech 和 instantaneous voice synthesis。

### 观点 5

> **下一阶段很可能是 multimodal + personalized + interactive + closed-loop。**

2026 年的 EEG/BCI 与 multimodal AI 工作正在向这一方向推进。

## 五、一个值得深入研究的问题

> **Can we decode conscious content rather than merely detect consciousness?**

中文：

> **能否不只是判断“患者有没有意识”，而是直接解码“患者正在意识到什么”？**

这是目前 BCI 与 consciousness research 最值得交叉的科学问题之一。

## 九、笔记规范（frontmatter / 命名 / 结构）

本合集遵循统一的 Obsidian 规范，便于用标签与 Dataview 检索。

### 命名

```text
<两位序号>_<论文完整标题>.md
```

保留论文原标题的大小写与副标题；Obsidian 不允许的字符以 ` - ` 替换（例如标题中的冒号）。PDF 文件名与笔记同名，故 `PDFs/<笔记名>.pdf` 始终可直接解析。

### frontmatter

```yaml
---
tags:
  - <领域标签，中文>          # 脑机接口 / 意识研究
  - <期刊标签，英文全称连字符> # New-England-Journal-of-Medicine
  - <概念标签，中文>          # 认知运动分离 / 隐蔽意识 / 语义解码
  - <缩写>                    # CMD / PDoC / AI
年份: <四位数字>
摘要: <该论文 abstract 的完整中文翻译>
---
```

标签顺序固定为 **领域 → 期刊 → 概念 → 缩写**。期刊标签一律使用英文全称加连字符，不用 ISO 缩写；概念标签沿用中文学界通行译名；缩写仅在论文将其作为术语使用时才单独设标签。

### 摘要：是翻译，不是概述

`摘要` 一栏必须是论文 abstract 的**逐句完整翻译**，不是内容概述：

- **一句对一句**——原文一句，译文一句；不合并、不拆分、不调换小节；原文用 `背景 / 方法 / 结果 / 结论` 分段，译文保留同样的分段。
- **数字全部落地**——abstract 里出现的每一个百分比、样本量、小数与 p 值都要出现在译文里。概述最容易在这里失真：`65%` 写成 `66%`、`25%` 写成 `26%`，论文的结论就变了。
- **以所引版本的 abstract 为准**——若本地 PDF 是作者稿、其 abstract 与正式发表版不同，翻译正式发表版，并在正文中标注版本差异。

原文 abstract 的纯文本存放在 `.tools/abstracts/`（点号开头，Obsidian 不会索引），可用 `check_abstract.py` 逐篇比对句数与数字覆盖：

```bash
python3 ~/.codex/skills/obsidian-reading/scripts/check_abstract.py \
  --collection "<本文件夹>" \
  --abstract-dir "<本文件夹>/../.tools/abstracts"
```

### 结构

每篇 `.md` 现在由两部分组成：

1. **中文精读报告**（原有部分）——文献信息、核心结论、方法、局限、与 BCI 的关系、汇报建议。
2. **附：关键句与核心论点（逐节原文提取）**（本次新增）——按论文原有小节顺序，逐节给出：
   - **原文关键句**：保留英文原句，便于回查、直接引用与核对；
   - **核心论点**：一句话中文提炼；
   - 部分小节附带 `> 核心论点` 总括，以及原文表格的还原（如 Fischer 2025 的 Table、Kordas 2026 的模态对比表）。

两部分的写作纪律：关键句必须**逐字引用**并标明来源文件与版本；数字原样保留并带上限定条件（置信区间、对照组数字、中心间差异范围）；保留削弱结论的反例与边界条件；区分「作者自述结论」与「本笔记推论」；发现论文内部数字不一致时并列标注而不擅自取舍。
