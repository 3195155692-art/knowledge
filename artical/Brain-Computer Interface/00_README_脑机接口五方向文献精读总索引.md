## 2. 每个方向的一句话定位

- **语言重建**：解码精度已不再是瓶颈，`无脚本居家使用 + 长期稳定性 + 免标定` 是新的竞争维度。
- **运动重建**：同一套系统正在同时回答"能否替代失去的功能"与"能否让神经系统修回一点"。
- **意识促醒**：证据以队列与试点为主，唯一 Level 1 证据来自药物；下一步是按层级做分层试验。
- **视觉重建**：视网膜假体先到达临床终点，皮层假体在"光幻视可控性"上取得关键突破。
- **听觉重建**：器件最成熟、闭环最不成熟；真正的问题是"谁获益多少"，而这正在被 AI 预测能力解决。

## 3. 跨方向的三条共同趋势

```text
① 评价体系从"精度"转向"可用性"
   语音：居家使用时长与天数（Card 2026）
   视觉：无装置相关严重不良事件 + 无人协助的真实使用（Petoe 2025）
   听觉：从"解码准确率"转向切换延迟、误切换率与聆听努力（Li & He 2026）

② 个体化从"经验调整"转向"模型驱动"
   运动：无监督潜在动力学对齐，免日常重标定（Karpowicz 2025）
   意识：电场建模决定电极位置与刺激方向（Warren 2025）
   视觉：个体化电场建模引导无创深部靶点（Hu 2026）
   听觉：术前 MRI + 深度迁移学习预测语言结局（Wang 2026）

③ 证据等级的自我意识增强
   多数论文在结论中显式限定证据强度（"single-subject feasibility"、
   "high-fidelity proof of principle"、"may facilitate"）
   本合集的笔记逐篇标注了这些限定，未将其升格为疗效结论
```

## 6. 资料组织与可核查性

每个方向目录的结构：

```text
<方向>/
  00_README_<方向>_文献精读合集.md   # 方向索引：主线、核心观点、阅读顺序、待办
  01_<论文完整标题>.md … 06_....md   # 精读笔记（两层结构）
  PDFs/                              # 出版社 PDF（文件名与笔记同名）
  FullText/                          # Europe PMC JATS 结构化全文（出版社 PDF 受限时）
  manifest.json                      # 每篇的标题/作者/期刊/DOI/版本/来源/哈希
```

核查方式：

1. 笔记第二层的每条英文引句都可在同名的 `PDFs/` 或 `FullText/` 文件中逐条检索验证；
2. `manifest.json` 记录了每篇的版本状态（正式版 / 作者接受稿 / 预印本）与来源 URL；
3. 各方向目录已通过 `obsidian-reading` 技能的 `check_notes.py` 与 `check_abstract.py` 校验：**0 错误**；剩余的警告均为"结构化全文（XML）不以 PDF 形式存在"，属预期。

## 7. 使用与更新

- 新增文献：放入对应方向的 `PDFs/`（或 `FullText/`），命名遵循 `<序号>_<论文完整标题>.<扩展名>`，并在 `manifest.json` 中追加条目。
- 更新合集索引：每个方向的 `00_README_...md` 的第 7 节文献清单、第 8 节获取状态表，以及本索引的第 1 节计数。
- 若获得出版社 PDF（替换 `FullText/` 的 XML），需同步更新笔记的版本标注与 manifest 的 `format` 字段。

## 8. 边界声明

本索引与下属所有笔记均为**文献整理与阅读报告**，不是临床指南，也不构成任何疗效主张。每篇笔记中的作者主张与本笔记推论均已分开表述；各项研究的证据等级（单例、单臂、回顾性、动物、仿真）在笔记内被显式标注。
