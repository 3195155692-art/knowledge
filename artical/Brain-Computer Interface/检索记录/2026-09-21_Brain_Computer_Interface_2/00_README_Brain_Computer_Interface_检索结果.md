## 三、下一步：取全文

1. 看 `manifest.json` 的 `oa` 字段：`true` 表示存在开放获取版本，可直接下载。
2. 中文文献、以及只有订阅才能获取的英文文献，改用 `nature-downloader` skill 走机构授权（会复用你已登录的浏览器）。
3. 下载好的 PDF 放进本目录的 `PDFs/`，并把文件名回填到 `manifest.json` 的 `file` 字段。
