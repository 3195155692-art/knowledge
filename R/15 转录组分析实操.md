# 转录组分析实操（Bulk RNA-seq）

> **一句话定位**：从公司交付的 FASTQ（或公共数据）到差异基因、富集结果与发表级图表的**完整可执行流程**。
> 原理与判读依据见 [[02 转录组学]]；环境与目录规范见 [[14 生信分析环境与工作流基础]]。

---

## 一、开始之前：准备好三样东西

| 要素 | 要求 | 常见错误 |
| --- | --- | --- |
| **原始数据** | 双端 FASTQ（`.fq.gz`），或 SRA 编号 | 文件名与样品表不一致；单双端混用 |
| **样品表** | 含 sample_id、fq1、fq2、group、batch、临床信息 | 分组与批次未同时记录（导致混杂无法发现） |
| **参考基因组 + 注释** | 物种、版本、来源统一（如 GRCh38 + GENCODE） | 比对与注释版本不配套 |

**先做三件小事，能省几小时**：

```bash
ls -1 *.fq.gz | wc -l                 # 确认文件数 = 样本数 × 2（双端）
zcat S1_R1.fq.gz | head -n 4          # 确认是标准 FASTQ 格式
seqkit stats -a *.fq.gz > logs/raw_reads_stats.txt   # 记录每样本 reads 数
```

## 二、流程总览

```
原始 FASTQ
  ↓ ① 质控（FastQC → MultiQC；fastp 修剪）
  ↓ ② 比对（STAR）或 伪比对定量（Salmon）
  ↓ ③ 计数（featureCounts）或 转录本定量（Salmon → tximport）
  ↓ ④ 表达矩阵与样本级质控（PCA / 相关性 / 离群样本）
  ↓ ⑤ 差异表达（DESeq2）
  ↓ ⑥ 富集分析（clusterProfiler / GSEA）
  ↓ ⑦ 可视化与结果交付
```

**两条技术路线怎么选**

| 路线 | 得到 | 适用 | 代价 |
| --- | --- | --- | --- |
| STAR + featureCounts | 基因水平计数 | 需要 BAM（可视化、融合、可变剪接） | 慢、吃内存 |
| Salmon + tximport | 基因/转录本定量 | 只做差异表达与分型 | 快、省资源，但拿不到 BAM |

## 三、命令骨架（逐步可复现）

### 3.0 准备参考基因组与索引

```bash
mkdir -p 02_ref && cd 02_ref
# 示例：GENCODE 人类参考（版本号按需替换，务必记录！）
wget https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_44/GRCh38.primary_assembly.genome.fa.gz
wget https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_44/gencode.v44.annotation.gtf.gz
gunzip *.gz

# STAR 索引（约需 32 GB 内存）
STAR --runThreadN 16 --runMode genomeGenerate \
     --genomeDir star_index \
     --genomeFastaFiles GRCh38.primary_assembly.genome.fa \
     --sjdbGTFfile gencode.v44.annotation.gtf \
     --sjdbOverhang 99

# Salmon 索引（用于伪比对路线）
grep -v "^#" gencode.v44.annotation.gtf > genes.gtf
salmon index -t transcripts.fa -i salmon_index -k 31 -p 16
```

> ⚠️ **参考版本一旦确定，全流程不得更换**。论文方法部分必须写明：参考基因组版本 + 注释版本 + 下载日期。

### 3.1 质控

```bash
fastqc -t 8 -o 03_clean/raw_qc 00_raw/*.fq.gz
multiqc 03_clean/raw_qc -o 03_clean/raw_qc

for s in $(cut -f1 01_meta/sample_sheet.tsv | tail -n +2); do
  fastp -i 00_raw/${s}_R1.fq.gz -I 00_raw/${s}_R2.fq.gz \
        -o 03_clean/${s}_R1.clean.fq.gz -O 03_clean/${s}_R2.clean.fq.gz \
        --detect_adapter_for_pe --qualified_quality_phred 20 \
        --length_required 36 --thread 8 \
        --json 03_clean/${s}.fastp.json --html 03_clean/${s}.fastp.html
done
multiqc 03_clean/clean_qc -o 03_clean/clean_qc   # 修剪后再评估一次
```

**看什么**：Q30 比例、接头污染、GC 分布、是否有人工序列（如 polyG、引物残留）。

### 3.2 判断链特异性（必做，否则计数会错）

```bash
# 先用少量 reads 比对一次，判断建库链特异性
python infer_experiment.py -r 02_ref/hg38.bed12 -i 04_aligned/S1.sorted.bam
# 输出 "1++,1--,2+-,2-+" 一类比例，据此决定 featureCounts 的 -s 参数：
#   主要为 1++,1--  → -s 1（正向）
#   主要为 1+-,1-+  → -s 2（反向，dUTP 建库最常见）
#   两者接近        → -s 0（非链特异性）
```

### 3.3 比对（STAR）

```bash
for s in $(cut -f1 01_meta/sample_sheet.tsv | tail -n +2); do
  STAR --runThreadN 16 --genomeDir 02_ref/star_index \
       --readFilesIn 03_clean/${s}_R1.clean.fq.gz 03_clean/${s}_R2.clean.fq.gz \
       --readFilesCommand zcat \
       --outFilterMismatchNmax 6 --outSAMtype BAM SortedByCoordinate \
       --outFileNamePrefix 04_aligned/${s}_ \
       > logs/${s}_star.log 2>&1
  samtools index 04_aligned/${s}_Aligned.sortedByCoord.out.bam
done
```

**看什么**：`Uniquely mapped %`（一般 >70–80%）、`Multiple mapped %`、`Too short %`。比对率异常先查参考版本与样本质量。

### 3.4 计数（featureCounts）

```bash
featureCounts -T 16 -p -t exon -g gene_id -s 2 -a 02_ref/gencode.v44.annotation.gtf \
  -o 05_quant/counts.txt 04_aligned/*_Aligned.sortedByCoord.out.bam

cut -f1,7- 05_quant/counts.txt | tail -n +2 > 05_quant/counts_matrix.tsv
head -n 1 05_quant/counts_matrix.tsv    # 确认列名与样本名一致
```

**要点**：`-p` 用于双端；`-s` 必须与 3.2 判断结果一致；输出矩阵再交给 R。

（若走 Salmon 路线：`salmon quant -i salmon_index -l A -1 R1 -2 R2 --gcBias --validateMappings -p 16 -o 05_quant/${s}`，再在 R 中用 `tximport(..., type = "salmon")` 汇总到基因层面。）

## 四、差异表达（DESeq2 可运行脚本骨架）

```r
library(DESeq2); library(tximport); library(ggplot2)

## 1. 读入计数矩阵与样品表（列名与样品表必须一一对应）
counts <- read.delim("05_quant/counts_matrix.tsv", row.names = 1, check.names = FALSE)
meta   <- read.delim("01_meta/sample_sheet.tsv", row.names = 1)
stopifnot(identical(colnames(counts), rownames(meta)))   # 顺序不一致是最常见事故

## 2. 低表达基因过滤（保留有信息的基因，减小多重检验负担）
keep   <- rowSums(counts >= 10) >= min(table(meta$group))
counts <- counts[keep, ]

## 3. 构建对象（把批次写进设计公式，防混杂）
dds <- DESeqDataSetFromMatrix(counts, meta, design = ~ batch + group)
dds <- DESeq(dds)

## 4. 提取结果（务必做收缩，避免低表达基因的倍数变化被夸大）
res <- lfcShrink(dds, contrast = c("group", "Tumor", "Normal"), type = "apeglm")
res_df <- as.data.frame(res)
write.csv(res_df, "06_results/DEG_all.csv")

## 5. 差异基因筛选（阈值需事先确定并写进方法）
deg <- subset(res_df, padj < 0.05 & abs(log2FoldChange) >= 1)
write.csv(deg, "06_results/DEG_significant.csv")

## 6. 样本级质控图：PCA 与样本相关性
vsd <- vst(dds, blind = TRUE)
plotPCA(vsd, intgroup = "group")
```

### 4.1 富集分析骨架

```r
library(clusterProfiler); library(org.Hs.eg.db); library(fgsea); library(msigdbr)

gene   <- bitr(rownames(deg), fromType = "SYMBOL", toType = "ENTREZID", OrgDb = org.Hs.eg.db)

## 过表征分析（ORA）：用差异基因列表
ego <- enrichGO(gene$ENTREZID, OrgDb = org.Hs.eg.db, ont = "BP",
                pAdjustMethod = "BH", pvalueCutoff = 0.05, qvalueCutoff = 0.2)
ekg <- enrichKEGG(gene$ENTREZID, organism = "hsa", pvalueCutoff = 0.05)

## 基因集富集分析（GSEA）：用全基因排序，比 ORA 更稳（不依赖人为阈值）
ranks <- res_df$log2FoldChange; names(ranks) <- rownames(res_df)
ranks <- sort(ranks[!is.na(ranks)], decreasing = TRUE)
hallmark <- msigdbr(species = "Homo sapiens", category = "H") |>
  (\(x) split(x$gene_symbol, x$gs_name))()
fgseaRes <- fgsea(hallmark, ranks, minSize = 15, maxSize = 500)
```

**注意**：ORA 依赖"差异基因阈值"这一人为选择，GSEA 用全部基因排序，两者结论不一致时以 GSEA 为准更能反映整体趋势。

### 4.2 出图骨架

```r
library(EnhancedVolcano); library(pheatmap)

EnhancedVolcano(res_df, lab = rownames(res_df), x = "log2FoldChange", y = "padj",
                pCutoff = 0.05, FCcutoff = 1, title = "Tumor vs Normal")

## 热图：用方差最大的基因，先做样本内标准化（z-score）
top <- head(order(rowVars(as.matrix(assay(vsd))), decreasing = TRUE), 50)
pheatmap(assay(vsd)[top, ], scale = "row", show_rownames = FALSE,
         annotation_col = meta["group"], cluster_cols = TRUE)
```

## 五、样品表与设计公式怎么写

| 场景 | 设计公式（DESeq2） | 说明 |
| --- | --- | --- |
| 两组比较 | `~ group` | 最简单 |
| 两组 + 批次 | `~ batch + group` | 批次与分组不混杂时可用 |
| 配对样本 | `~ patient + group` | 同一患者治疗前后 |
| 多组比较 | `~ group`，用 contrast 指定比较 | 不要两两无脑比较后再拼结论 |
| 时间序列 | `~ time + group` 或交互项 | 需专门建模 |
| 混杂无法分离 | 无法补救 | 只能在局限中说明 |

**核心原则**：**先看样品表，再看结果**。表里没有记录批次与临床变量，后面的所有校正都无从谈起。

## 六、常见坑与排查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 计数矩阵列名与 meta 行名不一致 | 样品名拼写/顺序问题 | `identical()` 断言；重命名后重跑 |
| 计数普遍偏低 | `-s` 链特异性设错 | 用 infer_experiment 重新判断 |
| `DESeq` 报错 "every gene contains at least one zero" | 未过滤低表达基因 | 先做 `rowSums` 过滤 |
| 结果里全是 NA | 该组样本过少或被过滤只剩少数基因 | 检查分组与过滤条件 |
| 倍数变化大得离谱（>100 倍） | 未做 lfcShrink / 低表达基因 | 使用 `lfcShrink`，过滤低表达 |
| PCA 里样本按批次聚集 | 批次效应主导 | 加入批次协变量；必要时 limma removeBatchEffect 仅用于可视化 |
| 出现一个明显离群样本 | 质量或标签错误 | 查 QC 与临床信息，不要为"跑出结果"直接删 |
| 富集结果什么都显著 | 基因列表过长（用了全部基因） | ORA 用差异基因，或用 GSEA |
| 富集结果一个都不显著 | 列表过短或阈值过严 | 放宽定义并报告敏感性分析 |
| 换了参考版本结果全变 | 版本不一致 | 全程固定同一版本并记录 |

## 七、结果交付清单（做给自己也做给论文）

| 类别 | 内容 |
| --- | --- |
| 原始数据质控 | MultiQC 报告（修剪前后）、reads 统计表 |
| 比对质控 | 比对率、唯一比对率、基因体覆盖均一性 |
| 表达矩阵 | 基因计数矩阵（含基因注释列） |
| 样本级质控 | PCA 图、样本相关性热图 |
| 差异结果 | 全基因结果表 + 显著差异表（含 log2FC、pvalue、padj） |
| 富集结果 | GO/KEGG/GSEA 结果表与图 |
| 可视化 | 火山图、热图、箱线图（关键基因） |
| 方法学段落 | 版本、参数、阈值、统计方法与校正方式 |
| 代码与环境 | 脚本、环境文件、随机种子、日志 |

### 方法学段落模板

> 原始 reads 经 fastp（vX.X）进行接头去除与质量过滤，使用 STAR（vX.X）比对至 GRCh38（GENCODE v44）参考基因组，采用 featureCounts（vX.X，`-s 2`）进行基因水平计数。差异表达分析使用 R 包 DESeq2（vX.X），设计公式为 `~ batch + group`，倍数变化采用 apeglm 收缩估计，以 padj < 0.05 且 |log2FC| ≥ 1 判定差异表达。功能富集采用 clusterProfiler（vX.X）与 fgsea（vX.X），多重检验采用 Benjamini-Hochberg 校正。

## 八、自查清单

- [ ] 参考基因组与注释版本是否全程一致并记录？
- [ ] 链特异性是否实测判断，而非默认？
- [ ] 样品表的分组与批次是否完整，列名是否完全匹配？
- [ ] 是否报告了修剪前后的质控指标？
- [ ] 是否检查了 PCA 与样本相关性，离群样本是否解释？
- [ ] 差异阈值是否**事先确定**并写进方法？
- [ ] 是否使用了 lfcShrink，是否报告 padj 而非原始 p 值？
- [ ] 富集分析是否同时给出方向（上调/下调）？
- [ ] 结论是否有独立验证（公共数据或 qPCR/蛋白）？
- [ ] 脚本与环境文件是否存档？

## 十、术语速查

| 术语 | 含义 |
| --- | --- |
| FASTQ | 含碱基与质量值的原始测序数据 |
| 链特异性（-s） | 计数时是否区分转录本方向 |
| 计数矩阵 | 基因 × 样本的 reads 计数 |
| lfcShrink | 对倍数变化做收缩估计，减少低表达基因的夸张值 |
| padj | 多重检验校正后的 P 值 |
| ORA / GSEA | 过表征分析 / 基因集富集分析 |
| vst | 方差稳定变换，用于 PCA 与聚类可视化 |
