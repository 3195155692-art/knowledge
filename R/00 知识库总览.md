# 组学知识库 · 总览

> 这是一套面向**临床医学背景、以应用为主**的组学知识库。每篇笔记都按同一体例编写：一句话定位 → 原理（只讲影响判读的部分）→ 技术选择 → 样本与设计 → 数据流程 → 质控阈值 → **结果怎么读** → 临床场景 → 陷阱 → 工具 → 权威出处。
> 编写与引用规则见 [[99 体例与写作规范]]。

## 三、生信分析实操路线

面向"以应用为主、要自己跑分析"的读者，建议按下面的顺序推进。每一篇都可以单独使用，但按顺序学最省时间。

| 阶段 | 做什么 | 看哪篇 | 完成标志 |
| --- | --- | --- | --- |
| 0 打地基 | 装环境、定目录、认格式 | [[14 生信分析环境与工作流基础]] | 能独立装好一个分析环境并跑通质控 |
| 1 走通流程 | Bulk RNA-seq 从 FASTQ 到差异基因 | [[15 转录组分析实操]] | 能自己出一个火山图和差异表 |
| 2 挖公共数据 | GEO / TCGA 下载、整理、生存分析 | [[18 公共数据挖掘实操]] | 能用公共数据做出一个可验证的结果 |
| 3 加专题分析 | 免疫浸润等常见附加分析 | [[17 免疫浸润分析]] | 能解释方法差异与结果边界 |
| 4 上单细胞 | 聚类、注释、pseudobulk 差异 | [[16 单细胞分析实操]] | 能独立完成一套单细胞分析 |
| 5 出图与写作 | 图型选择、统计标注、投稿规范 | [[19 分析结果可视化图鉴]] | 图能与统计结果一一对应 |

**三条不出错的经验**

1. **先跑通再优化**：第一遍按标准流程跑通，别一上来就试花哨方法；
2. **每步留证据**：日志、质控图、中间文件都保留，出错时才查得回去；
3. **结果先自查再解释**：对照 [[11 临床研究设计与统计要点]] 的自查清单，再动手写结论。

## 四、学习路径建议

**第一阶段 · 建立判断力（不需要动手分析）**

读 01、02 两篇的"定位 + 原理 + 结果怎么读"，配合 12 熟悉常用数据库。目标是：拿到一份报告或一篇组学论文，能判断结论是否站得住。

**第二阶段 · 能读懂数据**

读 03、05、06 三篇，掌握"不同组学各自的分辨率与局限"。同时通读 11，把设计、样本量、多重检验、验证这些概念建立起来。

**第三阶段 · 能做自己的研究**

读 04、07，学会从公共数据出发做发现，并理解单细胞分析的统计陷阱；用 10 把多层数据串起来；用 11 的报告规范写作。

**第四阶段 · 临床落地**

聚焦 01（变异解读与用药）、05、06（临床质谱应用）、07（拷贝数与产前）、13（液体活检）。

## 五、组学选择速查

| 我要回答的问题 | 首选 | 备选 |
| --- | --- | --- |
| 有没有致病突变 | 基因组（Panel/WES） | CMA（若怀疑拷贝数） |
| 基因表达有没有变化 | 转录组 | 微阵列芯片 |
| 是哪一类细胞在变化 | 单细胞 | 去卷积 |
| 分子的位置在哪里 | 空间组学 | 免疫组化 |
| 实际有多少蛋白 | 蛋白组 | 免疫组化/靶向质谱 |
| 有没有小分子异常 | 代谢组 | 常规生化 |
| 有没有表观改变 | 甲基化芯片/靶向甲基化 | WGBS |
| 有没有病原 | mNGS 或靶向核酸检测 | 培养 |
| 血液里能不能查出肿瘤 | cfDNA（甲基化或突变） | 影像 + 传统标志物 |

**通用原则**：先想清楚**要回答的临床问题**和**要排除的可能**，再选技术；技术越"全"，代价（成本、假阳性、解读负担）越高。

## 六、术语中英对照

| 中文 | 英文 | 备注 |
| --- | --- | --- |
| 组学 | Omics | 泛指基因组、转录组等各类"整体"研究 |
| 测序深度 | Sequencing depth | 决定能否检出低丰度信号 |
| 覆盖度 | Coverage | 有多少区域被覆盖到 |
| 差异表达 | Differential expression | 组间表达差异 |

| 结构变异 | Structural variant (SV) | 大片段重排 |

## 七、本库的使用与维护约定

1. **出处分级**：A 级指南/共识、B 级权威综述与里程碑论文、C 级方法学原始文献、D 级官方文档与数据库；厂商宣传材料不作为依据。
2. **原理取舍**：只保留影响结果判读的原理，算法与推导一律从略。
3. **修改记录**：每次实质性修订请更新文首"更新日期"，并在需要时于正文注明改动原因。
4. **交叉链接**：篇目之间的双链名称必须与文件名严格一致，避免图谱断链。
5. **已知待补**：脂质组学可作为独立专题补充；免疫组库（TCR/BCR）与药物基因组学若使用频繁也可单独成篇。
