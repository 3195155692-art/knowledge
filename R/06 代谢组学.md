# 代谢组学（Metabolomics）

> **一句话定位**：代谢组测的是小分子（氨基酸、脂质、糖、有机酸、药物代谢产物等）。它是最接近**表型**的组学，反映基因、环境、饮食、菌群与药物共同作用的最终结果。
> **它不回答**：是什么基因或蛋白导致了这些变化（→ 基因组 / 转录组 / 蛋白组）。代谢物变化是**结果**，解释机制需要与上游组学联合。
> **临床现实**：代谢组学是**临床检验中最常见的组学**——尿有机酸分析、血氨基酸与酰基肉碱谱、治疗药物监测，本质上都是临床代谢组学。

---

## 一、这项技术能回答什么问题

| 临床/科学问题 | 代谢组给出的答案 | 备注 |
| --- | --- | --- |
| 患者是否患有遗传代谢病？ | 特征性代谢物谱（氨基酸、酰基肉碱、有机酸） | **临床常规检测** |
| 两组人群的代谢谱有何不同？ | 差异代谢物列表 | 最基础的应用 |
| 能否预测糖尿病/心血管风险？ | 代谢标志物（如支链氨基酸、脂质类） | 多为队列研究的关联结果 |
| 肿瘤代谢有何特征？ | 代谢重编程特征（如 2-羟基戊二酸） | 与突变型 IDH 相关 |
| 药物在体内如何代谢？ | 药代动力学与代谢产物谱 | 与临床药理直接衔接 |
| 肠道菌群产生了什么？ | 短链脂肪酸、胆汁酸、氧化三甲胺等 | 菌群-宿主互作的核心 |
| 食品/环境暴露影响如何？ | 暴露相关代谢特征 | 暴露组学方向 |

## 二、基本原理

### 2.1 两大平台：核磁共振与质谱

| 平台 | 原理 | 优势 | 局限 |
| --- | --- | --- | --- |
| **核磁共振（NMR）** | 原子核在外磁场中的共振信号 | 定量准确、无需前处理、样品可回收、重复性极好 | 灵敏度低（只能看到高丰度代谢物） |
| **质谱（MS）** | 分子离子化后按质荷比分离并检测 | 灵敏度高、可测数千种代谢物 | 需前处理、基质效应、跨平台可比性差 |

质谱通常要先经**色谱分离**（液相 LC、气相 GC、毛细管电泳 CE），再进入质谱检测：色谱负责"按化学性质把分子分开"，质谱负责"精确称重 + 碎裂识别结构"。

### 2.2 靶向与非靶向

- **靶向代谢组**：预先确定要测的化合物（如氨基酸谱、胆汁酸谱），用标准品定量。**优点是准确可定量，临床检测都用这一类。**
- **非靶向代谢组**：尽可能多地检测所有可测到的信号，用于发现新标志物。**缺点是多数信号无法确定结构，且是半定量。**

### 2.3 代谢物鉴定的四个等级（必须掌握）

代谢组学最容易被误读的环节就是"这个峰到底是什么"。国际代谢组学学会（Metabolomics Society）的化学分析工作组给出了**四级鉴定标准**：

| 等级 | 判定依据 | 可信度 |
| --- | --- | --- |
| **Level 1（已鉴定）** | 与标准品在相同条件下保留时间、质谱图完全一致 | 最高，可定量 |
| **Level 2（可能结构）** | 与公共/自建谱库的谱图高度匹配，但无标准品 | 结构可靠，定量存疑 |
| **Level 3（化合物类别）** | 只能确定属于某类化合物（如某类脂质） | 只能做类别层面的解释 |
| **Level 4（未知特征）** | 只知质荷比与保留时间，结构未知 | 只能用于统计比较 |

**写作与解读要求**：报告中必须写明每个代谢物的鉴定等级；把 Level 2/3 的代谢物当成 Level 1 来下临床结论，是这一领域最常见的学术不严谨。

### 2.4 由此决定的三条判读规则

1. **丰度是半定量的（非靶向）。** 不同研究、不同平台之间的信号强度**不可直接比较**，只有同一批次内的相对变化有意义。
2. **代谢组对样本采集极其敏感。** 采血时间、是否空腹、饮食、运动、体位、保存温度都会显著改变结果。临床解读代谢组数据时，必须先确认采集条件是否统一。
3. **批次效应比任何其他组学都严重。** 信号漂移会随时间累积，因此必须随机化上机顺序，并插入质控样本做漂移校正。

## 三、技术方案怎么选

| 方案 | 适用场景 | 取舍 |
| --- | --- | --- |
| LC-MS 非靶向 | 发现性研究、整体代谢谱 | 覆盖面广，但鉴定与定量受限 |
| LC-MS 靶向（如胆汁酸、脂质） | 特定代谢物定量 | 准确定量，但范围固定 |
| GC-MS | 挥发性/可衍生化代谢物、有机酸 | **临床遗传代谢病常规**，重复性好 |
| NMR 代谢组 | 队列研究、尿液/血清指纹谱 | 定量可靠、重复性佳，但灵敏度低 |
| 脂质组学（靶向 LC-MS） | 脂质分类与定量 | 脂质种类极多，需专门方法 |
| 单细胞/空间代谢组 | 组织原位代谢成像 | 前沿方向，标准化不足 |

## 四、实验设计与样本要求

### 4.1 样本采集（决定成败的一步）

| 样本 | 关键要求 |
| --- | --- |
| 血清/血浆 | 统一空腹时间与采血时段；快速离心、低温保存；避免反复冻融 |
| 尿液 | 建议记录肌酐并做归一化（浓度受饮水影响大） |
| 组织 | 需快速淬灭（液氮），防止代谢物在离体后继续变化 |
| 粪便 | 厌氧环境、快速冷冻，注意菌群继续代谢 |
| 细胞 | 洗涤后立即淬灭；注意培养基成分残留 |
| 脑脊液 | 采集量与吸附问题 |

**随机化**：样本采集顺序、前处理顺序、上机顺序都应与分组解耦。

### 4.2 设计要点

1. **批次与分组解耦**，并把质控样本按固定间隔插入序列；
2. **每组生物学重复 ≥6–10**（代谢组个体间变异大，通常比转录组需要更多样本）；
3. **控制饮食、作息、用药**等混杂因素，必要时记录并纳入协变量；
4. **明确是发现还是验证**，非靶向发现的结果应换靶向方法验证。

### 4.3 送检前必须问清楚的五个问题

1. 采集条件（空腹时长、时段、保存时间）是否在所有样本中一致？
2. 是靶向还是非靶向？鉴定等级要求到什么水平？
3. 每组多少样本？批次如何安排？有没有质控样本？
4. 是否同时采集了常规生化指标，用于交叉验证？
5. 发现阶段的结果用什么方法验证？（标准品加标、靶向定量、独立队列）

| 格式 | 内容 | 用途 |

| NMR 谱与峰表 | 化学位移与积分值 | 定量分析 |

## 六、标准分析流程

```
样本采集与前处理
  ↓ ① 数据采集（正负离子模式、随机化上机、间隔插入质控样本）
  ↓ ② 峰检测与对齐（XCMS / MZmine / MS-DIAL）
  ↓ ③ 信号漂移校正与归一化
  ↓ ④ 统计分析与差异代谢物筛选
  ↓ ⑤ 结构鉴定（谱库匹配、标准品确认、鉴定定级）
  ↓ ⑥ 通路分析（MetaboAnalyst / mummichog）
  ↓ ⑦ 验证（靶向定量、独立队列）
```

| 步骤 | 目的 | 常用工具 | 关键点 |
| --- | --- | --- | --- |
| 采集 | 获得代谢信号 | LC-MS、GC-MS、NMR | 随机化上机、插入质控样本 |
| 峰检测与对齐 | 把信号整理成特征表 | XCMS、MZmine、MS-DIAL | 参数需记录并可复现 |
| 漂移校正 | 消除时间漂移 | QC-RLSC 等 | 必须用质控样本建模 |
| 统计分析 | 找差异 | MetaboAnalyst、limma、多元统计（PCA/OPLS-DA） | **OPLS-DA 易过拟合，需交叉验证与置换检验** |
| 鉴定 | 确定结构 | HMDB、METLIN、GNPS、mzCloud | 明确鉴定等级 |
| 通路分析 | 解释生物学含义 | MetaboAnalyst、mummichog、KEGG | 注意数据库覆盖不全 |
| 验证 | 确认真实性 | 靶向 LC-MS/MS、标准品加标 | 无验证的发现只能算假设 |

## 七、质量控制指标

| 指标 | 常见参考 | 异常含义 |
| --- | --- | --- |
| 质控样本的相对标准偏差 | 常用门槛 <30%（多数平台可达 <15%） | 超出说明方法不稳 |
| PCA 中质控样本聚集 | 应紧密聚集 | 分散提示漂移严重 |
| 保留时间漂移 | 同一代谢物在样本间应稳定 | 漂移大影响对齐与鉴定 |
| 空白样本信号 | 应低，携带污染应小 | 高则提示污染或残留 |
| 内标响应 | 应稳定 | 波动提示前处理或仪器问题 |
| 特征数量 | 与方法历史水平比较 | 明显异常提示采集问题 |
| 归一化前后分布 | 应改善而非恶化 | 归一化方法选择错误 |

## 八、结果怎么读（临床视角）

### 8.1 四步阅读法

1. **先看质控**：质控样本是否聚集、漂移是否被校正、缺失比例多少；
2. **再看鉴定等级**：Level 1 与 Level 3 的代谢物，结论强度完全不同；
3. **然后看效应量**：倍数变化与置信区间，而不是只看 P 值；
4. **最后看验证**：是否用标准品或靶向方法在独立样本中确认。

### 8.2 分类模型要有交叉验证

代谢组学论文里常见的 OPLS-DA 图非常"漂亮"，但**极易过拟合**：只要特征数多于样本数，就能把两组完全分开。判断要点：

- 是否做了交叉验证；
- 是否做了置换检验（permutation test）；
- 是否在**独立队列**中验证了模型；
- 报告的是不是 AUC 的置信区间，而不是一个孤立的 AUC 数值。

### 8.3 通路分析是"提示"不是"证明"

mummichog 等工具可以在没有鉴定结果的情况下预测受影响的通路，但结果是**基于假设的推断**，依赖数据库覆盖度。用于生成假设合理，用于下临床结论不合适。

### 8.4 代谢物与临床指标的关系

临床解读时最好把代谢物与**已有的常规检验**对照（血糖、血脂、肝肾功能、电解质等）。如果一项代谢组"发现"与临床常规指标完全脱节，应优先怀疑技术问题而非生物学新发现。

## 九、临床应用场景

### 9.1 遗传代谢病与新生儿筛查（临床最成熟）

- **新生儿筛查**：串联质谱一次检测多种氨基酸与酰基肉碱，覆盖苯丙酮尿症、甲基丙二酸血症、脂肪酸氧化障碍、尿素循环障碍等；
- **尿有机酸分析（GC-MS）**：用于有机酸血症等疾病的诊断；
- **血浆氨基酸谱**：氨基酸代谢病的诊断与随访；
- **判读要点**：这类检测的解读需要结合临床表型、家族史与基因检测，不能只看单项指标（很多代谢物受饮食、药物与标本采集影响）。

### 9.2 代谢性疾病风险

队列研究提示若干代谢物（如支链氨基酸、特定脂质与神经酰胺）与 2 型糖尿病与心血管事件风险相关。临床价值在于**机制提示与风险分层**，目前尚未普遍进入个体化诊疗路径。

### 9.3 肿瘤代谢

- **2-羟基戊二酸**：IDH1/2 突变肿瘤的特征性代谢物，用于机制研究与部分诊断场景；
- **代谢重编程**：糖酵解、谷氨酰胺代谢通路是治疗干预的热点；
- 临床上，乳酸等代谢物还与影像学（磁共振波谱）相互印证。

### 9.4 肠道菌群与宿主代谢

短链脂肪酸、胆汁酸、氧化三甲胺等是菌群-宿主互作的关键分子。临床上与菌群移植、炎症性肠病、代谢综合征研究相关，**目前多为机制研究层面** → [[09 微生物组与病原检测]]。

### 9.5 药物代谢与毒理

代谢组可用于分析药物代谢产物、解释个体差异与毒性机制，与治疗药物监测（质谱定量）在方法上高度重合。

## 十、局限与常见陷阱

| 陷阱 | 错在哪 | 怎么避免 |
| --- | --- | --- |
| 把 Level 3 的代谢物当确定结构 | 结论建立在错误命名上 | 明确标注鉴定等级，关键代谢物用标准品确认 |
| 跨研究比较半定量信号 | 平台与条件都不可比 | 只在同一批次内比较；跨研究需靶向定量 |
| 采集条件不统一 | 结果反映的是采样差异 | 统一空腹、时段、保存流程 |
| 忽略批次漂移 | 与分组混杂的漂移被当成生物学差异 | 随机化上机 + 质控样本校正 |
| OPLS-DA 未交叉验证 | 过拟合，分类"完美"但无意义 | 交叉验证 + 置换检验 + 独立验证 |
| 把缺失当零 | 系统性偏倚 | 说明缺失机制与处理方法 |
| 未校正多重比较 | 假阳性泛滥 | 报告 FDR |
| 未考虑饮食与药物 | 混杂因素被当成发现 | 记录并纳入协变量，必要时做饮食控制研究 |
| 样本量过小 | 结果不可重复 | 每组 ≥6–10，验证队列独立 |
| 只做通路预测即下结论 | 推断被当作证据 | 用标准品或靶向定量确认关键代谢物 |

## 十三、术语速查

| 术语 | 含义 |
| --- | --- |
| 靶向/非靶向 | 预先指定化合物定量 / 尽可能广泛地检测 |
| 特征（feature） | 峰检测得到的一个信号，未必已确定结构 |
| 鉴定等级 | Level 1–4，表示结构确定的可靠程度 |
| 质控样本（QC） | 混合样本，用于监测漂移与校正 |
| 漂移校正 | 消除信号随时间变化的技术波动 |
| 半定量 | 只能比较相对高低，不能给出绝对浓度 |
| NMR | 核磁共振，定量准确但灵敏度低 |
| 暴露组学 | 研究与疾病相关的环境暴露代谢特征 |
