# 临床研究设计与统计要点

> **一句话定位**：组学研究里，**绝大多数"结果不可重复"不是技术问题，而是设计与统计问题**。这一篇不讲数学推导，只讲临床医生做组学研究必须知道、且最容易出错的部分。
> 读法建议：先从第 1 节（设计）和第 6 节（常见错误）看起，写作或投稿前再看第 7 节（报告规范）与第 8 节（自查清单）。

---

## 一、设计：错误在数据产生之前就已经注定

### 1.1 设计类型与能回答的问题

| 设计 | 能回答 | 不能回答 | 组学中的常见形式 |
| --- | --- | --- | --- |
| 横断面 | 患病率、相关性 | 因果、时间顺序 | 一次检测所有入组患者 |
| 病例对照 | 相关性（OR） | 发病率 | 病例组 vs 对照组做组学比较 |
| 队列（前瞻） | 发病风险、预后、因果证据较强 | 罕见终点需极大规模 | 基线组学 → 随访终点 |
| 队列（回顾） | 预后、关联 | 因果（易受选择偏倚影响） | 已有生物样本库 + 病历随访 |
| 随机对照试验（RCT） | 因果（最高等级） | 成本高、组学样本量常不足 | 分层生物标志物分析（需预设） |
| 自身前后对照/配对 | 干预效应（控制个体差异） | 时间效应难以排除 | 治疗前后配对样本 |
| 诊断准确性研究 | 敏感度、特异度、AUC | 临床获益 | 新标志物 vs 金标准 |
| 预后/预测模型研究 | 风险预测 | 因果 | 多指标建模（TRIPOD 规范） |

### 1.2 组学研究最常用的两种模式

**模式 A：发现 + 验证（最稳）**

```
发现队列（组学筛选，样本可较小，允许一定假阳性）
   → 生成候选标志物/模型
   → 验证队列（独立人群，靶向方法或独立检测）
   → 临床效用评估（前瞻性/决策曲线分析）
```

**模式 B：公共数据 + 自有队列（临床医生最高性价比）**

```
公共数据（GEO/TCGA）发现 → 自有队列验证 → 结合随访做预后分析
```

⚠️ **公共数据的内部验证不算外部验证**。用同一数据集建模又验证，是最常被审稿人驳回的问题。

### 1.3 样本量与统计功效

组学研究的样本量问题有两个层面：

- **技术层面**：差异表达通常每组 ≥3 个生物学重复；代谢组因个体变异大，常需每组 ≥6–10；
- **临床层面**：涉及临床终点（如复发、死亡）时，样本量由**事件数**决定，而不是由样本总数决定。

| 场景 | 经验原则 |
| --- | --- |
| 连续指标的组间比较 | 由效应量、标准差、α、把握度估算 |
| 二分类终点 | 每个自变量至少 10 个事件（EPV ≥10 的经验法则） |
| 生存终点 | 由事件数（而非人数）估算 |
| 预测模型开发 | 需专门的样本量计算方法，不能照搬组间比较 |
| 机器学习/高维标志物 | 特征数 ≫ 样本量时极易过拟合，必须交叉验证 + 外部验证 |

**最常见的错误是"事后算功效"**：样本量应在研究开始前确定，并在方法部分写明依据。

### 1.4 随机化与批次（不可逆的设计错误）

| 错误做法 | 后果 | 正确做法 |
| --- | --- | --- |
| 对照组第 1 批、实验组第 2 批 | 批次效应与分组完全混杂，事后无法分离 | 每个批次内都包含各组样本 |
| 按住院时间顺序入组并分装 | 时间趋势混入结果 | 随机化或按区组随机化 |
| 样本处理顺序按分组集中 | 前处理差异被当成生物学差异 | 处理顺序随机化 |
| 多中心数据直接合并 | 中心效应被当成疾病差异 | 中心作为协变量或做分层分析 |

### 1.5 偏倚与混杂

| 类型 | 含义 | 组学研究中的典型表现 | 控制手段 |
| --- | --- | --- | --- |
| 选择偏倚 | 入组样本不能代表目标人群 | 只纳入能取到足够组织量的患者 | 明确纳排标准、连续入组 |
| 信息偏倚 | 暴露/结局测量不准 | 随访靠回忆、结局定义模糊 | 标准化定义与盲法评估 |
| 混杂 | 第三因素同时与暴露和结局相关 | 年龄、性别、分期未校正 | 设计阶段匹配/分层；分析阶段多元校正 |
| 伯克森偏倚 | 医院人群中的假关联 | 病例来自专科门诊 | 注意来源人群 |
| 幸存者偏倚 | 只分析"活到能取样的人" | 生物样本库样本偏健康 | 报告入组流程与缺失 |
| 选择报告偏倚 | 只报告阳性结果 | 多指标中挑好看的 | 预注册、报告全部预设指标 |

## 二、数据预处理中影响统计的三个决策

1. **离群样本怎么处理**：先查技术原因（质控失败、批次、样本错配），能解释就剔除并说明；无法解释时保留并做敏感性分析。**不要因为"影响结果"就删样本。**
2. **批次校正能不能做**：只有当批次与分组**不混杂**时才能校正；若完全混杂，校正也无法挽回，必须在讨论中作为局限说明。
3. **缺失值怎么处理**：少量随机缺失可用多重插补；组学特征层面的缺失（尤其蛋白组的 MNAR）应优先过滤而不是插补。

## 三、统计方法怎么选

| 数据类型 | 组间比较 | 多因素分析 |
| --- | --- | --- |
| 连续变量（正态） | t 检验 | 线性回归 |
| 连续变量（偏态） | Mann-Whitney / Wilcoxon | 变量变换后回归或稳健回归 |
| 二分类结局 | 卡方 / Fisher 精确检验 | 逻辑回归（报告 OR 与置信区间） |
| 生存时间（含删失） | Log-rank 检验、Kaplan-Meier 曲线 | Cox 比例风险模型（报告 HR；需检验比例风险假设） |
| 配对/重复测量 | 配对 t / Wilcoxon | 混合效应模型 |
| 多中心/聚类数据 | — | 混合效应模型或聚类稳健标准误 |
| 高维数据（组学） | 负二项模型（计数）、limma（芯片/蛋白） | 含协变量的设计矩阵 |

### 3.1 多重检验：组学研究绕不开的一步

一次检测上万基因，如果每个都用 0.05 的阈值，光靠偶然就会得到大量"阳性"。

| 控制方式 | 含义 | 适用 |
| --- | --- | --- |
| FWER（如 Bonferroni） | 控制"出现任意一次假阳性"的概率 | 检验次数少、结论必须极稳（如确证性研究） |
| **FDR（Benjamini-Hochberg）** | 控制"被判为阳性的结果中假阳性的比例" | **组学研究的默认选择** |

**实践建议**：组学筛选报告 FDR（padj）；少数预先设定的核心指标再单独校正。报告时写清是 FDR 还是 Bonferroni，并给出具体数值。

### 3.2 效应量与置信区间，比 P 值更重要

- **P 值只回答"有没有差异"**，不回答"差异有多大"；
- 报告应给出：效应量（倍数变化、OR、HR、均值差）+ **95% 置信区间**；
- 置信区间宽说明估计不可靠——样本量小的时候，即使 P<0.05，置信区间也可能跨越无意义区间。

### 3.3 生存分析要点

- Kaplan-Meier 曲线用于展示，组间比较用 log-rank；
- 多因素用 Cox 模型，报告 HR 与置信区间；
- **必须检验比例风险假设**，不满足时考虑时依协变量或分层 Cox；
- 连续变量按"最佳截断值"分组会显著高估效应（见下文），尽量保留连续变量或使用预设截断。

### 3.4 诊断与预测：不要只看 AUC

| 指标 | 回答的问题 | 注意 |
| --- | --- | --- |
| 敏感度 / 特异度 | 判对阳性和阴性的能力 | 随阈值变化，须同时报告 |
| 阳性/阴性似然比 | 该结果对诊断概率的改变程度 | 比单一敏感度更实用 |
| ROC / AUC | 判别能力 | 需给置信区间；不同人群差别大 |
| **校准度** | 预测概率是否准确 | 常被忽略，却是临床使用的前提 |
| 决策曲线分析 | 在不同阈值下是否有净获益 | 反映临床有用性 |
| 净重分类改善（NRI） | 新指标是否改善分类 | 解释存在争议，慎用 |

**关键提醒**：AUC 高不等于临床有用；一个模型如果校准差，给出的"风险 30%"可能根本不成立。

### 3.5 验证：内部、外部与时间验证

| 方式 | 做法 | 强度 |
| --- | --- | --- |
| 内部验证 | 交叉验证、bootstrap 校正 | 只能说明模型没有明显过拟合 |
| 外部验证 | 独立中心/独立人群 | **临床可用的必要条件** |
| 时间验证 | 用后续时间段的数据验证 | 接近真实使用场景 |

**嵌套交叉验证**：凡是在交叉验证内部做了特征筛选或调参的，必须把筛选步骤放进循环内，否则结果偏乐观。

### 3.6 亚组分析

亚组分析应当**预先设定**并说明理由，报告交互作用检验（P for interaction），而不是在多个亚组里反复比较找阳性结果。**事后挑选亚组得阳性的结论，只能作为假设。**

## 四、结果解读的尺度

### 4.1 相对风险 vs 绝对风险

| 指标 | 含义 | 陷阱 |
| --- | --- | --- |
| RR / OR / HR | 相对风险 | 数值大不一定临床重要（基线风险低时尤甚） |
| ARR / ARD | 绝对风险差 | 更能反映实际获益 |
| NNT | 需治疗多少人获益一例 | 与随访时间绑定，需注明时长 |

**举例**：某干预把风险从 2% 降到 1%，相对风险下降 50%（看起来很大），绝对风险下降 1%（NNT=100）。反过来，风险从 20% 降到 15%，相对下降 25%，但绝对下降 5%（NNT=20），临床意义更实在。

### 4.2 把连续变量二分的代价

"按中位数分组""取最佳截断值"是临床研究里最普遍的做法，但它会：

- 丢失信息、显著降低统计功效；
- **被"最佳截断值"人为放大效应量**，且几乎无法在外部重复。

首选做法：保留连续变量进入模型；确需分组时使用**预设的临床有意义阈值**（如指南采用的分界）。

### 4.3 统计显著 ≠ 临床重要

样本量足够大时，任何微小差异都能达到 P<0.05。判断临床价值要问三件事：**效应量大不大、在独立人群中能不能重复、对患者决策有没有改变**。

### 4.4 概率思维

检验结果的意义取决于**检验前的可能性**：一个患病率极低的病，即使检测灵敏度和特异度都不错，阳性预测值也可能很低（这就是为什么筛查项目要谨慎解读阳性结果）。反过来，临床高度怀疑时，阴性结果的说服力也有限。

## 五、数据分析中的常见错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 事后算功效 | 掩盖样本量不足 | 研究前确定样本量 |
| 循环验证 | 结论不可重复 | 独立队列验证 |
| 把细胞/技术重复当生物学样本（伪重复） | 假阳性剧增 | 以个体为统计单位 |
| 多重检验不校正 | 假阳性泛滥 | 报告 FDR |
| 只看 P 值 | 忽略效应量与不确定性 | 报告效应量与置信区间 |
| 用最佳截断值分组 | 高估效应、无法重复 | 保留连续或预设阈值 |
| 亚组反复寻找阳性 | 假阳性 | 预设亚组 + 交互检验 |
| 用同一数据做特征筛选与验证 | 结果过于乐观 | 嵌套交叉验证或外部验证 |
| 缺失值随便填 | 引入偏倚 | 说明机制与方法，做敏感性分析 |
| 生存分析忽略比例风险假设 | 结论失真 | 检验假设并调整模型 |
| 只报告 AUC 不报告校准 | 无法判断能否临床使用 | 报告校准曲线与决策曲线 |
| 选择性报告 | 结论不可信 | 预注册、报告全部预设指标 |

## 六、报告规范与偏倚评估工具（写作与投稿必备）

| 规范/工具 | 适用研究类型 |
| --- | --- |
| CONSORT | 随机对照试验 |
| STROBE | 观察性研究（队列、病例对照、横断面） |
| STROBE-ME | 分子流行病学研究（含生物标志物） |
| PRISMA | 系统综述与荟萃分析 |
| STARD | 诊断准确性研究 |
| TRIPOD / TRIPOD+AI | 预测模型研究（含机器学习） |
| REMARK | 肿瘤标志物预后研究 |
| ARRIVE | 动物实验 |
| CARE | 病例报告 |
| Cochrane RoB 2 / ROBINS-I / PROBAST | 偏倚风险评估（RCT / 非随机干预 / 预测模型） |

**实操建议**：写文章时把这些清单直接当写作提纲用；投稿前逐条核对，可以避免绝大多数方法学质疑。

## 七、投稿前自查清单

**设计**

- [ ] 研究问题能用一句话说清，且事先明确？
- [ ] 样本量有事先估算，并写明参数来源？
- [ ] 试验/研究已在公开平台注册？患者入组流程图是否完整？
- [ ] 批次与分组是否解耦？

**统计**

- [ ] 统计方法与数据类型匹配？
- [ ] 多重检验是否校正，并写明方法？
- [ ] 是否报告效应量与置信区间？
- [ ] 是否以个体（而非技术重复或细胞）为统计单位？
- [ ] 生存分析是否检验比例风险假设？
- [ ] 缺失值与离群样本的处理是否说明并做敏感性分析？
- [ ] 模型是否报告了校准度与外部验证？

**结果与写作**

- [ ] 是否区分"发现"与"验证"两个阶段？
- [ ] 阴性结果与预设指标是否如实报告？
- [ ] 亚组分析是否预设并报告交互作用？
- [ ] 结论是否超出数据支持的范围？
- [ ] 是否按相应的报告规范逐条核查（STROBE / TRIPOD 等）？
