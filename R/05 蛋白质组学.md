# 蛋白质组学（Proteomics）

> **一句话定位**：蛋白质组测的是"细胞里实际有多少蛋白质、被修饰成什么样"。它是所有组学里**最贴近功能表型**的一层——RNA 多不一定蛋白多，而蛋白才是绝大多数药物的作用对象。
> **它不回答**：基因有没有突变（→ 基因组）、RNA 有多少（→ 转录组）。蛋白质组通常只告诉你"哪一批蛋白变了"，不直接给出机制。
> **临床现实**：质谱早已是**常规检验手段**（微生物鉴定、治疗药物监测、新生儿筛查、内分泌激素检测），只是很多临床医生不知道这些结果来自质谱。

---

## 一、这项技术能回答什么问题

| 临床/科学问题 | 蛋白质组给出的答案 | 备注 |
| --- | --- | --- |
| 两组样本哪些蛋白表达不同？ | 差异蛋白列表（倍数变化 + 显著性） | 属发现阶段，需独立验证 |
| 肿瘤的蛋白分型与治疗靶点 | 蛋白组亚型、信号通路活性 | CPTAC 等大型计划的核心产出 |
| 血浆里有哪些疾病相关蛋白？ | 血浆蛋白与疾病/遗传的关联 | 大队列多用亲和法 |
| 淀粉样物质是什么成分？ | 淀粉样蛋白的质谱鉴定分型 | 已进入**临床常规** |
| 这是哪种细菌/真菌？ | 特征蛋白指纹比对 | MALDI-TOF，**微生物室常规** |
| 血药浓度是多少？ | 目标化合物精确定量 | LC-MS/MS，治疗药物监测常规 |
| 蛋白质有哪些翻译后修饰？ | 磷酸化/乙酰化/糖基化位点 | 需专门富集，覆盖度有限 |
| 每个细胞里蛋白如何分布？ | 单细胞/空间蛋白组 | 方法与通量仍在发展中 → [[08 空间组学]] |

## 二、基本原理

### 2.1 质谱的三步逻辑

**离子化 → 按质荷比分离 → 碎裂后读序列**：

1. **离子化**：蛋白质先酶切成肽段，再让肽段带电（常用电喷雾离子化，ESI）。另一条常见路线是基质辅助激光解吸电离（MALDI），用于微生物鉴定等场景。
2. **质量分析**：按质荷比（m/z）分离并测定质量，常用轨道阱（Orbitrap）或飞行时间（TOF）分析器。质量精度越高，鉴定越可靠。
3. **碎裂测序（MS/MS）**：把目标肽段再打碎，读取碎片谱，与理论序列比对，从而确定"这是哪条肽段、来自哪个蛋白"。

### 2.2 定量的四条路线

| 路线 | 原理 | 特点 |
| --- | --- | --- |
| **免标记定量（label-free）** | 直接比较不同样本中同一肽段的信号强度 | 成本低、样本数不受限；对操作一致性要求高 |
| **标记定量（TMT、iTRAQ）** | 给不同样本的肽段打上不同质量标签后混测 | 批次内可比性强、通量高；但混测样本数受限，存在比例压缩 |
| **靶向定量（PRM/MRM）** | 只瞄准预设的目标肽段 | 灵敏度与准确度最高，是**验证阶段的标准方法** |
| **亲和法（Olink、SomaScan 等）** | 用抗体或适配体捕获目标蛋白 | 通量极高（数百至数千蛋白 × 数千样本），适合大队列；但只测预设蛋白 |

### 2.3 两条采集策略：DDA 与 DIA

- **DDA（数据依赖采集）**：机器挑选信号最强的肽段去碎裂 → 鉴定数多，但**重复性较差、缺失值多**；
- **DIA（数据非依赖采集）**：把所有窗口内的肽段都碎裂，事后用谱图库提取定量 → **重复性好、缺失值少**，当前队列与临床转化研究更倾向 DIA。

### 2.4 由此决定的三条判读规则

1. **缺失值不是"零"。** 没检测到某个蛋白，可能是它真的不存在，也可能是丰度低、离子化效率差导致的随机丢失。**把缺失当零会系统性高估差异。**
2. **高丰度蛋白会遮蔽低丰度蛋白。** 血浆中少数高丰度蛋白占据绝大部分质量，掩盖了真正可能作为标志物的低丰度蛋白。血液蛋白组必须做**去高丰度处理或改用亲和法**，否则检出的往往是"最响的那几个"。
3. **FDR 控制是可信度的前提。** 目标-诱饵策略下，通常要求肽段与蛋白层面的错误发现率控制在 1% 左右，并在方法中明确写出；未给出 FDR 的鉴定结果不应采信。

## 三、技术方案怎么选

| 方案 | 检测范围 | 适用场景 | 取舍 |
| --- | --- | --- | --- |
| 免标记 DDA 蛋白质组 | 数千蛋白 | 探索性研究、机制 | 便宜，但缺失值多、重复性一般 |
| DIA 蛋白质组 | 数千至上万蛋白 | 队列研究、临床转化 | 重复性好，分析门槛较高 |
| TMT 标记蛋白质组 | 数千至上万蛋白 | 多样本比较 | 批次内可比性强，但比例被压缩 |
| 修饰蛋白质组（如磷酸化） | 数千位点 | 信号通路、激酶活性 | 需富集，覆盖度有限 |
| 靶向 PRM/MRM | 数十至数百蛋白 | 标志物验证 | 灵敏准确，但需先有候选 |
| 亲和法多重检测 | 数百至数千蛋白 | 大样本队列、血浆 | 通量最高，但仅限预设蛋白 |
| 单细胞/空间蛋白组 | 数十个标志物 | 组织原位、细胞分型 | 原位信息强，广度有限 |

## 四、实验设计与样本要求

### 4.1 样本与处理

| 样本 | 要点 | 风险 |
| --- | --- | --- |
| 血浆/血清 | 需去高丰度或使用亲和法；采集与离心流程必须统一 | 采血管类型、离心时间都会改变结果 |
| 组织 | 快速冷冻，取材部位一致 | 组织异质性、血液污染 |
| 细胞 | 裂解效率一致，充分洗涤 | 培养基蛋白残留 |
| FFPE 组织 | 可行，但需专门流程 | 交联影响酶切效率 |
| 尿/脑脊液 | 需浓缩或去高丰度 | 蛋白总量低，易吸附损失 |

### 4.2 设计要点

1. **批次与分组必须解耦**（样本制备批次、上机批次都要随机化）；
2. **设置质控样本与内标**，用于评估批次漂移；
3. **生物学重复**：组织/细胞一般每组 ≥3；队列研究需要更大样本量；
4. **预先确定目标**：是"发现"（广度优先）还是"验证"（准确度优先），两者方案完全不同。

### 4.3 送检前必须问清楚的五个问题

1. 处于发现阶段还是验证阶段？（决定用免标记/DIA 还是 PRM）
2. 样本是血浆还是组织？（决定是否去高丰度、是否用亲和法）
3. 目标是定量蛋白丰度，还是定位磷酸化等修饰？
4. 有没有质控样本与内标？批次如何安排？
5. 差异蛋白打算用什么方法验证？（靶向质谱、免疫印迹、免疫组化）

## 六、标准分析流程

```
样本 → 前处理（裂解、还原烷基化、酶切、可选去高丰度/富集）
     → ① LC-MS/MS 采集（DDA 或 DIA）
     → ② 搜库鉴定（MaxQuant / FragPipe / Proteome Discoverer / Spectronaut）
     → ③ FDR 过滤（肽段与蛋白层面 1% 左右）
     → ④ 定量与归一化
     → ⑤ 缺失值处理与样本级质控（PCA、相关性）
     → ⑥ 差异分析（limma / MSstats / Perseus 等）
     → ⑦ 功能富集与通路分析
     → ⑧ 验证（PRM/MRM、免疫印迹、免疫组化、独立队列）
```

| 步骤 | 目的 | 常用工具 | 关键点 |
| --- | --- | --- | --- |
| 前处理 | 把蛋白变成可测肽段 | 商用试剂盒、自动化工作站 | 流程统一比方法先进更重要 |
| 采集 | 获得质谱信号 | Orbitrap、TOF 类仪器 | DDA 或 DIA 决定后续分析路线 |
| 搜库 | 把谱图对上序列 | MaxQuant、FragPipe、Proteome Discoverer、Spectronaut、DIA-NN | 数据库版本、酶切规则、修饰设置要写进方法 |
| 质控过滤 | 控制假发现 | 目标-诱饵 FDR | PSM/肽段/蛋白三级 FDR 都要看 |
| 定量归一化 | 消除上样量差异 | 内置函数、内标校正 | 归一化策略直接影响差异结果 |
| 缺失值处理 | 避免偏倚 | 过滤、插补（谨慎） | **插补会制造虚假差异，需在文中说明** |
| 差异与富集 | 得到结论 | limma、MSstats、Perseus、clusterProfiler | 以样本为单位统计，控批次 |
| 验证 | 确认结论 | PRM、免疫印迹、免疫组化 | 发现阶段的结论必须验证 |

### 关键参数怎么读

| 参数 | 含义 | 判读意义 |
| --- | --- | --- |
| 质量精度（ppm） | 测得质量与理论质量的偏差 | 通常要求 <5–10 ppm（高分辨仪器） |
| FDR | 假发现率 | 常规 1%，需说明统计层级 |
| 肽段数/蛋白数 | 鉴定广度 | 决定结论的覆盖面 |
| 缺失值比例 | 有多少比例样本中未检出 | 过高说明方法不稳定或蛋白过低丰度 |
| 倍数变化 | 组间丰度比 | 需结合变异度与验证结果 |
| 内标变异系数 | 质控品信号稳定性 | 反映批次与仪器稳定性 |

## 七、质量控制指标

| 指标 | 常见参考 | 异常含义 |
| --- | --- | --- |
| 质量精度 | 高分辨仪器通常 <5–10 ppm | 仪器需校准 |
| 肽段/蛋白鉴定数 | 与本方法与样本类型的历史水平对比 | 明显偏低提示前处理或仪器问题 |
| FDR | 常用 1%（肽段与蛋白层面） | 未做 FDR 的结果不可信 |
| 色谱保留时间漂移 | 同一肽段在不同样本间应稳定 | 漂移大影响定量 |
| 样本间相关性 | 同一组样本应高度相关 | 低相关提示批次或样本问题 |
| 内标/质控样本变异系数 | 通常要求 <20% | 超出说明方法不稳 |
| 缺失值比例 | 越低越好（按方法设定阈值） | 高缺失影响统计功效 |
| 污染蛋白 | 角蛋白、胰酶自切峰应低 | 反映操作污染 |
| 酶切效率 | 漏切比例应低 | 影响定量准确性 |

## 八、结果怎么读（临床视角）

### 8.1 先看数据质量，再看差异蛋白

顺序永远是：**鉴定数是否达标 → FDR 是否合格 → 样本聚类是否符合分组 → 缺失值是否合理 → 最后才看差异蛋白**。跳过前四步直接看差异列表，是解读蛋白组数据最常见的错误。

### 8.2 蛋白与 RNA 并不一致

同一批样本的转录组与蛋白组相关性通常只是**中等水平**（不同研究给出的相关系数差异较大，一般在 0.4–0.6 附近波动）。因此：

- 不能因为 RNA 没变就认为蛋白没变；
- 也不能用 RNA 结果替代蛋白验证；
- 两者不一致本身往往是有价值的生物学信息（提示转录后调控）。

### 8.3 缺失值的两种机制

- **MNAR（非随机缺失）**：低丰度蛋白更容易丢失——这是主要情况，插补会引入偏倚；
- **MAR（随机缺失）**：与丰度无关的随机丢失。

**实践建议**：优先用过滤（只保留在多数样本中检出的蛋白）而不是插补；确需插补时，必须说明方法与理由。

### 8.4 修饰组学的额外注意点

磷酸化等修饰的解读要区分三件事：**修饰位点的占比**、**总蛋白量**、**修饰肽段的绝对量**。总蛋白升高也会带来磷酸化信号升高，不能直接说"激酶活性增强"。此外，富集效率在样本间波动会造成假差异，必须做富集效率校正。

### 8.5 从"差异蛋白"到"临床标志物"的距离

这条路径通常分三段：**发现**（蛋白质组学筛选）→ **验证**（靶向质谱或免疫法在独立队列中确认）→ **临床验证**（前瞻性研究评估诊断/预后价值与临床效用）。绝大多数发现阶段的候选标志物在验证阶段失败，原因多是样本量不足、队列不匹配、检测方法不可迁移。**只做了第一步就称"标志物"，是文献里最常见的夸大。**

## 九、临床应用场景

### 9.1 已进入临床常规的应用（最应掌握）

| 应用 | 方法 | 临床价值 |
| --- | --- | --- |
| 微生物快速鉴定 | MALDI-TOF 质谱 | 数分钟内鉴定菌种，替代部分生化鉴定 |
| 淀粉样变分型 | 激光显微切割 + 质谱 | 判定 AL、AA、ATTR 等类型，直接决定治疗 |
| 治疗药物监测 | LC-MS/MS | 免疫抑制剂、抗癫痫药、抗真菌药等血药浓度 |
| 新生儿遗传代谢病筛查 | 串联质谱 | 一次检测多种氨基酸与酰基肉碱谱 |
| 内分泌激素与类固醇检测 | LC-MS/MS | 提高小分子激素检测的特异性 |
| 单克隆免疫球蛋白检测 | 质谱法 | 优于传统电泳，用于浆细胞病随访 |

### 9.2 大型队列与肿瘤蛋白组

- **CPTAC 肿瘤蛋白组计划**：对多种肿瘤做了蛋白组 + 基因组 + 磷酸化组的整合分析，产出蛋白层面的分子分型与治疗靶点，是当前最权威的肿瘤蛋白组资源；
- **血浆蛋白组大队列**：以亲和法在数万人规模上测量血浆蛋白，用于疾病风险关联与药物靶点验证（如 UK Biobank 的血浆蛋白组数据），这类研究的价值在于**把"相关"推向"可能因果"的证据链**。

### 9.3 空间与单细胞蛋白组

多重免疫荧光/成像质谱（如 CODEX、IMC、MIBI 等）可在组织原位同时标记数十个蛋白，把病理形态与分子分型结合起来，是病理学与组学结合最紧的方向 → [[08 空间组学]]。

### 9.4 免疫肽组

直接鉴定肿瘤细胞表面由 HLA 呈递的突变来源肽段（新抗原），为个体化免疫治疗与疫苗设计提供依据，目前主要在研究阶段。

## 十、局限与常见陷阱

| 陷阱 | 错在哪 | 怎么避免 |
| --- | --- | --- |
| 把缺失值当零 | 系统性高估差异 | 过滤为主，插补需说明 |
| 不做 FDR 控制 | 假阳性多 | 说明 PSM/肽段/蛋白层面的 FDR |
| 血浆不做去高丰度 | 只看到高丰度蛋白 | 去高丰度或改用亲和法 |
| 未设质控样本 | 无法评估批次 | 加质控品与内标 |
| 批次与分组混杂 | 效应不可分离 | 随机化 + 组内混批 |
| 用免疫法验证质谱发现的同一抗体 | 相关误差 | 用独立方法或靶向质谱验证 |
| 发现阶段即称标志物 | 过度声称 | 按发现-验证-临床验证三阶段推进 |
| 修饰位点变化等同通路激活 | 忽略总蛋白量 | 校正总蛋白后再谈修饰比例 |
| 忽略蛋白与 RNA 差异 | 结论片面 | 两层数据联合解释 |
| 单一细胞系即外推临床 | 代表性不足 | 用临床样本与独立队列 |
| 样本采集流程不统一 | 结果是流程差异 | 统一采血管、离心与保存流程 |

| 质荷比（m/z） | 质谱的核心测量量 |

| TMT / iTRAQ | 化学标记定量方法 |
| PRM / MRM | 靶向质谱定量方法，用于验证 |
| FDR | 假发现率，鉴定可信度控制指标 |
| 缺失值（MNAR/MAR） | 未检出的两类机制，处理方式不同 |
| 去高丰度 | 去除血浆中占主导的高丰度蛋白 |
