# 多组学联合分析

> **一句话定位**：把两层以上的组学数据（基因组、转录组、蛋白组、代谢组、表观组、微生物组等）放在一起分析，寻找**单层数据看不见的规律**。
> **它不回答**：多做了几层就能自动提升结论强度。**没有明确科学问题的多组学，只会同时放大假阳性与工作量。**

---

## 一、什么时候值得做多组学

| 值得做 | 不值得做 |
| --- | --- |
| 同一批样本，要回答"机制链条"问题（基因变异 → 表达 → 蛋白 → 代谢） | 各层来自不同队列，硬凑在一起 |
| 要建立比单层更稳的分型（多层一致的结果更可靠） | 单层结果还没验证就想加层 |
| 要解释"转录没变但表型变了"（需要蛋白/代谢/表观层面） | 只为了投稿"看起来更完整" |
| 空间或单细胞数据需要参考层来解释 | 样本量不足以支撑多层统计 |

**判断标准**：如果多组学不能回答一个单层回答不了的问题，就不要做。

---

## 二、两种整合方向

### 2.1 垂直整合（同一批样本、不同层次）

按信息流顺序串联：**基因组 → 表观组 → 转录组 → 蛋白组 → 代谢组**。

典型用途：找出"既有拷贝数扩增、又有 mRNA 高表达、还有蛋白高丰度"的靶点——这类三重一致的候选比单层结果可靠得多；或解释"为什么携带某突变的患者对药物不敏感"。

### 2.2 水平整合（同一层次、不同来源或模态）

例如：单细胞转录组 + 空间转录组、微生物组 + 代谢组、影像 + 基因组。

典型用途：用单细胞解释空间数据的细胞组成；用代谢组解释微生物组的功能后果。

---

## 三、常见的整合策略

| 策略 | 做法 | 适用 | 注意事项 |
| --- | --- | --- | --- |
| **一致性筛选** | 各层分别分析后取交集（如同时差异表达 + 差异蛋白） | 最简单、最稳健，临床研究常用 | 交集可能过小；两层不一致本身也是信息 |
| **相关性/网络整合** | 找跨层相关模块（如 WGCNA） | 大样本、模块化结构 | 相关不等于因果 |
| **潜变量降维整合** | 把多层压缩成共同因子（MOFA+、DIABLO、iCluster） | 分型、降维、可视化 | 结果解释需回到原始特征 |
| **通路/网络层面整合** | 在通路层面合并多层信号 | 机制解释、稳健性好 | 依赖数据库覆盖度 |
| **相似网络融合（SNF）** | 按样本相似性融合多层网络 | 分型 | 参数选择影响结果 |
| **监督式整合** | 以临床终点为目标选择多层特征 | 预测模型 | 必须交叉验证 + 外部验证 |

**给临床研究者的实用建议**：如果目标是把结果说清楚，**"一致性筛选 + 通路层面整合"通常比复杂的潜变量模型更好解释，也更经得起审稿**。

## 四、设计与样本要求

1. **同一批样本优先**。同一患者、同一时间点取材是最理想的设计；若必须用不同队列，需在论文中明确说明并避免因果措辞。
2. **样本量取决于最"贵"的那一层**。多组学的功效受限于最难获得的组学，应事先按最严格的那层估算样本量。
3. **注意各层样本量与缺失情况**。不同组学可用样本数不一致时，统计策略要相应调整（成对分析 vs 非成对分析）。
4. **批次与分组解耦**仍然适用于每一层，且各层的批次应对应同一次取材与处理流程。
5. **预先确定分析计划**。多层数据极易"翻找结果"，事先写明主要终点与预设分析路径。

### 设计前必须问清楚的五个问题

1. 多组学要回答的具体科学问题是什么？单层能不能回答？
2. 各层是否来自同一批样本、同一时间点？
3. 样本量对最"贵"的那一层是否足够？
4. 整合策略是预先确定的，还是事后挑选的？
5. 结果用什么独立数据验证？

## 五、标准分析流程

```
① 各层独立预处理与质控（各自归一化、批次处理、缺失值处理）
   ↓
② 各层独立分析（差异表达、差异甲基化、差异蛋白、差异代谢物）
   ↓
③ 特征选择与降维（保留有信息量的特征，控制维度）
   ↓
④ 整合分析（一致性筛选 / 网络 / 潜变量 / 通路层面）
   ↓
⑤ 结果解读与生物学解释（回到具体分子与通路）
   ↓
⑥ 验证（独立队列、正交实验方法）
```

| 步骤 | 关键点 |
| --- | --- |
| 各层预处理 | **先各自处理再整合**；不要为了整合而扭曲单层的正确流程 |
| 单层分析 | 单层结论本身要站得住 |
| 特征选择 | 降维是控制多重检验与过拟合的必要步骤 |
| 整合 | 方法假设要写清楚，参数要可复现 |
| 解释 | 潜变量、聚类编号必须能翻译成具体分子 |
| 验证 | 至少关键结论要有独立验证 |

## 六、统计与质量控制的特殊问题

| 问题 | 为什么危险 | 应对 |
| --- | --- | --- |
| 多重检验被放大 | 多层 × 多特征，假阳性成倍增加 | 每层校正 + 整合层面再做多重检验控制 |
| 过拟合 | 特征数远超样本量 | 嵌套交叉验证、外部验证 |
| 各层样本量不一致 | 统计功效不同 | 报告各层 n，避免统一解读 |
| 层间批次不同 | 引入虚假的跨层相关 | 记录并校正；尽量同批处理 |
| 缺失组学 | 部分样本缺某层 | 说明缺失模式，避免选择性分析 |
| 只用内部数据验证 | 形成循环验证 | 独立队列 + 正交方法 |
| 用"多组学"掩盖单层不显著 | 过度声称 | 如实报告单层结果 |

**报告建议**：方法部分必须写清各层样本数、预处理与归一化方法、整合方法与参数、多重检验校正方式、验证策略。

## 七、结果怎么读（临床视角）

### 7.1 "一致"与"不一致"都有价值

- **多层一致**（如拷贝数扩增 + mRNA 高表达 + 蛋白高丰度）：候选更可靠，适合作为靶点或标志物；
- **多层不一致**：往往提示重要的调控机制（转录后调控、蛋白降解、翻译效率变化），也可能只是技术差异。**报告时要说清是哪种可能性，以及如何区分。**

### 7.2 分型结果要回到临床终点

多组学分型只有在**与预后或治疗响应相关、并在独立队列中重复**时才有临床意义。仅仅"能分开几群"不是终点。

### 7.3 因果表述的边界

多数多组学分析是**关联性**的。要谈因果，需要干预实验、孟德尔随机化或纵向数据支持。临床论文中常见的"多组学揭示某某驱动疾病"，往往证据不足。

### 7.4 潜变量与聚类编号的解释

MOFA 因子、iCluster 亚型这类结果，必须翻译回**具体的分子与通路**，否则对临床读者没有意义。

## 八、临床应用场景

### 8.1 肿瘤多组学分型

最成功的例子是泛癌多组学分析：整合拷贝数、甲基化、mRNA、miRNA 与蛋白数据后发现，**组织来源（细胞起源）对分子特征的塑造作用往往强于单个基因突变**。这类结果改变了人们对"分子分型"的理解方式。

### 8.2 蛋白组主导的整合（CPTAC 等）

把基因组变异与蛋白/磷酸化层面结合，可识别出**基因组层面看不到的治疗脆弱点**（例如某激酶通路在蛋白层面被激活，而 DNA 层面并无明显变异）。

### 8.3 标志物与诊断模型

多组学标志物（如"影像 + 血液代谢物 + 临床变量"）在理论上能提升判别能力，但必须报告增量价值（是否优于已有模型）、校准度与外部验证，否则无法进入临床。

### 8.4 机制研究

在临床样本上做多组学，主要价值是**发现机制假设**；随后通常需要细胞与动物实验验证，才能形成完整的因果链。

## 九、局限与常见陷阱

| 陷阱 | 错在哪 | 怎么避免 |
| --- | --- | --- |
| 无明确问题就上多组学 | 结果无法解释 | 先写清科学问题 |
| 各层来自不同队列 | 跨层关联不成立 | 同一批样本优先 |
| 单层不显著靠"整合"来救 | 过度解释 | 如实报告单层结果 |
| 忽略样本量最受限的一层 | 功效不足 | 按最严格那层估算 |
| 只用内部数据验证 | 循环验证 | 独立队列验证 |
| 把相关当因果 | 结论过强 | 说明证据等级 |
| 潜变量结果无法解释 | 临床无用 | 回到具体分子 |
| 未控制整合层面的多重检验 | 假阳性 | 分层 + 整合双重校正 |
| 缺少敏感性分析 | 结果不稳健 | 更换参数/方法复算 |
