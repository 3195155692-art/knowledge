# 液体活检与 cfDNA

> **一句话定位**：从**一管血**里获取肿瘤或其他组织来源的分子信息，用于基因分型、疗效监测、复发预警与早筛。它解决的核心问题是"取不到组织"与"需要反复取样"。
> **最大的认知门槛**：**阴性结果不能排除疾病**。血液里的信号量取决于肿瘤负荷与脱落程度，早期或低负荷患者的检出率天然偏低。

---

## 一、这项技术能回答什么问题

| 临床问题 | 用途 | 成熟度 |
| --- | --- | --- |
| 组织无法取材时的基因分型 | 靶向用药决策 | 已进入指南/常规 |
| 治疗后耐药机制 | 换药依据 | 部分癌种已进入指南 |
| 术后复发风险预警（MRD） | 辅助治疗决策、随访强化 | 快速进展，多癌种已有前瞻性证据 |
| 多癌种早筛 | 高危人群筛查 | 研究中，需谨慎解读 |
| 单癌种筛查（如结直肠癌） | 筛查 | 部分国家/地区已有批准产品 |
| 肿瘤起源不明 | 甲基化组织溯源 | 研究到早期临床 |
| 治疗疗效动态评估 | 分子层面的疗效指标 | 研究到临床过渡 |

## 二、基本原理

### 2.1 cfDNA 是什么

血浆中的游离 DNA（cfDNA）主要来自凋亡或坏死细胞释放的基因组片段，健康人主要来自造血细胞，**半衰期短（数十分钟到数小时）**，因此能反映"当下"的状态。肿瘤来源的那部分称为 **ctDNA**。

正常 cfDNA 片段长度集中在**约 167 bp** 附近并呈周期性分布；肿瘤来源片段的长度分布与断裂位点常有差异——这就是"片段组学"的基础。

### 2.2 检测的四类分子信号

| 信号 | 内容 | 典型用途 |
| --- | --- | --- |
| 点突变 | 肿瘤驱动基因变异 | 靶向用药基因分型 |
| 拷贝数 | 扩增/缺失 | 肿瘤负荷与耐药 |
| 甲基化 | 组织特异的甲基化模式 | 早筛、组织溯源 |
| 片段特征 | 片段长度、末端序列偏好 | 提高检测灵敏度与特异性 |

### 2.3 技术路线

| 路线 | 灵敏度量级 | 适用 |
| --- | --- | --- |
| 数字 PCR（ddPCR） | 约 0.1% 级别 | 已知单点突变的动态监测，成本低 |
| 靶向 NGS（带 UMI 的超深测序） | 0.1% 甚至更低 | 多基因分型、MRD 监测 |
| 低深度全基因组 | 依赖肿瘤负荷 | 拷贝数层面的监测 |
| 靶向甲基化测序 / WGBS | 与平台有关 | 早筛、组织溯源 |
| 全基因组甲基化 + 片段组学 | 与平台有关 | 多癌种早筛 |

### 2.4 由此决定的三条判读规则

1. **检出限决定阴性结果的含义。** 方法的检测限通常是 0.1% 甚至更低，但患者体内 ctDNA 占比可能低于检测限。所以"未检出"等于"低于方法检测限"，不等于"没有肿瘤"。
2. **克隆性造血是最重要的假阳性来源。** 随着年龄增长，造血细胞本身会携带体细胞突变（CHIP），这些突变会出现在血浆中并被误判为肿瘤突变。因此血浆检测报告必须评估或提示克隆性造血的可能。
3. **筛查人群的患病率决定阳性预测值。** 即使在健康人群中特异性达 99%，若该癌种患病率只有 0.1%，阳性结果中仍有相当比例是假阳性——这是早筛产品解读中最容易被忽略的数学事实。

## 三、方案怎么选

| 目的 | 推荐方案 | 理由 |
| --- | --- | --- |
| 已知单点突变的动态监测 | ddPCR | 便宜、快、灵敏度足够 |
| 需要同时看多个基因 | 靶向 NGS panel | 一次拿到多基因信息 |
| 术后 MRD 监测 | 高深度靶向 panel（含 UMI） | 需要低至 0.01%–0.1% 的检测限 |
| 多癌种早筛 | 甲基化 + 片段的平台化方案 | 需覆盖多组织来源信号 |
| 组织分型/起源判断 | 甲基化特征分析 | 组织特异性强 |
| 耐药机制探索 | 靶向 panel 或全外显子 | 需结合既往组织检测结果 |

## 四、样本与设计（决定成败的环节）

### 4.1 采血与处理

| 要点 | 要求 | 原因 |
| --- | --- | --- |
| 采血管 | 含保护剂的专用采血管；普通 K2EDTA 管需快速处理 | 白细胞破裂会释放大量基因组 DNA，稀释肿瘤信号 |
| 处理时间 | 越短越好，普通 EDTA 管建议数小时内完成血浆分离 | 同上 |
| 离心 | 建议两步离心（先分离血浆，再高速去残渣） | 减少细胞碎片污染 |
| 溶血 | 必须避免 | 溶血显著增加背景 DNA |
| 采血时间点 | 与治疗周期、肿瘤负荷对应记录 | 影响 VAF 的解读 |
| 保存 | −80 ℃，避免反复冻融 | 影响片段完整性 |

### 4.2 解读必须配套的临床信息

1. 肿瘤类型、分期、肿瘤负荷（影像可测量病灶）；
2. 当前治疗状态（用药、术后天数、放疗）；
3. 既往组织基因检测结果（判断血浆结果是否合理）；
4. 血液学指标（白细胞、乳酸脱氢酶等，用于评估克隆性造血可能）；
5. 采样时间点（纵向监测需固定时间点，如术后 4 周、此后每 3 个月）。

### 4.3 送检前必须问清楚的五个问题

1. 这项检测的**检测限**是多少？低于检测限的阴性结果如何表述？
2. 实验室是否有克隆性造血的评估或提示机制？
3. 采血管类型与运输时限要求是什么？我能否满足？
4. 阳性结果是否用第二种方法或组织样本确认过？
5. 阴性结果会如何影响我的临床决策？（避免用阴性结果排除疾病）

| 输出 | 内容 | 用途 |

## 六、标准分析流程

```
采血 → 血浆分离（两步离心）→ cfDNA 提取
  ↓ ① 文库构建（带 UMI，必要时加甲基化转换）
  ↓ ② 超深度测序
  ↓ ③ 去除背景噪声（UMI 一致性校正、背景错误模型）
  ↓ ④ 变异/甲基化信号识别（设定检测限与阈值）
  ↓ ⑤ 克隆性造血与污染评估
  ↓ ⑥ 临床解读（结合肿瘤负荷、治疗状态、既往结果）
  ↓ ⑦ 纵向比较与动态监测
```

| 步骤 | 关键点 |
| --- | --- |
| 血浆分离 | 时间与离心条件是质量的第一道门槛 |
| cfDNA 提取 | 提取量直接影响检测限 |
| UMI 校正 | 区分真实分子与 PCR、测序错误 |
| 阈值设定 | 实验室必须验证自身检测限并写入报告 |
| CHIP 评估 | 结合白细胞配对测序或生物信息学过滤 |
| 纵向解读 | 同一患者不同时间点需用同一方法比较 |

## 七、质量控制指标

| 指标 | 参考 | 异常含义 |
| --- | --- | --- |
| cfDNA 提取量 | 与采血量匹配 | 过低说明提取或运输问题 |
| 片段分布 | 应有 167 bp 附近的特征峰 | 峰偏移或高分子量污染提示白细胞裂解 |
| 基因组 DNA 污染比例 | 越低越好 | 高则稀释肿瘤信号 |
| 测序深度 | 按检测限要求设定 | 深度不足直接抬高检测限 |
| UMI 家族大小 | 反映分子多样性与深度 | 过小说明有效分子不足 |
| 背景错误率 | 低且稳定 | 高则假阳性增加 |
| 阳性/阴性对照 | 应通过 | 判断批次可靠性 |

## 八、结果怎么读（临床视角）

### 8.1 四个必须问的问题

1. **VAF 是多少？支持分子数多少？** 极低 VAF 需要更多独立分子支持才可信；
2. **与临床背景是否吻合？** 与影像、肿瘤标志物、治疗状态是否一致；
3. **是否可能是克隆性造血？** 尤其当检出的是血液系统常见突变基因、且与肿瘤类型无关时；
4. **这项结果会不会改变我的决策？** 不改变决策的检测，其临床价值需要重新评估。

### 8.2 阴性的正确表述

> "本检测未检出可报告的变异，代表血浆中肿瘤来源 DNA 低于本方法的检测限（0.1%）。不能据此排除疾病或残留病灶。"

用"未检出"而不是"阴性/无肿瘤"，是这一领域最基本也最重要的表述规范。

### 8.3 MRD 的解读逻辑

术后 ctDNA 阳性通常提示残留病灶风险高，与复发风险显著相关；但它提供的是**风险分层**，而不是"必须治疗"的直接依据。是否据此升级治疗，多数癌种仍在临床试验中回答。

### 8.4 早筛的解读逻辑

- **阳性**：需影像或其他检查确认，不能直接诊断；
- **阴性**：不能排除癌症，尤其不能排除早期病变；
- 评估早筛产品时，必须同时看**特异度、阳性预测值与目标人群的患病率**；只看"敏感度 90%"没有意义。

### 8.5 纵向监测的两个前提

1. 同一患者的所有时间点应用**同一方法、同一实验室**检测；
2. 结果变化需与治疗时间点、影像评估时间点对齐解释，避免把采样时间差异误读为疗效差异。

## 九、临床应用场景

### 9.1 靶向治疗基因分型（已进入指南）

当组织不可获得或取材风险高时，血浆检测可用于 EGFR 等驱动基因的分型，并用于耐药后的再分型。ESMO 等指南明确支持在特定场景使用血浆检测，并强调**血浆阴性时应尽可能再取组织**。

### 9.2 术后 MRD 与复发监测

在结直肠癌、肺癌、乳腺癌等癌种中，术后 ctDNA 状态与复发风险显著相关；前瞻性研究正在评估"以 ctDNA 指导辅助治疗"能否改善结局。临床使用要点：把它当作**风险分层工具**，结合病理分期与多学科讨论。

### 9.3 多癌种早筛

基于 cfDNA 甲基化的多癌种早筛已在前瞻性研究中评估（如 PATHFINDER 研究），结果显示可检出多种癌症并提示组织来源，但**阳性预测值受人群患病率限制，对早期肿瘤的敏感性仍有限**。目前适用于高危人群的研究性使用，不宜作为普筛手段。

### 9.4 单癌种筛查

以甲基化标志物为基础的结直肠癌血液筛查已在部分国家获批使用；其敏感性低于粪便免疫化学检测与结肠镜，通常用于不愿或无法接受其他筛查方式的人群。

### 9.5 组织溯源与研究性应用

cfDNA 甲基化可用于推断肿瘤原发组织来源，在"原发灶不明肿瘤"中有研究价值；片段组学等新特征仍在方法学发展阶段。

## 十、局限与常见陷阱

| 陷阱 | 错在哪 | 怎么避免 |
| --- | --- | --- |
| 把阴性当排除 | 检测限以下的肿瘤检不到 | 报告写明检测限与阴性含义 |
| 忽略克隆性造血 | 假阳性与误治 | 评估 CHIP，必要时白细胞配对测序 |
| 采血/运输不合规 | 白细胞 DNA 稀释肿瘤信号 | 严格按采血管与时限要求执行 |
| 用不同方法比较趋势 | 平台间结果不可比 | 同一患者固定方法与实验室 |
| 只看敏感度评估早筛 | 忽略特异度与患病率 | 结合 PPV 与目标人群患病率判断 |
| 用 ctDNA 直接指导治疗 | 多数癌种证据尚不充分 | 在临床试验或多学科框架内使用 |
| 采样时间点随意 | 结果被治疗周期干扰 | 固定时间点采样 |
| 忽略肿瘤异质性 | 单点突变未必代表全部病灶 | 结合组织检测与影像 |
| 把 VAF 当作肿瘤体积的精确度量 | VAF 受脱落率与清除率影响 | 仅作趋势参考 |
| 报告缺少对照与质控数据 | 无法判断可信度 | 只采信含质控信息的报告 |
