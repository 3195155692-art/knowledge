# 单细胞分析实操

> **一句话定位**：从 Cell Ranger 输出的表达矩阵，到细胞注释、差异分析与发表级图表的**可执行流程**。
> 原理、统计陷阱与解读边界见 [[04 单细胞分析]]；环境与目录规范见 [[14 生信分析环境与工作流基础]]。

## 一、数据从哪来

| 来源 | 你会拿到 | 注意 |
| --- | --- | --- |
| 自己做（10x） | Cell Ranger 输出的 `filtered_feature_bc_matrix`（barcodes/features/matrix 三个文件） | 保留 `raw` 与 `filtered` 两份，便于回溯 |
| 公司交付 | 常是 `.h5` 或表达矩阵 + 注释表 | 追问：用的什么版本、是否做过过滤 |
| 公共数据（GEO） | 矩阵（mtx/tsv）、`.h5`、`.h5ad` 或 `rds` 对象 | 核对物种、版本、是否已整合；样本分组信息要自己整理 |
| 其他平台 | BD Rhapsody、Smart-seq 等 | 分析参数与 10x 不同，不可照搬 |

```bash
  --fastqs=fastq/S1 --sample=S1 \

```

## 二、流程总览

```
表达矩阵（barcodes/features/matrix）
  ↓ ① 读入与合并（Seurat/Scanpy）
  ↓ ② 质控（nFeature、nCount、线粒体比例）与过滤
  ↓ ③ 双细胞识别
  ↓ ④ 标准化、高变基因、PCA
  ↓ ⑤ 批次整合（Harmony）
  ↓ ⑥ 聚类与 UMAP
  ↓ ⑦ 细胞注释（marker + 自动注释）
  ↓ ⑧ 差异表达（pseudobulk）与比例分析
  ↓ ⑨ 可视化和交付
```

## 三、可运行脚本骨架（Seurat）

```r
library(Seurat); library(tidyverse); library(harmony)

## 1. 读入：每个样本一个对象，再合并
dirs <- c("S1" = "data/S1/filtered_feature_bc_matrix",
          "S2" = "data/S2/filtered_feature_bc_matrix",
          "S3" = "data/S3/filtered_feature_bc_matrix")
obj_list <- lapply(names(dirs), function(s) {
  m <- Read10X(dirs[[s]])
  CreateSeuratObject(m, project = s, min.cells = 3, min.features = 200)
})
names(obj_list) <- names(dirs)

## 2. 合并（Seurat v5 用 add.cell.ids；v4 用 merge）
merged <- merge(obj_list[[1]], y = obj_list[-1], add.cell.ids = names(obj_list))

## 3. 记录样本与分组（分组信息必须来自样品表，不能靠猜）
meta <- read.delim("meta/sample_sheet.tsv", row.names = 1)
merged$group <- meta[merged$orig.ident, "group"]
merged$batch <- meta[merged$orig.ident, "batch"]

## 4. 质控指标
merged[["percent.mt"]] <- PercentageFeatureSet(merged, pattern = "^MT-")   # 人类用 MT-；小鼠用 mt-
VlnPlot(merged, features = c("nFeature_RNA", "nCount_RNA", "percent.mt"), ncol = 3)
plot1 <- FeatureScatter(merged, "nCount_RNA", "nFeature_RNA")
plot2 <- FeatureScatter(merged, "nCount_RNA", "percent.mt")

## 5. 过滤（阈值要按组织与数据分布决定，不要照抄教程）
merged <- subset(merged, subset = nFeature_RNA > 200 & nFeature_RNA < 6000 &
                   percent.mt < 15)

## 6. 标准化与高变基因
merged <- NormalizeData(merged) |> FindVariableFeatures(nfeatures = 2000) |>
          ScaleData() |> RunPCA()
ElbowPlot(merged, ndims = 50)     # 看拐点决定用多少个主成分

## 7. 批次整合（多个样本/芯片时必做）
merged <- RunHarmony(merged, group.by.vars = "batch")

## 8. 聚类与降维
merged <- FindNeighbors(merged, reduction = "harmony", dims = 1:20) |>
          FindClusters(resolution = 0.6) |> RunUMAP(reduction = "harmony", dims = 1:20)
DimPlot(merged, group.by = c("seurat_clusters", "group"))
```

## 四、质控阈值怎么定（不要照抄教程）

教程里常见的 `nFeature_RNA > 200 & percent.mt < 10` 只是起点。正确做法是按**数据分布**与**组织类型**决定：

| 指标 | 判断方式 | 注意 |
| --- | --- | --- |
| nFeature_RNA 下限 | 看分布左侧的"空液滴尾巴" | 一般 200–500；过低是空液滴 |
| nFeature_RNA 上限 | 分布右侧的长尾（多为双细胞） | 一般认为 >5000–6000 需警惕 |
| 线粒体比例 | 按组织设定 | 心肌、肝、肾等代谢活跃组织本身偏高，15% 一刀切会误删真实细胞 |
| nCount_RNA | 与基因数联动 | 单独设阈值意义有限 |
| 每样本细胞数 | 过滤后每样本剩多少？ | 某样本只剩几百个细胞时，该样本的组间比较不可靠 |

**MAD 法（比固定阈值更客观）**

```r
library(scater)
is_outlier <- function(x) (x < median(x) - 3 * mad(x)) | (x > median(x) + 3 * mad(x))
```

**报告要求**：质控阈值、过滤前后细胞数、每样本细胞数都必须写进论文，最好附过滤前后的分布图。

## 五、常见报错与坑

| 现象/报错 | 原因 | 解决 |
| --- | --- | --- |
| `cannot allocate vector of size ...` | 内存不足 | 降低维度或用 on-disk 方案（BPCells）；换大内存机器 |
| Seurat v5 报 layers 相关错误 | v5 与 v4 数据结构不同（多 assay layer） | 用 `JoinLayers()`；或全程统一版本 |
| 细胞名重复 / rownames 不唯一 | merge 时未加 `add.cell.ids` | 合并时加样本前缀 |
| 整合后 marker 被抹平 | 过度整合（维度用得太多） | 减少 `dims`，比较整合前后 marker |
| 聚类数异常多 | resolution 过高 | 调低 resolution，结合 marker 判断 |
| 自动注释结果不合理 | 参考数据集物种/组织不匹配 | 换参考，以 marker 人工核对为准 |
| 出现"新细胞类型"的簇 | 多为双细胞或环境 RNA | 先看双细胞分数与 marker 混杂程度 |
| `FindAllMarkers` 返回数千基因 | 未设阈值 | 设 `logfc.threshold`、`min.pct` |
| 组间差异"极显著" | 把细胞当独立样本 | 改用 pseudobulk |
| Python/R 对象互转失败 | 版本或字段不兼容 | 用 `.h5ad` + `sceasy`/`zellkonverter`，核对基因名格式 |
| 小鼠数据用 `^MT-` | 小鼠线粒体基因前缀是 `mt-` | 修改 pattern |
| 结果与上次不同 | 包版本或随机种子变化 | 固定环境与 `set.seed()` |

## 六、结果交付清单与自查

| 类别 | 内容 |
| --- | --- |
| 对象文件 | 最终 Seurat/AnnData 对象（含注释与降维坐标） |
| 细胞注释 | 每个细胞的类型标签 + marker 依据 |
| 质控记录 | 过滤前后细胞数、阈值、每样本细胞数 |
| 图 | UMAP（按 cluster/分组）、marker 点图、比例堆叠图、热图 |
| 统计结果 | pseudobulk 差异表、比例检验结果 |
| 方法段落 | 上下游软件版本、参数、阈值、统计单位 |

**自查清单**

- [ ] 每个样本的细胞数与分组是否记录？是否有生物学重复？
- [ ] 质控阈值是否按数据分布确定并报告？
- [ ] 是否做了双细胞识别？环境 RNA 是否评估？
- [ ] 批次与分组是否解耦？整合后 marker 是否未被抹平？
- [ ] 细胞注释是否有 marker 支持、自动注释是否人工复核？
- [ ] 组间差异是否用 pseudobulk（以样本为单位）？
- [ ] 细胞比例差异是否以样本为单位统计？
- [ ] 结论是否与流式/免疫组化/病理等正交证据一致？
- [ ] 方法与版本是否完整记录、脚本是否存档？
