# 基因组学（Genomics）

> **一句话定位**：基因组学测的是"一个人的全部 DNA 序列"，用来回答三个临床问题——这个人为什么得病（诊断）、该用什么药（用药指导）、会不会遗传给下一代（遗传咨询与产前）。
> **它不回答**：基因"开不开"（→ 转录组）、基因有没有被甲基化关闭（→ 表观组）、蛋白质与代谢物水平（→ 蛋白组 / 代谢组）。

---

## 一、这项技术能回答什么问题

| 临床问题 | 该选的检测 | 典型样本 | 周期与成本量级 |
| --- | --- | --- | --- |
| 罕见病/发育迟缓的病因诊断 | 染色体微阵列（CMA）、临床外显子组、全外显子组（WES） | 外周血（EDTA） | 3–6 周，数千元 |
| 已知致病基因的验证 | 靶向 Panel 或 Sanger | 外周血 | 1–2 周，数百至数千元 |
| 肿瘤靶向用药 | 肿瘤组织大 Panel（数十至数百基因） | 新鲜组织 / FFPE / 穿刺 | 1–3 周，数千至万元 |
| 免疫治疗适应证（MSI/MMR、TMB） | 组织 Panel，或免疫组化 + 分子检测 | FFPE | 1–2 周 |
| 遗传性肿瘤易感（BRCA 等） | 易感基因 Panel 或 WES | 外周血 | 2–4 周 |
| 用药前基因型（如卡马西平、别嘌醇） | 药物基因组学 Panel | 外周血 / 唾液 | 数天 |
| 胎儿染色体异常筛查 | 无创产前检测（NIPT，测孕妇血中 cfDNA） | 孕妇外周血 | 约 1 周 |
| 胎儿结构异常的确诊 | 羊水/绒毛的 CMA 或 WES | 侵入性取材 | 2–4 周 |
| 未知病原感染 | 病原宏基因组测序（mNGS） | 脑脊液 / 肺泡灌洗液 / 血 | 1–3 天 |
| 治疗后复发监测 | ctDNA 动态监测、MRD | 外周血 cfDNA | 1–2 周 |

## 二、基本原理（只讲判读必需的部分）

### 2.1 从 Sanger 到高通量

Sanger 法（1977）用双脱氧核苷酸终止链延伸，一次读一条序列，读长可达约 1000 bp，准确率 >99.9%，至今仍是**单基因验证的金标准**。它的短板是通量太低、成本太高，无法测全基因组。2005 年之后的高通量测序（NGS）把"一次测一条"变成"一次测数亿条"，成本下降了几个数量级，基因组学才真正走进临床。

### 2.2 二代测序（Illumina）的化学原理

核心是**边合成边测序（Sequencing by Synthesis, SBS）**，配合**可逆末端终止**：

1. **文库制备**：DNA 打断成 200–300 bp，末端修复加 A 尾，两端接上接头（含样本标签 Index，用于多样本混测）。
2. **成簇**：文库结合到流动池上的寡核苷酸，经**桥式 PCR** 把单条模板扩增成约千拷贝的克隆簇——目的是把信号放大到可被相机捕捉。
3. **逐碱基读取**：加入带荧光标记、且 3′ 端有可切除保护基团的 dNTP，每轮只允许掺入**一个**碱基，成像后切除保护基团，进入下一轮。
4. **判读**：每轮荧光颜色 → 一个碱基，同时输出该碱基的**质量分数**。

**长读长测序（PacBio、ONT）**不需要成簇，直接读单分子。它的价值不在"更准"，而在于能跨越重复序列、解析大片段结构变异，并可直读 DNA 甲基化。

### 2.3 三代平台对比

| 维度 | Sanger（一代） | Illumina（二代） | PacBio / ONT（三代） |
| --- | --- | --- | --- |
| 读长 | ~1000 bp | 50–300 bp | 10–100 kb+ |
| 通量 | 极低 | 极高 | 中高 |
| 原始准确率 | >99.9% | >99%（Q30 以上） | 85–95%；HiFi 共识序列可达 >99.9% |
| 最擅长 | 单点验证、重复扩增 | 变异检测、表达定量 | 结构变异、重复区域、甲基化直读 |
| 主要短板 | 成本高、通量低 | 读长短、GC 偏好 | 单读长错误率高、成本高 |

**当前主流是长短读长联用**：短读长保证深度与准确率，长读长解决重复序列和结构变异。

### 2.4 由原理决定的三条判读规则（重点）

这三条比任何算法都重要，直接决定"报告为什么是阴性"：

1. **深度决定能不能检出低丰度变异。** 若某变异只占 5%，100 条 reads 里只有约 5 条支持，落在随机波动范围内，极易漏检。所以胚系变异 ≥30× 通常足够，肿瘤组织突变常需 ≥500×，血浆 ctDNA 常需数千至上万×。**没有深度，就没有低丰度变异的可信度。**
2. **短读长读不透重复区域。** 短读长对结构变异、大片段缺失/重复，以及三核苷酸重复扩增病（脆性 X、亨廷顿病、强直性肌营养不良）**天然不可靠**，这类病需要长读长、Southern 印迹或 TP-PCR 等专门方法，不能凭一份 WES 报告排除。
3. **PCR 重复会造成假阳性。** 文库扩增中同一条模板被反复复制，会伪装成"多条 reads 支持"的变异。因此肿瘤检测普遍使用**分子标签（UMI）**来区分真实的独立分子与复制品。

## 三、检测方案怎么选

| 方案 | 覆盖范围 | 适合场景 | 主要取舍 |
| --- | --- | --- | --- |
| 靶向 Panel | 数十至数百个基因 | 已知病种、靶向用药 | 便宜快，覆盖范围外一律看不到 |
| 临床外显子组 | 约 2 万个基因的编码区 | 罕见病一线、遗传易感 | 性价比最高，但漏内含子变异与结构变异 |
| 全外显子组（WES） | 同上，偏科研设计 | 研究、疑难病例 | 数据可复用性好 |
| 全基因组（WGS） | 全部序列 | 疑难罕见病、结构变异、科研 | 最全，但贵且数据量大 |
| 长读长 | 全部序列且跨重复区 | 结构变异、重复扩增病、单倍型 | 成本高、生信要求高 |
| 染色体微阵列（CMA） | 全基因组拷贝数 | 发育迟缓/多发畸形一线、产前 | 只看拷贝数，不看点突变 |
| 单基因 Sanger | 单个基因 | 已知家系变异的验证 | 必做确证，不能当筛查 |

**决策顺序建议**：先明确临床问题 → 判断要看"点突变"还是"拷贝数/结构" → 再决定 Panel、外显子、WGS 还是 CMA。**先想清楚要排除什么，再选方案**，否则很容易测了一大堆、关键区域却没覆盖。

## 四、实验设计与样本要求

### 4.1 样本类型与要求

| 样本 | 关键要求 | 备注 |
| --- | --- | --- |
| 外周血 | EDTA 抗凝，忌肝素（抑制酶反应） | 胚系检测首选，室温 24–48 h 内处理 |
| 唾液 / 口腔拭子 | 防细菌污染 | 方便，但 DNA 质量波动大 |
| FFPE 组织 | 关注 DV200、片段化程度 | 临床最常用，但降解影响检出 |
| 新鲜 / 冷冻组织 | 液氮或 −80 ℃，避免反复冻融 | 肿瘤检测最佳 |
| 血浆 cfDNA | 专用保存管，避免溶血 | 需极高深度，注意采血时间与肿瘤负荷 |
| 骨髓 / 外周血（血液肿瘤） | 需与胚系对照区分 | 易混淆体细胞与胚系变异 |
| 干血片 | 新生儿筛查常规 | DNA 量少，需专门流程 |

### 4.2 送检前必须问清楚的五个问题

1. 我要回答的临床问题是什么？（诊断 / 用药 / 预后 / 遗传咨询）
2. 样本能支持这个深度和技术路线吗？（FFPE？cfDNA？DNA 量够吗？）
3. 需不需要配对对照？（肿瘤必须配正常对照，以区分体细胞与胚系变异）
4. 报告包含什么、不包含什么？（是否报告二次发现？是否涵盖结构变异？）
5. 出了阳性结果，谁做遗传咨询、谁做家系验证？

### 4.3 肿瘤检测的对照设置

肿瘤与正常对照配对，是区分**体细胞突变**（仅存在于肿瘤）与**胚系变异**（全身都有）的前提。无对照时只能做肿瘤-only 分析，会引入大量假阳性，尤其是克隆性造血相关变异。此外要关注**肿瘤纯度**：纯度低会把真实突变的 VAF 稀释到检测限以下。

### 4.4 伦理与知情同意

基因数据**终身不变、且牵涉家系**，与其他检验不可类比。送检前须明确：是否报告**二次发现**（与主诉无关但可干预的致病基因，参考 ACMG 二次发现清单）、数据如何存储与共享、以及阳性结果对亲属的提示义务。知情同意与结果沟通应由遗传咨询师或受过培训的临床医师参与。

## 五、数据产出与文件格式

| 格式 | 是什么 | 谁需要看 |
| --- | --- | --- |
| FASTQ | 原始 reads 及每个碱基的质量分 | 生信分析起点 |
| BAM / CRAM | 比对到参考基因组的结果（CRAM 为压缩版） | 查看覆盖度、IGV 可视化 |
| VCF / gVCF | 变异清单（gVCF 记录每个位置的证据） | 变异解读的核心文件 |

| BED / SEG | 目标区域、拷贝数区段 | 覆盖度评估、CNV 结果 |
| PDF 报告 | 临床可直接使用的最终产物 | 临床医师 |

## 六、标准分析流程

```
原始数据 FASTQ
   ↓ ① 质控与修剪（FastQC + fastp）
   ↓ ② 比对到参考基因组（BWA-MEM / minimap2）
   ↓ ③ 排序、标记重复（samtools、GATK MarkDuplicates）
   ↓ ④ 碱基质量校正（BQSR）
   ↓ ⑤ 变异检测（HaplotypeCaller / Mutect2 / DeepVariant）
   ↓ ⑥ 过滤（VQSR 或硬过滤）
   ↓ ⑦ 注释（VEP / SnpEff / ANNOVAR）
   ↓ ⑧ 人工审核与解读（IGV + 数据库比对 + ACMG 分级）
最终临床报告
```

| 步骤 | 目的 | 常用工具 | 关键点 |
| --- | --- | --- | --- |
| ① 质控 | 去掉接头与低质量碱基 | FastQC、fastp、Trimmomatic | Q30 比例、接头污染、GC 分布 |
| ② 比对 | 把 reads 放回参考基因组位置 | BWA-MEM（短读长）、minimap2（长读长） | 参考基因组版本须与报告一致（如 GRCh38） |
| ③ 去重 | 去除 PCR 复制品 | GATK MarkDuplicates | 肿瘤样本需评估 UMI |
| ④ 校正 | 修正测序系统性偏差 | GATK BQSR | 大规模队列中可省略 |
| ⑤ 变异检测 | 找出与参考序列的差异 | GATK HaplotypeCaller（胚系）、Mutect2（体细胞）、DeepVariant、CNVkit（拷贝数）、Manta/DELLY（结构变异） | 不同变异类型必须用不同工具 |
| ⑥ 过滤 | 压掉假阳性 | GATK VQSR 或硬过滤 | 小样本时 VQSR 不可靠，改用硬过滤 |
| ⑦ 注释 | 给变异贴功能标签 | VEP、SnpEff、ANNOVAR | 数据库版本要写进报告 |
| ⑧ 解读 | 判定致病性 | ClinVar、gnomAD、ClinGen、OMIM + 人工审核 | 机器不能替代这一步 |

### 关键参数怎么读

| 参数 | 含义 | 判读意义 |
| --- | --- | --- |
| VAF（变异等位基因频率） | 支持变异的 reads 占总 reads 比例 | 胚系约 50% 或 100%；体细胞随纯度变化；极低值需排除噪音 |
| 支持 reads 数 | 有多少条独立分子支持 | 少于 3–5 条时不可轻信 |
| 深度 | 该位点总覆盖 | 决定检测限 |
| 链偏倚 | 变异是否只出现在一条链上 | 明显偏倚提示假阳性或建库异常 |
| 比对质量 | reads 是否唯一匹配 | 低质量区域（重复、同源）结果不可靠 |

## 七、质量控制指标

| 环节 | 指标 | 常用阈值 | 不达标怎么办 |
| --- | --- | --- | --- |
| 测序 | Q30 比例 | ≥85%（多数平台可 >90%） | 联系实验室评估是否重测 |
| 比对 | 比对率 | 通常 >95% | 检查参考基因组版本、接头残留 |
| 文库 | 重复率 | 视深度而定，过高提示起始量不足 | 增加起始 DNA 量或文库复杂度 |
| 覆盖 | 目标区域平均深度 | 胚系 WGS ≥30×、WES ≥100×、肿瘤 panel ≥500×、ctDNA 数千× | 补测或改用更小 Panel |
| 覆盖 | 均一性：≥10× 覆盖的目标区域比例 | 一般目标 ≥95% | 排查 GC 极端区域与捕获效率 |
| 污染 | 样本间/交叉污染估计 | 越低越好 | 异常即报警并重新取样 |
| 身份 | 性别一致性、基因型指纹 | 必须与送检信息一致 | 提示样本错配，立即停检核查 |
| 肿瘤 | 纯度与倍性估计 | 纯度低需说明检测限受限 | 报告中注明低纯度带来的局限 |

## 八、结果怎么读（临床视角）

这一节是全篇重点：**一份基因报告的价值几乎全部取决于对变异的解读，而非测序本身。**

### 8.1 变异怎么命名

采用 HGVS 规范：`c.` 表示编码 DNA 层面（如 `c.1521_1523del`），`p.` 表示蛋白层面（如 `p.Glu508del`）。报告应同时给出转录本编号（如 NM_xxxx），因为**同一基因存在多个转录本，命名可能不同**——核对转录本号是读报告的第一步。

### 8.2 致病性五级分类（ACMG/AMP 标准）

| 分级 | 含义 | 临床怎么用 |
| --- | --- | --- |
| 致病（Pathogenic） | 证据充分支持致病 | 可用于临床决策 |
| 可能致病（Likely Pathogenic） | 证据较强但未达致病 | 结合表型，多数可用于决策 |
| **意义未明（VUS）** | **证据不足，无法判定** | **不得据此做临床决策或产前诊断** |
| 可能良性（Likely Benign） | 证据偏向良性 | 一般不作为病因解释 |
| 良性（Benign） | 证据充分支持良性 | 不作为病因解释 |

分级依赖一套**证据条目**：致病性证据（PVS1、PS1–4、PM1–6、PP1–5）与良性证据（BA1、BS1–4、BP1–7）。临床医师不需要背下全部条目，但要知道三点：

- 证据是**组合加权**的，单条证据通常不足以定级；
- 功能证据、人群频率证据、家系共分离证据都可纳入；
- 结论会随证据更新而**改变**（某 VUS 后来可能被重分类为致病），因此报告需要定期复核。

### 8.3 拷贝数变异（CNV）的解读

CNV 采用 ClinGen **评分制**：把剂量敏感性、病例证据、家系证据等逐项计分求和——总分 ≥0.99 判为致病，0.90–0.98 为可能致病，−0.89 至 0.89 为意义未明，≤−0.99 为良性。染色体微阵列（CMA）在发育迟缓/智力障碍/多发畸形中是一线检测。

### 8.4 一份合格报告应包含什么

样本与患者信息、检测方法与**检测范围及局限**、参考基因组版本、覆盖度与质控数据、变异列表（HGVS 命名、转录本号、VAF、深度）、致病性分级与证据、人群频率与已有报道、临床意义与用药建议、参考文献、报告医师与实验室资质（如 ISO 15189 认可情况）。**缺少"局限"章节的报告，判读时应更保守。**

### 8.5 遇到 VUS 的正确处理

1. 不用它做诊断、产前诊断或用药决策；
2. 检测家系携带情况，获取分离证据；
3. 关注功能研究进展与数据库更新，必要时随访重分析——**对旧数据重新分析是提高诊断率最经济的手段**；
4. 向患者如实说明"目前不确定"，而不是含糊地讲成"有问题"。

### 8.6 二次发现

在明确知情同意的前提下，可按 ACMG 二次发现清单（SF v3.2）报告与主诉无关但**可干预**的致病变异（如遗传性肿瘤易感、遗传性心血管病、恶性高热易感）。这不是"多出来的麻烦"，而是可预防的临床收益。

### 8.7 体细胞报告要多看什么

除变异本身，还要看：**VAF 与深度**（是否在可靠检测限内）、**肿瘤纯度与拷贝数**（缺失型变异会被低估）、**用药证据等级**（ESCAT、OncoKB 等按证据强弱分级，从已批准适应证到仅有病例报道）、**TMB 与 MSI 状态**（免疫治疗适应证；TMB-H 常以 ≥10 mut/Mb 为门槛，但不同平台需先做标准化验证）、**是否牵出胚系易感基因**（需单独遗传咨询）。

### 8.8 最容易读错的三条规则

1. **阴性不等于排除。** 写"未检出致病变异"，可能只是检测范围或深度不覆盖。
2. **VUS 不是"可疑致病"。** 它意味着证据不足，不能当结论用。
3. **体细胞阳性也可能牵出胚系问题。** BRCA1/2、TP53 等基因在肿瘤样本中检出时，需考虑胚系验证。

## 九、临床应用场景（均附指南或标准支撑）

### 9.1 罕见遗传病的病因诊断

发育迟缓 / 智力障碍 / 多发畸形：CMA 为一线；阴性者进一步做 WES/WGS。这一步的关键是**表型术语标准化**（HPO 词条），它直接影响变异解读的准确性——临床信息写得越清楚，解读越准。

### 9.2 肿瘤

- **靶向用药**：大 Panel 检测驱动基因（EGFR、ALK、KRAS、BRCA 等），按 NCCN/ESMO 推荐选药；
- **免疫治疗**：MSI/MMR 状态与 TMB（TMB 只能在经过标准化验证的平台间比较）；
- **遗传易感**：BRCA1/2（乳腺癌/卵巢癌）、MMR 基因（林奇综合征）、TP53（Li-Fraumeni）等，阳性者转入遗传咨询与家系检测。

### 9.3 药物基因组学（PGx）

按 CPIC 指南执行基因型指导用药，临床高频例子：CYP2C19 与氯吡格雷、CYP2D6 与可待因/他莫昔芬、DPYD 与氟尿嘧啶/卡培他滨（严重毒性风险）、TPMT/NUDT15 与硫唑嘌呤、HLA-B*15:02 与卡马西平、HLA-B*57:01 与阿巴卡韦、CYP2C9/VKORC1 与华法林、SLCO1B1 与他汀。**这类检测临床价值最直接，也最容易落地。**

### 9.4 产前与生殖

- **NIPT**：检测孕妇血浆中胎盘来源 cfDNA，用于 21/18/13 三体筛查。它是**筛查**不是诊断，阳性需侵入性检查确诊；对微缺失与单基因病的筛查性能有限。
- **产前诊断**：羊水/绒毛 CMA 为一线；超声结构异常而 CMA 阴性时可行 WES。
- **携带者筛查**：脊髓性肌萎缩（SMN1）、囊性纤维化（CFTR）、脆性 X（FMR1）等，用于备孕与孕期人群。

### 9.5 感染病原诊断

病原宏基因组测序（mNGS）直接从临床标本中检出核酸序列，对脑膜炎/脑炎、免疫抑制患者不明发热等场景意义重大，尤其适用于培养阴性、经验性治疗无效者。解读难点在于区分致病菌、定植菌与环境背景污染。

### 9.6 液体活检与复发监测

血浆 ctDNA 可反映肿瘤的时空异质性，用于无法取材患者的基因分型、耐药机制监测与术后 MRD 评估。临床需注意：**阴性结果受肿瘤负荷与检出限限制**，不能直接等同于无病。

## 十、局限与常见陷阱

| 陷阱 | 错在哪 | 怎么避免 |
| --- | --- | --- |
| 把 VUS 当诊断 | 证据不足却用于决策或产前诊断 | 严格按 ACMG 分级，仅致病/可能致病可用于决策 |
| 阴性就排除 | 检测范围与深度有限 | 报告中明确写出覆盖范围与检测限 |
| 忽略低深度 | 低丰度突变被漏检 | 提高深度或改用带 UMI 的方法 |
| 用 WES 排除结构变异与重复扩增病 | 短读长技术盲区 | 明确列出阴性结果不含盖的范围 |
| 忽视人群频率 | 罕见良性变异被误判致病 | 查 gnomAD 频率并考虑族裔背景 |
| 组织"特异性"被过度解释 | 组织混样导致细胞比例变化 | 需去卷积或结合病理评估 |
| 样本错配 | 结果完全不可用 | 必做基因型指纹与性别核对 |
| 胚系 / 体细胞混淆 | 遗传风险判断错误 | 肿瘤必配正常对照 |
| 忽略克隆性造血 | 血细胞来源变异被当成肿瘤突变 | 结合对照样本、年龄与血液学指标 |
| 报告缺少资质与局限说明 | 无法评估结果可信度 | 只采信标注方法、阈值与局限的报告 |
| 不做遗传咨询 | 家系风险被忽略 | 阳性结果一律转入咨询流程 |

## 十三、术语速查

| 术语 | 含义 |
| --- | --- |
| 胚系变异 | 来自父母、全身细胞都携带，可遗传 |
| 体细胞变异 | 仅存在于肿瘤等特定组织，一般不遗传 |
| VAF | 变异等位基因频率，支持变异的 reads 占比 |
| VUS | 意义未明变异，证据不足无法定级 |
| CNV | 拷贝数变异（片段缺失或重复） |
| SV | 结构变异（大片段倒位、易位、缺失等） |
| TMB | 肿瘤突变负荷，每兆碱基的突变数量 |
| MSI | 微卫星不稳定性，常提示错配修复功能缺陷 |
| ctDNA | 血浆中来自肿瘤的游离 DNA |
| cfDNA | 血浆游离 DNA，含正常与肿瘤来源片段 |
| MRD | 微小残留病灶，治疗后残存肿瘤的分子证据 |
