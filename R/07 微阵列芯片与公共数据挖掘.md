# 微阵列芯片与公共数据挖掘

> **一句话定位**：微阵列（芯片）在**科研**中基本已被测序取代，但它仍然是临床里**实实在在还在用**的技术（染色体微阵列是发育异常的一线诊断），同时 GEO 里积累的海量芯片数据是临床研究者**成本最低的研究起点**。
> **本页解决两个问题**：① 芯片在临床还有哪些不可替代的用处；② 如何规范地把公共数据用在自己的研究里而不翻车。

---

## 一、这项技术能回答什么问题

| 场景 | 芯片能做 | 为什么要用它 |
| --- | --- | --- |
| 发育迟缓/智力障碍/多发畸形的病因诊断 | 全基因组拷贝数检测（染色体微阵列） | 指南推荐的一线检测，检出率高于核型分析 |
| 产前超声异常 | 拷贝数检测 | 指南推荐在核型分析基础上或作为一线使用 |
| 肿瘤拷贝数与杂合性缺失 | SNP 芯片 | 提供拷贝数与杂合性缺失/单亲二体信息 |
| 大样本表达谱比较 | 表达芯片 | 成本低、批次稳定，适合万人级队列 |
| 甲基化谱 | 甲基化芯片 | 表观组主流平台 → [[03 表观组学]] |
| 公共数据再挖掘 | GEO/ArrayExpress | 零成本获取已发表研究的原始数据 |
| 新研究的数据来源 | 公共数据 | 用于发现阶段、构建假设、外部验证 |

## 二、基本原理

### 2.1 探针杂交

芯片的核心逻辑是：**把已知序列的探针固定在固相表面，让标记过的样本核酸与之杂交，用荧光强度反映丰度或基因型**。

- 表达芯片：探针针对转录本，荧光强度 ≈ 表达量；
- SNP 芯片：探针针对特定变异位点，可同时判断基因型与拷贝数；
- 比较基因组杂交芯片（CMA）：样本与对照竞争杂交，用信号比值判断拷贝数增减。

### 2.2 类型与用途

| 类型 | 检测对象 | 临床/科研用途 |
| --- | --- | --- |
| 表达谱芯片 | mRNA 丰度 | 差异表达、分子分型、公共数据挖掘 |
| SNP 芯片 | 基因型、拷贝数、杂合性缺失 | 遗传关联、肿瘤拷贝数、血型/药物基因分型 |
| 甲基化芯片 | CpG 位点甲基化 | 表观分型、早筛标志物 |
| 比较基因组杂交芯片（CMA） | 全基因组拷贝数 | **临床一线遗传诊断** |

### 2.3 由此决定的三条判读规则

1. **芯片只测"预设的探针"**，未设计探针的位点一律看不到——这是它与测序最本质的区别；
2. **探针到基因的映射是解释的第一步也是错误高发区**：一个基因对应多个探针、一个探针可能匹配多个基因，映射规则不同结论就会不同；
3. **芯片是相对信号**，不同平台、不同批次之间的绝对强度不可直接比较，必须归一化后才能谈"差异"。

## 三、方案怎么选：芯片还是测序

| 需求 | 推荐 | 原因 |
| --- | --- | --- |
| 全基因组拷贝数（临床诊断） | CMA | 指南推荐、成熟稳定、成本低、报告周期短 |
| 点突变/小片段变异 | 测序 | 芯片分辨率不足 |
| 大样本（数千上万例）表达谱 | 芯片或 3′ 测序 | 芯片批次稳定；测序覆盖更广 |
| 新转录本、融合基因、异构体 | 测序 | 芯片无法胜任 |
| 甲基化谱（大样本） | 甲基化芯片 | 性价比高 |
| 未知病原/新物种 | 测序 | 芯片需要预设探针 |

**结论**：**临床诊断用 CMA，科研发现用测序，超大队列可以用芯片控制成本。**

## 四、实验设计与公共数据选择

### 4.1 自己产生数据时的要点

- 同批样本必须同一平台、同一试剂批次；
- 芯片批次必须与分组解耦；
- 保留原始文件（CEL/IDAT），否则后续无法重新归一化；
- 保存完整临床注释（年龄、性别、分期、治疗、随访）。

### 4.2 公共数据（GEO 等）筛选清单

下载数据集前，逐条核对：

| 核对项 | 为什么重要 |
| --- | --- |
| 平台型号是否统一 | 跨平台合并会引入系统误差 |
| 样本量是否足够 | 决定统计功效 |
| 分组定义是否明确 | 定义模糊会导致错误标签 |
| 临床注释是否完整 | 缺随访就无法做预后分析 |
| 是否提供原始数据（CEL/IDAT） | 有原始数据才能自主预处理 |
| 是否有批次信息 | 无法校正批次时会与分组混杂 |
| 是否有配对样本 | 配对设计需要专门模型 |
| 是否有本人/他人在同一数据集发表过结论 | 避免重复与"数据重复使用"争议 |

### 4.3 使用公共数据的伦理与规范

- 遵守数据库的使用条款与数据访问协议；
- 高敏感数据（如受控访问的基因型数据）需按流程申请；
- **不得用同一数据集既建模又"验证"**，这是最常被审稿人指出的问题；
- 引用数据集应给出 GEO 编号与原始文献。

## 五、数据产出与文件格式

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| CEL / IDAT / GPR | 芯片原始信号文件 | 归一化的输入，**必须保留** |
| Series Matrix（GEO） | 已归一化的表达矩阵 + 样本信息 | 快速分析起点（但无法重做预处理） |
| TXT / CSV 表达矩阵 | 探针 × 样本的强度值 | 统计分析输入 |
| beta 值矩阵（甲基化） | 甲基化水平 | → [[03 表观组学]] |
| 拷贝数片段文件 | 拷贝数区段 | CMA 报告 |

## 六、标准分析流程

```
原始文件（CEL / IDAT）
  ↓ ① 读取与质控
  ↓ ② 归一化（RMA / 分位数归一化）与背景校正
  ↓ ③ 探针过滤与注释（探针 → 基因映射）
  ↓ ④ 批次校正（ComBat 等，必要时）
  ↓ ⑤ 差异分析（limma）
  ↓ ⑥ 功能富集与聚类
  ↓ ⑦ 模型构建与验证（训练集 / 内部验证 / 外部验证）
```

| 步骤 | 目的 | 常用工具 | 关键点 |
| --- | --- | --- | --- |
| 读取与质控 | 评估芯片质量 | affy、lumi、arrayQualityMetrics | 看归一化前后分布与离群样本 |
| 归一化 | 消除技术与批次影响 | RMA、分位数归一化 | 同一分析中的样本必须一起归一化 |
| 探针注释 | 把探针映射到基因 | Bioconductor 注释包、官方注释文件 | 映射规则必须写进方法 |
| 批次校正 | 去除批次效应 | ComBat、sva | 只在批次与分组不混杂时使用 |
| 差异分析 | 找差异基因 | limma | 芯片数据用 limma，不用 t 检验 |
| 模型与验证 | 建立并检验标志物/模型 | 交叉验证、独立队列 | 报告 AUC 置信区间与校准度 |

### 关键参数怎么读

| 参数 | 含义 | 判读意义 |
| --- | --- | --- |
| 归一化后表达值 | 对数尺度强度 | 只看相对高低，不看绝对值 |
| log2FC | 组间倍数变化 | 结合效应量与置信区间 |
| 校正后 P 值 | 多重检验校正结果 | 必须报告 |
| 检测 P 值（illumina） | 该探针信号是否可靠 | 过低说明信号接近背景 |
| AUC 及置信区间 | 模型判别能力 | 需外部验证才有临床意义 |

## 七、质量控制指标

| 指标 | 参考 | 异常含义 |
| --- | --- | --- |
| 归一化前后箱线图分布 | 应整齐对齐 | 归一化失败或样本降解 |
| 芯片内与芯片间相关性 | 同组样本应高相关 | 批次或质量问题 |
| PCA / 层次聚类 | 应主要按分组聚集 | 按批次聚集说明批次效应主导 |
| RNA 降解曲线 | 应平缓 | 样本降解 |
| 背景信号与检测 P 值 | 背景低、检测 P 值低 | 信号弱 |
| 性别核查（X/Y 基因表达） | 必须与临床信息一致 | 样本错配 |
| 离群样本判断 | 结合技术指标而非只看聚类 | 盲目删除会造成偏倚 |

## 八、结果怎么读（临床视角）

### 8.1 公共数据挖掘的四类常见错误

1. **过拟合**：特征数远多于样本量时，任何分类器都能"完美分类"。→ 必须交叉验证，并有独立外部验证；
2. **循环验证**：用同一数据集筛选标志物又报告其 AUC。→ 需另找队列验证；
3. **忽略批次**：不同中心的数据直接合并。→ 需校正或做分层分析；
4. **临床信息错误**：分组标签来自二手整理，定义与原文不一致。→ 回到原始文献核对。

### 8.2 预后/诊断模型该怎么报告

临床预测模型有专门的报告规范：**TRIPOD**（预测模型报告规范）与 **STARD**（诊断准确性研究），偏倚风险评估可用 **PROBAST**。一个合格的模型报告至少包含：人群与纳排标准、变量定义、缺失值处理、样本量依据、内部与外部验证结果、判别能力（AUC 与置信区间）、校准度、以及临床可用性讨论。

### 8.3 拷贝数结果怎么读

- 报告需给出**片段大小、基因组坐标、含有的基因（尤其是剂量敏感基因）、致病性分级与证据**；
- 判定依据 ClinGen 评分体系（见 [[01 基因组学]]）；
- **意义未明的拷贝数变异不要用于临床决策**，应结合表型、家系检测与随访；
- 需注意平台分辨率（不同芯片能检出的最小片段不同），报告须写明检出限。

### 8.4 芯片结果与测序结果不一致怎么办

优先考虑三点：**检测范围不同**（芯片只测探针覆盖区）、**分辨率不同**（芯片难以发现小片段）、**验证方法不同**（确证应采用正交方法，如定量 PCR、MLPA 或测序）。临床上以**正交方法确证**为准。

## 九、临床应用场景

### 9.1 染色体微阵列（CMA）——芯片技术在临床的核心阵地

- **适应证**：发育迟缓/智力障碍、孤独症谱系、多发先天畸形、不明原因生长障碍；
- **地位**：指南推荐为**一线检测**，检出率显著高于传统核型分析；
- **产前**：超声结构异常时推荐拷贝数检测；核型正常但超声异常者，CMA 可额外检出致病性拷贝数变异；
- **报告要素**：平台与分辨率、片段坐标与大小、致病性分级、遗传方式与再发风险、后续建议（家系验证、遗传咨询）。

### 9.2 肿瘤

SNP 芯片可同时给出拷贝数与杂合性缺失信息，用于部分血液肿瘤与实体瘤的辅助诊断与预后分层；临床上更多与测序、FISH、核型分析互补使用。

### 9.3 其他仍在使用芯片的场景

药物基因组学与血型基因分型、HLA 相关分型、部分遗传病靶向探针检测，均属于"预设位点、固定 panel"的检测思路，其稳定性与成本优势在特定场景仍不可替代。

### 9.4 公共数据再挖掘（临床研究者最高性价比的路径）

典型的三段式做法：**GEO 或 TCGA 做发现 → 自家小样本队列做验证 → 结合临床随访做预后分析**。要点是把公共数据当"发现工具"，而不是把公共数据的内部验证当"外部验证" → 详见 [[12 公共数据库与资源速查]] 与 [[11 临床研究设计与统计要点]]。

## 十、局限与常见陷阱

| 陷阱 | 错在哪 | 怎么避免 |
| --- | --- | --- |
| 用同一数据集建模又验证 | 循环论证 | 独立外部验证队列 |
| 未保留原始文件 | 无法重新归一化 | 保存 CEL/IDAT |
| 探针注释混乱 | 基因层面结论错误 | 统一注释规则并写明 |
| 跨平台直接合并 | 系统误差被当差异 | 分别归一化后校正，或分层分析 |
| 忽略样本量 | 结论不稳定 | 事先做功效估算 |
| 忽略批次混杂 | 批次被当生物学差异 | 校正或分层 |
| 把意义未明拷贝数当结论 | 临床决策错误 | 按 ClinGen 分级处理 |
| 忽略平台分辨率 | 漏检小片段 | 报告中写明检出限 |
| 只看 AUC 不看校准度 | 预测概率不可用 | 报告校准曲线 |
| 公共数据重复使用 | 学术争议 | 遵守数据使用条款并规范引用 |

## 十三、术语速查

| 术语 | 含义 |
| --- | --- |
| 探针 | 固定在芯片上的已知序列，用于捕获目标核酸 |
| CEL / IDAT | 不同平台的原始信号文件 |
| 归一化 | 消除芯片间技术差异的处理 |
| 检测 P 值 | 探针信号是否高于背景的统计量 |
