# 单细胞分析（Single-cell Analysis）

> **一句话定位**：单细胞测序把"一块组织"拆成"一个一个细胞"来分析，回答 bulk 数据回答不了的问题——**到底是哪一类细胞在变化，还是所有细胞的平均水平在变化**。
> **代价**：每个细胞的测序深度很浅（大量基因测不到，即"dropout"），技术噪音大，成本高，分析复杂度远高于 bulk。
> **它不回答**：单个细胞的空间位置（→ [[08 空间组学]]）、蛋白质与代谢物水平（需多组学或蛋白组方法）。

---

## 一、这项技术能回答什么问题

| 临床/科学问题 | 单细胞给出的答案 | 备注 |
| --- | --- | --- |
| 肿瘤微环境由哪些细胞构成？ | 细胞类型与状态图谱、比例 | 最成熟的临床应用方向 |
| 哪些 T 细胞处于耗竭状态？ | 耗竭相关基因程序与克隆信息 | 与免疫治疗响应相关 |
| 治疗前后细胞组成如何变化？ | 配对样本的细胞比例与状态变化 | 需要生物学重复才能做统计 |
| 肿瘤细胞有没有不同克隆？ | 单细胞层面的拷贝数推断 | 需与 DNA 数据交叉验证 |
| 组织里的"上调基因"来自哪种细胞？ | 直接定位到细胞类型 | 解决 bulk 的细胞比例混淆问题 |
| 发育/分化轨迹是怎样的？ | 拟时序轨迹 | 属于假设生成，不是因果证明 |
| 细胞之间如何通讯？ | 配体-受体预测 | **只是计算预测，需实验验证** |

## 二、基本原理

### 2.1 三种主流分液方式

| 方式 | 原理 | 特点 |
| --- | --- | --- |
| **微流控液滴**（10x Genomics 为主） | 细胞与凝胶珠在油相中形成液滴，每个液滴内一条带条码的珠子捕获 mRNA | 通量最高、最主流 |
| **微孔板/纳米孔**（如 BD Rhapsody） | 细胞沉入带条码的微孔 | 细胞捕获温和，适合脆弱细胞与靶向 panel |
| **组合索引**（SPLiT-seq 等） | 多轮条码连接，无需分液设备 | 成本低，适合固定样本，但效率与商业化程度较低 |

### 2.2 建库：3′ 还是 5′

- **3′ 建库**：只读转录本 3′ 端，定量最稳、最常用；
- **5′ 建库**：用于捕获 T/B 细胞受体的可变区序列，做**免疫组库分析**（克隆型、克隆扩增）；
- **多组学建库**：同一细胞内同时读转录组与表面蛋白（CITE-seq，用带条码的抗体）、或同时读转录组与染色质可及性（Multiome）。

### 2.3 由此决定的三条判读规则

1. **每个细胞的深度很浅。** 一个细胞只能捕获到几千个基因，**基因"没测到"不等于"不表达"**。因此单个细胞的表达值不能当定量结果，只有把同类细胞聚合起来看才有统计意义。
2. **统计单位是"样本"，不是"细胞"。** 同一个供体的 5 000 个细胞不是 5 000 个独立样本。把细胞当独立观测单位做检验，会得到大量假阳性——这是单细胞分析中最严重的统计错误（见第 8 节）。
3. **批次来自"芯片/上机批次"。** 不同芯片、不同天、不同操作者都构成批次，且通常与分组混杂，必须在设计阶段就随机化。

## 三、技术方案怎么选

| 方案 | 适用场景 | 取舍 |
| --- | --- | --- |
| 10x 3′ 转录组 | 细胞图谱、微环境、状态分析 | 最通用、性价比最高 |
| 10x 5′ + V(D)J | 免疫组库、克隆型、CAR-T | 多了克隆信息，成本上升 |
| CITE-seq（转录组 + 蛋白） | 需要精确免疫分型 | 分型更准，但抗体panel成本高 |
| 单细胞 Multiome（RNA + ATAC） | 调控机制 | 数据量大，分析复杂 |
| 单核测序（snRNA-seq） | 冻存组织、实体瘤、脑 | 适合难解离组织，但丢失胞质 RNA |
| 靶向 panel 单细胞 | 固定基因集、临床转化 | 灵敏度高但范围固定 |
| 单细胞甲基化/多组学 | 表观异质性 | 通量低，尚在研究阶段 |

**关键选择原则**：先想清楚是"要发现新细胞类型"（需要深覆盖）还是"要可靠地比较已知细胞类型的比例"（需要更多细胞数与更多供体）。**前者靠深度，后者靠样本量。**

## 四、实验设计与样本要求

### 4.1 样本与解离

| 样本 | 要点 | 风险 |
| --- | --- | --- |
| 新鲜组织 | 快速解离，控制在最短时间 | 长时间酶解会诱导应激基因（如 FOS、JUN、HSP） |
| 冻存组织 | 优先做单核测序 | 冻存破坏细胞膜，难解离成单细胞 |
| 血液/骨髓 | 尽快处理 | 常温放置会显著改变表达谱 |
| 类器官/细胞系 | 状态与传代一致性 | 与体内差异需谨慎外推 |

**必查的样本指标**：细胞活性（一般要求 >80–90%）、结团率（越低越好）、细胞浓度。活性差会引入大量死细胞/环境 RNA 噪音。

### 4.2 设计要点

1. **生物学重复优先于细胞数。** 想比较两组差异，每组至少 3 个供体/动物；把 10 万个细胞都来自一个供体，只是把一个样本测得更深，**推不出组间差异**。
2. **批次与分组解耦。** 对照组与实验组要分散到不同芯片上混着做，不能"对照组一个芯片、实验组一个芯片"。
3. **多路混样（multiplexing）可显著降低批次效应**：用带条码的抗体或基因型拆分，把多个样本放进同一芯片。
4. **上样量决定双细胞率**：上样越多，双细胞比例越高，需靠算法识别并剔除。
5. **目标细胞数**：常见每个样本 1 000–10 000 个细胞；稀有细胞类型需要更多总量。

### 4.3 送检前必须问清楚的五个问题

1. 我要找新细胞类型，还是比较已知细胞的比例变化？（决定深度与细胞数）
2. 有几个供体/生物学重复？分组是否与芯片批次解耦？
3. 样本能解离成高质量单细胞吗？只能冻存的话要不要改单核测序？
4. 需不需要免疫组库（5′ + VDJ）或表面蛋白（CITE-seq）？
5. 分析出的差异，用什么独立方法验证？（流式、免疫组化、bulk 数据）

## 五、数据产出与文件格式

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| FASTQ | 原始 reads | 上机产物 |
| 表达矩阵（matrix.mtx + barcodes + features） | 细胞 × 基因的计数 | 分析输入标准格式 |
| h5ad / Seurat 对象（.rds） | 矩阵 + 注释 + 降维坐标 | 分析过程载体 |
| 细胞注释表 | 每个细胞的类型标签 | 结果核心 |
| UMAP/t-SNE 坐标 | 二维可视化坐标 | 仅用于展示，不做距离解释 |
| 差异表达表（pseudobulk） | 组间差异基因 | 结论依据 |

## 六、标准分析流程

```
FASTQ
  ↓ ① 比对与计数（Cell Ranger / STARsolo / alevin）
  ↓ ② 细胞质控与过滤（nFeature、nCount、线粒体比例）
  ↓ ③ 双细胞识别（scDblFinder / DoubletFinder）
  ↓ ④ 环境 RNA 校正（SoupX / CellBender）
  ↓ ⑤ 标准化与特征选择（LogNormalize / SCTransform；高变基因）
  ↓ ⑥ 降维（PCA → UMAP/t-SNE）
  ↓ ⑦ 批次整合（Harmony / scVI / CCA）
  ↓ ⑧ 聚类（Leiden/Louvain）与细胞注释（人工 marker + 自动注释）
  ↓ ⑨ 差异表达（pseudobulk + DESeq2/edgeR）与比例分析
  ↓ ⑩ 专项分析（轨迹、细胞通讯、拷贝数推断、免疫组库）
```

| 步骤 | 目的 | 常用工具 | 关键点 |
| --- | --- | --- | --- |
| ① 比对计数 | 生成表达矩阵 | Cell Ranger、STARsolo、alevin | 参考基因组版本一致 |
| ② 质控 | 剔除死细胞、空液滴 | Seurat、Scanpy | 阈值应按组织调整，避免"一刀切" |
| ③ 双细胞 | 剔除两个细胞共享一个液滴 | scDblFinder、DoubletFinder | 双细胞会造出"新细胞类型"的假象 |
| ④ 环境 RNA | 去除其他细胞飘散的 RNA | SoupX、CellBender | 对免疫细胞与分泌型基因影响大 |
| ⑤ 标准化 | 消除深度差异 | LogNormalize、SCTransform | 不能用 TPM/FPKM 思路处理单细胞 |
| ⑥ 降维 | 压缩维度、便于聚类 | PCA + UMAP/t-SNE | UMAP 只用于展示 |
| ⑦ 整合 | 去批次、保留生物学差异 | Harmony、scVI、CCA/RPCA | **不要过度整合**，会抹平真实差异 |
| ⑧ 聚类与注释 | 定义细胞类型 | Leiden、Louvain；SingleR、CellTypist | 注释必须结合 marker 基因人工确认 |
| ⑨ 差异与比例 | 组间比较 | pseudobulk + DESeq2/edgeR；Milo | 必须用样本为单位做统计 |
| ⑩ 专项分析 | 机制探索 | Monocle3、Slingshot、CellChat、CopyKAT、inferCNV | 结果为假设，需验证 |

## 七、质量控制指标

| 指标 | 常见参考 | 异常含义 |
| --- | --- | --- |
| 细胞活性 | >80–90% | 低活性引入大量环境 RNA |
| 每个细胞检测到的基因数 | 通常 500–5 000（按组织调整） | 过低是空液滴，过高可能是双细胞 |
| 每个细胞 UMI 数 | 与基因数联动 | 过低的细胞过滤 |
| 线粒体基因比例 | 常用 <10–20% | 过高提示细胞凋亡；但心肌、肝脏等组织本身偏高，阈值需调整 |
| 双细胞率 | 越低越好（一般 <5–10%） | 过高会伪造成新细胞亚群 |
| 测序饱和度 | 越高越好 | 低饱和度说明深度不足 |
| 每个 cluster 的细胞数 | 过小（如 <50）的簇不可靠 | 需合并或标注不确定 |
| 批次混杂程度 | 用 kBET/iLISI 等评估 | 整合不足或过度整合 |
| 已知 marker 基因表达 | 应与细胞类型一致 | 反向说明注释错误 |

## 八、结果怎么读（临床视角）

### 8.1 UMAP 图不是"距离图"

UMAP 只保留局部邻接关系，**簇间的距离和大小不代表相似程度或细胞数量**。因此：

- 不能根据"两个簇离得近"就说它们相似；
- 不能根据"某个簇面积大"推断细胞比例（坐标是无量纲的）；
- 判断细胞比例变化必须回到**原始细胞计数 + 统计检验**。

### 8.2 聚类结果是参数产物

簇的数量由**分辨率参数**决定，调解分辨率就能得到更多或更少的簇。所以"发现了一群新细胞"必须谨慎表述，通常应改为"发现了一群具有某某特征的细胞状态"，并用独立方法验证。

### 8.3 差异表达必须用 pseudobulk

这是本节最重要的技术点：

- **错误做法**：把每个细胞当独立样本做 Wilcoxon/t 检验 → 细胞数越多，"显著性"越夸张，得到大量假阳性；
- **正确做法**：按**样本（供体）**把同一细胞类型的表达加和（pseudobulk），再用 DESeq2/edgeR 做组间比较；
- 若只关心"这群细胞里哪些基因是这个细胞类型特有的"，可以用细胞层面的检验（这一步是描述性的，不是组间推断）。

### 8.4 细胞比例的差异怎么分析

比例分析同样需要**以样本为单位**：先算每个样本中该细胞类型的占比，再做组间检验（如比例检验或 Milo 等专门方法）。**同一供体内细胞数再多，也只是 n=1。**

### 8.5 专项分析的边界

| 分析 | 能得出什么 | 不能得出什么 |
| --- | --- | --- |
| 拟时序/轨迹 | 状态的连续变化假设 | 真实时间顺序、因果关系 |
| 细胞通讯 | 配体-受体可能存在的互作 | 实际发生的信号传导 |
| 单细胞拷贝数推断 | 肿瘤细胞的克隆结构假设 | 精确的变异断点 |
| 免疫组库 | 克隆型与克隆扩增 | 抗原特异性（除非有专门实验） |
| 代谢/通路打分 | 相对活性倾向 | 真实代谢通量 |

### 8.6 临床解读的三条底线

1. **细胞注释要用正交证据确认**（流式、免疫组化、bulk 数据）；
2. **组间结论必须有生物学重复**，单样本的"差异"不能作为结论；
3. **稀有细胞类型与低表达基因的结论要保守**，dropout 会严重干扰判断。

## 九、临床应用场景

### 9.1 肿瘤微环境与免疫治疗

这是目前最成熟的转化方向：刻画肿瘤浸润 T 细胞的耗竭状态、Treg 与髓系抑制细胞的比例、免疫检查点分子表达谱，用于解释免疫治疗响应与耐药的细胞学基础。临床解读时要区分"相关性描述"与"可用于疗效预测的标志物"——后者需要前瞻性队列验证。

### 9.2 血液系统疾病

白血病/骨髓瘤的单细胞分析可以揭示克隆异质性、白血病干细胞样群体，以及治疗后残留病灶的细胞构成，与 MRD 监测结合具有重要意义。

### 9.3 细胞治疗

CAR-T 等细胞治疗产品的质量与疗效评估中，单细胞技术可用于分析产品的细胞组成、耗竭状态与克隆结构（配合 5′ 免疫组库）。

### 9.4 器官与发育

器官细胞图谱（如 Human Cell Atlas 相关成果）为疾病研究提供正常参考；发育与再生研究大量使用轨迹分析。

### 9.5 感染与免疫

感染性疾病中刻画免疫细胞的激活与耗竭状态，用于理解重症化机制与疫苗应答。

## 十、局限与常见陷阱

| 陷阱 | 错在哪 | 怎么避免 |
| --- | --- | --- |
| 把细胞当独立样本 | 假阳性暴增 | 用 pseudobulk，以样本为单位 |
| 无生物学重复 | 无法做组间推断 | 每组 ≥3 个供体/动物 |
| 批次与分组混杂 | 效应不可分离 | 设计阶段随机化、多路混样 |
| 过度整合 | 抹平真实生物学差异 | 对比整合前后 marker 与已知生物学 |
| UMAP 距离解读 | 距离无意义 | 只用它展示，统计回到数据本身 |
| 阈值一刀切 | 不同组织线粒体比例差别很大 | 按组织与样本分布设置阈值 |
| 忽略环境 RNA | 分泌型基因"到处表达" | SoupX/CellBender 校正 |
| 双细胞未去除 | 伪新细胞类型 | 必做双细胞识别 |
| 自动注释照单全收 | 注释错误传播 | 人工核对 marker 基因 |
| 解离应激基因当结论 | FOS/JUN/HSP 是处理引入的 | 与单核或原位方法对照 |
| 把预测当事实 | 通讯/轨迹结果只是假设 | 明确标注为假设并验证 |
| 细胞数当作样本量 | 统计学错误 | 报告供体数而非细胞数 |

## 十三、术语速查

| 术语 | 含义 |
| --- | --- |
| 液滴/条码 | 每个细胞的 RNA 被加上独特条码，用于归属 |
| UMI | 分子标签，区分真实分子与 PCR 复制品 |
| dropout | 某基因在细胞内实际表达但未被检出 |
| 环境 RNA | 其他细胞释放、飘散到液滴中的 RNA |
| 双细胞（doublet） | 一个液滴中有两个细胞，会造出"伪新类型" |
| pseudobulk | 把同一细胞类型按样本聚合后再做差异分析 |
| 整合 | 消除批次差异同时保留生物学差异 |
| 拟时序轨迹 | 依据表达相似度推断的细胞状态变化顺序 |
