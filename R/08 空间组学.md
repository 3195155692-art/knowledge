# 空间组学（Spatial Omics）

> **一句话定位**：把分子数据放回**组织原位**——"哪些细胞、在什么位置、表达什么"。它补上了单细胞测序丢失的空间信息，补上了病理形态缺失的分子信息。
> **它不回答**：时间顺序（需要纵向样本）、确定性因果。空间相关性只是"共定位"，不是"互相调控"的证据。

---

## 一、这项技术能回答什么问题

| 临床/科学问题 | 空间组学给出的答案 | 备注 |
| --- | --- | --- |
| 肿瘤与正常组织的边界在哪里？ | 界面区域的分子特征 | 与病理切片直接对齐 |
| 免疫细胞是否进入肿瘤内部？ | 免疫细胞的分布与距离 | 解释"免疫排斥"现象 |
| 某个基因在哪种细胞、哪个区域表达？ | 空间表达图谱 | 解决 bulk 数据的平均化问题 |
| 标志物分布在浸润前沿还是中心？ | 空间梯度 | 影响活检取材与治疗策略 |
| 药物在组织里分布到哪里？ | 空间药物成像 | 质谱成像的独特价值 |
| 病理分型能否用分子特征解释？ | 形态与分子的对照 | 病理与组学结合最紧的方向 |

## 二、基本原理（三条技术路线）

### 2.1 原位捕获型（测序读出）

在载玻片上排布带**空间条码**的捕获探针，把切片组织中的 mRNA 原位捕获，再测序。每个捕获点的条码对应一个坐标，从而获得"位置 + 表达"。

- 代表技术：**Visium**（每个捕获点覆盖数个到十余个细胞）、**Slide-seq**、**Stereo-seq**（分辨率更高）；
- 特点：**无偏、可发现新基因**，但分辨率受捕获点尺寸限制，一个点内混合多种细胞。

### 2.2 原位成像型（显微镜读出）

用荧光标记的探针在组织上反复杂交/成像，直接数每个转录本分子。

- 代表技术：**Xenium**、**CosMx**、**MERFISH**、**seqFISH**；
- 特点：**单细胞甚至亚细胞分辨率**，但**只能测预设的基因 panel**（几十到几千个基因）。

### 2.3 空间蛋白与空间代谢

| 技术路线 | 检测对象 | 代表作 |
| --- | --- | --- |
| 多重免疫荧光/成像质谱 | 数十种蛋白 | CODEX、IMC、MIBI |
| 质谱成像 | 小分子、代谢物、药物 | MALDI 成像 |

**三条路线的共同点**：结果都必须与**病理形态**（H&E 或免疫组化）对齐解读，脱离形态谈空间分布没有意义。

### 2.4 由此决定的三条判读规则

1. **"spot 里有一群细胞"不是"一个点一个细胞"。** 捕获型技术的每个点混合了多种细胞，判断"某基因来自哪种细胞"需要**去卷积**，或用成像型技术在单细胞分辨率下确认。
2. **成像型的"没测到"不是"不表达"**：panel 之外的基因根本没被检测。
3. **空间相邻 ≠ 功能互作**：共定位提供的是假设，验证需要实验。

## 三、方案怎么选

| 需求 | 推荐路线 | 原因 |
| --- | --- | --- |
| 发现新的空间模式 | 捕获型（Visium 等） | 全转录组无偏 |
| 精确定位到单细胞 | 成像型（Xenium 等） | 单细胞/亚细胞分辨率 |
| 大视野筛查 | 捕获型或 CosMx 大视野模式 | 覆盖面积大 |
| 蛋白层面的空间分型 | 多重免疫荧光 / CODEX / IMC | 蛋白更贴近功能 |
| 小分子与药物分布 | 质谱成像 | 代谢物与药物的独特优势 |
| 与临床病理结合（回顾性队列） | FFPE 兼容的平台 | 多数临床标本是 FFPE |

## 四、样本与设计

| 要点 | 建议 |
| --- | --- |
| 样本类型 | FFPE 兼容性好的平台优先（多数临床样本为 FFPE）；新鲜冷冻样本质量更好 |
| 切片厚度 | 按平台要求（常见 5–10 μm），切片质量直接影响结果 |
| 形态确认 | **相邻切片做 H&E 染色**，用于形态对齐与病理注释 |
| 取材区域 | 明确 ROI（如肿瘤中心、浸润前沿、癌旁），并记录理由 |
| 重复与样本量 | 不同患者之间存在显著异质性，**切勿用单个切片代表一种疾病** |
| 对照 | 阴性对照（无探针/无关探针）、阳性对照组织、技术重复 |

### 送检前必须问清楚的五个问题

1. 用 FFPE 还是新鲜冷冻？样本保存多久了（RNA 降解程度）？
2. 是要"发现新模式"（用捕获型）还是"精确定位"（用成像型）？
3. 成像型的 panel 里有没有我关心的基因？panel 之外的一律看不到。
4. 有没有配套的 H&E 切片与病理注释？
5. 分析结果打算用什么方法验证？（免疫组化、多重免疫荧光、单细胞数据）

## 五、数据产出与文件格式

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| 表达矩阵 + 空间坐标 | 每个点/细胞的表达与位置 | 分析核心数据 |
| 组织图像（H&E/荧光） | 形态信息 | 与分子数据对齐 |
| 细胞分割结果 | 成像型的细胞边界 | 单细胞定位 |
| 空间可变基因表 | 具有位置依赖的表达基因 | 主要结果 |
| 去卷积结果 | 每个点的细胞类型组成 | 捕获型技术的必备步骤 |

## 六、标准分析流程

```
切片与染色
  ↓ ① 平台数据处理（Space Ranger / 类似流程）
  ↓ ② 质控与组织区域识别
  ↓ ③ 标准化与降维聚类
  ↓ ④ 空间可变基因识别
  ↓ ⑤ 去卷积（捕获型）或细胞分割（成像型）
  ↓ ⑥ 空间邻域与细胞互作分析
  ↓ ⑦ 与病理形态、单细胞数据的联合解读
  ↓ ⑧ 验证（免疫组化、多重免疫荧光）
```

| 步骤 | 常用工具 | 关键点 |
| --- | --- | --- |
| 平台处理 | Space Ranger、各厂商流程 | 参考基因组与 panel 版本要记录 |
| 质控 | Seurat、Scanpy、空间专用包 | 剔除无组织区域与低质量点 |
| 空间可变基因 | 空间统计专用方法 | 与普通差异表达不是一回事 |
| 去卷积 | 单细胞参考 + 去卷积算法 | 参考数据选择直接影响结果 |
| 邻域分析 | 空间邻域富集、细胞距离统计 | 需校正组织密度差异 |
| 可视化与对齐 | 空间绘图工具、图像对齐流程 | 与 H&E 对齐是解读前提 |

## 七、质量控制指标

| 指标 | 参考 | 异常含义 |
| --- | --- | --- |
| 组织覆盖与点/细胞数 | 与切片面积一致 | 覆盖不足影响代表性 |
| 每个点/细胞的 counts | 无过低区域 | 低质量区提示降解或脱片 |
| 组织外的点比例 | 应被正确识别并剔除 | 误纳入会干扰分析 |
| 成像型 panel 检出率 | 与厂商基准比较 | 过低提示样本或流程问题 |
| 细胞分割准确性 | 与形态核对 | 分割错误会系统性偏倚结果 |
| 重复切片一致性 | 相邻切片结果应相符 | 差异大提示技术问题 |
| 与 H&E 形态的对应 | 分子区域应能对应形态 | 对不上需先排查技术原因 |

## 八、结果怎么读（临床视角）

### 8.1 三类常见过度解读

1. **把 spot 的表达当成"某类细胞的表达"**：捕获型的点内混合细胞，必须先做去卷积；
2. **把空间相关当成互作**：某类免疫细胞离肿瘤细胞近，只能说明"有接触机会"，不能证明抑制或杀伤；
3. **用单个样本推断疾病规律**：空间异质性极大，结论需要多个患者样本支持。

### 8.2 空间可变基因与差异表达不是一回事

空间可变基因回答的是"它在空间上有没有结构"，差异表达回答的是"它在两组之间有没有差别"。二者混用会导致错误结论。

### 8.3 与单细胞数据的关系

理想做法是**同一课题内两种数据互相印证**：单细胞确定细胞类型与状态，空间数据确定位置与比例。仅有空间数据而没有参考单细胞数据时，去卷积结果的可信度会下降。

## 九、临床应用场景

### 9.1 肿瘤病理与分子分型

空间组学最有价值的应用是解释**形态相同但预后不同的肿瘤**：例如免疫细胞是"围在边缘"还是"进入中心"，直接关联免疫治疗响应；肿瘤浸润前沿的分子特征往往决定侵袭能力。这类结果正在推动病理分型从"看形态"走向"看形态 + 分子 + 空间结构"。

### 9.2 免疫治疗与微环境

空间分布可用于评估免疫排斥（免疫细胞停留在基质而无法进入肿瘤实质）、三级淋巴结构（可能与免疫治疗响应相关）等结构特征。这类指标目前多用于研究，尚未进入常规临床决策。

### 9.3 药物分布与药效

质谱成像可直接显示药物及其代谢物在组织中的分布，用于理解药物为什么在某类组织中无效，是临床药理与药效学研究的独特工具。

### 9.4 病理辅助诊断

把空间分子数据与病理形态、影像数据结合，是"计算病理"的方向，目前在研究中用于辅助分级、预后分层与标志物发现。

## 十、局限与常见陷阱

| 陷阱 | 错在哪 | 怎么避免 |
| --- | --- | --- |
| 忽略分辨率限制 | 把混合信号当单细胞信号 | 结合去卷积或改用成像型 |
| 忽略 panel 限制 | 把"未检出"当"不表达" | 明确写明 panel 范围 |
| 不做形态对齐 | 分子区域无法解释 | 相邻 H&E 切片 + 病理注释 |
| 单样本下结论 | 空间异质性巨大 | 多患者样本 + 统计推断 |
| 忽略切片间差异 | 相邻切片也可能不一致 | 技术重复与一致性检查 |
| 分割误差未评估 | 单细胞结果系统性偏倚 | 人工核对分割质量 |
| 把共定位当互作 | 过度解释机制 | 明确表述为假设并验证 |
| 用空间数据直接做临床预测 | 样本量与验证不足 | 独立队列验证后再谈应用 |
