# 微生物组与病原检测

> **一句话定位**：这项技术解决两类完全不同的临床问题——**"患者感染了什么"**（病原检测，直接指导治疗）与**"菌群与疾病有什么关系"**（微生物组研究，多为基础与转化）。两者方法相似，但判读标准截然不同，混用会造成严重误判。
> **它不回答**：菌群变化是原因还是结果（横断面研究无法判断因果）、细菌是否存活（DNA 检测不代表活菌）。

---

## 一、这项技术能回答什么问题

| 临床/科学问题 | 方法 | 结果可信度 |
| --- | --- | --- |
| 中枢神经系统感染的病原是什么？ | 脑脊液 mNGS | 高（结合临床，已有前瞻性证据） |
| 培养阴性的重症感染病原是什么？ | mNGS | 中高，需排除污染与定植 |
| 有没有耐药基因？ | 宏基因组 + 耐药基因库 | 中（基因存在 ≠ 表达 ≠ 耐药表型） |
| 肠道菌群组成有何改变？ | 16S / 宏基因组 | 描述性，因果需干预研究 |
| 菌群与免疫治疗响应的关系？ | 队列 + 宏基因组 | 相关性证据为主 |
| 真菌/分枝杆菌等难培养病原？ | 靶向 PCR、tNGS、mNGS | 取决于方法与靶标 |
| 粪菌移植前后菌群如何变化？ | 16S / 宏基因组 | 可解释但不等同疗效 |

---

## 二、基本原理

### 2.1 扩增子测序（16S / ITS）

用引物扩增所有细菌共有的**16S rRNA 基因**的某个可变区（常见 V3–V4），测序后按序列相似度归为操作分类单元或**扩增子序列变异（ASV）**，再与数据库比对得到分类。

- **优点**：便宜、快速、适合大样本；
- **局限**：**通常只能分类到属**，多数情况无法可靠鉴定到种；无法给出功能基因信息；扩增引物有偏好性。
- 真菌常用 **ITS** 区，原理相同。

### 2.2 宏基因组测序

直接把样本中所有 DNA 一起测序，可同时获得**物种组成 + 功能基因 + 耐药基因**。

- **优点**：分辨率到种/株、能看功能；
- **局限**：贵、数据量大、宿主序列占比高时需要去除、低丰度物种可能检不到。

### 2.3 临床病原检测的三条路线

| 路线 | 检测对象 | 特点 |
| --- | --- | --- |
| 靶向核酸检测（多重 PCR、tNGS） | 预设病原清单 | 灵敏、快、便宜；**清单外的一律看不到** |
| 宏基因组测序（mNGS） | 样本中所有核酸 | 无偏、可发现罕见/新发病原；**解读最难** |
| 培养 + 质谱鉴定 | 可培养微生物 | 仍是金标准之一，但慢、部分病原无法培养 |

### 2.4 由此决定的三条判读规则

1. **"检出"不等于"致病"。** 呼吸道、皮肤、肠道样本中必然存在大量定植菌与背景核酸。判断致病性必须结合**部位、丰度、临床表型**，尤其是无菌部位（脑脊液、血液、关节液）的检出意义远大于有菌部位。
2. **相对丰度不是绝对数量。** 一种菌的相对比例下降，可能只是另一种菌大量增殖，而非它本身减少——这是微生物组数据的**组成性（compositional）**本质。
3. **DNA 存在不代表活菌。** 抗生素治疗后死菌的 DNA 仍可被检出，这会干扰疗效判断。

## 三、方案怎么选

| 需求 | 推荐 | 说明 |
| --- | --- | --- |
| 常规感染病原 | 培养 + 靶向 PCR | 快、便宜、有明确阈值 |
| 疑难/重症/免疫抑制患者感染 | mNGS | 培养阴性时价值最大 |
| 难培养病原（真菌、分枝杆菌、胞内菌） | 靶向 PCR 或 mNGS | 视可获得的方法 |
| 耐药基因筛查（研究） | 宏基因组 + 耐药基因库 | 结果需与药敏表型对照 |
| 肠道菌群组成（大队列） | 16S | 性价比高，分辨率到属 |
| 菌群功能与代谢潜力 | 宏基因组 | 分辨率到种/株，可看功能 |
| 菌群转录活性 | 宏转录组 | 研究阶段 |
| 单菌基因组精细分析 | 分离培养 + 全基因组测序 | 临床暴发溯源常用 |

## 四、样本与设计

### 4.1 样本类型

| 样本 | 要点 |
| --- | --- |
| 粪便 | 新鲜采集、尽快冷冻；记录饮食与用药（尤其抗生素） |
| 拭子 / 灌洗液 | 采样部位与深度会影响结果；避免口腔/皮肤污染 |
| 无菌部位（脑脊液、血液、关节液、组织） | **采集过程必须严格无菌**，避免皮肤菌群污染 |
| 尿液 | 中段尿，注意污染判断 |
| 组织 | 需与病理对照（有无坏死、取材部位） |

### 4.2 设计的不可妥协之处

1. **必须设置阴性对照（空白）**，用于识别试剂与环境污染菌——**没有阴性对照的 mNGS 报告无法判断污染**；
2. **阳性对照**（已知浓度菌株）用于评估灵敏度；
3. **采样条件统一**：时间、部位、方法、保存与运输时间；
4. **记录混杂因素**：抗生素使用史、饮食、益生菌、质子泵抑制剂、近期住院；
5. **研究性菌群分析要有足够样本量**，菌群个体差异极大，小样本极易得出不可重复的结论。

### 4.3 送检前必须问清楚的五个问题

1. 是"查某个病原"还是"找不明原因病原"？（决定靶向还是 mNGS）
2. 采样部位是有菌部位还是无菌部位？（决定检出结果的解读权重）
3. 有没有阴性对照？实验室如何界定"阳性阈值"？
4. 患者近期用过抗生素吗？（影响活菌与 DNA 关系）
5. 结果打算怎么用于临床决策？（是否需要与培养、影像、临床表现结合）

## 五、数据产出与文件格式

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| FASTQ | 原始 reads | 分析起点 |
| ASV/OTU 表 | 序列变异 × 样本的丰度表 | 16S 分析核心 |
| 物种丰度表 | 物种 × 样本的相对丰度 | 组成分析 |
| 功能/耐药基因表 | 基因 × 样本的丰度 | 功能与耐药分析 |
| mNGS 报告 | 病原序列数、相对丰度、覆盖度 | 临床解读依据 |

## 六、标准分析流程

### 6.1 16S / ITS 扩增子

```
FASTQ → ① 质控与去嵌合（DADA2 / QIIME2）
      → ② 生成 ASV 表
      → ③ 分类学注释（SILVA / UNITE 等数据库）
      → ④ 多样性分析（α 多样性：观察物种数、Shannon；β 多样性：Bray-Curtis、UniFrac）
      → ⑤ 差异丰度分析（ANCOM-BC、ALDEx2 等）
      → ⑥ 与临床变量关联分析
```

### 6.2 宏基因组

```
FASTQ → ① 质控与宿主序列去除
      → ② 分类学分析（Kraken2、MetaPhlAn）
      → ③ 功能注释（HUMAnN、eggNOG/KEGG）
      → ④ 耐药基因分析（CARD 等）
      → ⑤ 组装与分箱（可选，用于菌株层面分析）
      → ⑥ 统计与关联分析
```

### 6.3 临床 mNGS

```
标本 → 核酸提取（含对照）→ 建库测序 → 去除人源序列
     → 比对病原参考库 → 输出病原序列数与覆盖度
     → 结合临床表现、部位、丰度阈值综合判读
```

| 步骤 | 常用工具 | 关键点 |
| --- | --- | --- |
| 质控与去嵌合 | DADA2、QIIME2、fastp | 参数影响 ASV 数量 |
| 分类注释 | SILVA、GTDB、Kraken2、MetaPhlAn | 数据库版本必须记录 |
| 多样性 | QIIME2、phyloseq、vegan | 需按测序深度标准化 |
| 差异丰度 | ANCOM-BC、ALDEx2、MaAsLin2 | **相对丰度数据不能直接用普通 t 检验** |
| 功能与耐药 | HUMAnN、CARD、VFDB | 基因存在不等于表型耐药 |
| 可视化 | phyloseq、MicrobiomeAnalyst、GraPhlAn | 报告需给出稀释曲线与对照结果 |

## 七、质量控制指标

| 指标 | 参考 | 异常含义 |
| --- | --- | --- |
| 测序深度与稀释曲线 | 曲线应趋于平缓 | 深度不足，低丰度物种不可靠 |
| 阴性对照中的菌 | 应极少且稳定 | 大量菌提示试剂/环境背景 |
| 阳性对照检出 | 应稳定检出 | 反映方法灵敏度 |
| 宿主序列比例（宏基因组/mNGS） | 过高会压缩有效数据 | 需评估是否影响检出限 |
| ASV/物种数 | 与同类研究比较 | 明显异常提示流程问题 |
| 样本间一致性（技术重复） | 应较高 | 低则提示污染或操作问题 |
| mNGS 判读阈值 | 实验室必须制定并验证 | 无阈值的报告不可采信 |

## 八、结果怎么读（临床视角）

### 8.1 mNGS 报告的四步判读

1. **看部位**：无菌部位检出 > 有菌部位检出；脑脊液中的少量序列也可能具临床意义，而痰液中的同样序列可能只是定植；
2. **看丰度与覆盖度**：序列数（或每百万序列中的读段数）与基因组覆盖均匀度，高丰度 + 广覆盖更可信；
3. **看对照与背景**：实验室是否报告阴阳性对照结果、是否列出常见背景菌；
4. **看临床一致性**：与症状、影像、常规检验、经验性治疗反应是否吻合。**不吻合时优先怀疑污染或定植**，而不是立即更改治疗方案。

### 8.2 菌群研究结果的三个"不能"

- **不能用横断面结果推论因果**：疾病导致菌群改变，与菌群导致疾病，横断面研究无法区分；
- **不能用 16S 结果下"到种"的结论**：多数情况仅到属；
- **不能只报告相对丰度**：相对丰度的变化可能由其他成员变化引起，需同时报告绝对定量（如 qPCR 或流式）或明确说明局限。

### 8.3 耐药基因结果的边界

宏基因组检出耐药基因，只能说明**耐药基因存在**，不等于该菌在患者体内表达耐药表型，也不等于药物无效。临床用药仍应以**药敏试验**为主要依据。

### 8.4 粪菌移植（FMT）相关

FMT 的临床证据最强的是**复发性艰难梭菌感染**；其他适应证（如炎症性肠病）证据较弱，属于研究性应用。评估疗效时要区分"菌群改变"与"临床缓解"——前者是过程指标，后者才是终点。

## 九、临床应用场景

### 9.1 感染病原诊断（临床价值最直接）

以 mNGS 为代表的无偏检测在**脑膜炎/脑炎、免疫抑制患者不明发热、培养阴性重症感染**中显示了明确价值，已有前瞻性研究支持其诊断增益。使用要点：严格无菌采样、必带阴性对照、与常规微生物学检查并行而非替代。

### 9.2 耐药与医院感染

分离菌株的全基因组测序用于**暴发溯源**与耐药机制分析，是院感控制中成熟的应用；宏基因组层面的耐药基因筛查主要用于研究。

### 9.3 肠道菌群与疾病

菌群与代谢病、炎症性肠病、肿瘤免疫治疗响应、神经系统疾病的研究众多，但**绝大多数为相关性证据**。临床可落地的部分目前主要是复发性艰难梭菌感染的 FMT。

### 9.4 微生物组作为生物标志物

个别基于菌群特征的检测已被探索用于疾病风险分层与疗效预测，但普遍存在**跨人群可迁移性不足**的问题（不同地区人群菌群结构差异大），需要本地化验证。

## 十、局限与常见陷阱

| 陷阱 | 错在哪 | 怎么避免 |
| --- | --- | --- |
| 没有阴性对照 | 无法区分污染与真实信号 | 每批必设空白对照 |
| 把定植当感染 | 过度治疗 | 结合部位与临床综合判断 |
| 用 16S 结论说到种 | 分辨率不足 | 需种/株层面时改用宏基因组或分离培养 |
| 相对丰度直接做 t 检验 | 统计方法错误 | 用组成性数据专用方法 |
| 忽略组成性本质 | 把"比例下降"当成"绝对减少" | 补绝对定量或说明局限 |
| 用 DNA 检测判断活菌 | 死菌 DNA 仍可检出 | 结合培养、RNA 或治疗反应 |
| 小样本菌群结论 | 不可重复 | 扩大样本量并外部验证 |
| 忽略混杂因素 | 饮食、抗生素、PPI 未校正 | 记录并纳入模型 |
| 菌群相关当因果 | 过度声称 | 明确表述为关联，需干预研究 |
| 耐药基因直接指导用药 | 基因 ≠ 表型 | 以药敏试验为准 |

## 十三、术语速查

| 术语 | 含义 |
| --- | --- |
| 16S rRNA 基因 | 细菌共有的保守基因，用于分类鉴定 |
| ITS | 真菌核糖体基因间隔区，用于真菌分类 |
| ASV | 扩增子序列变异，比传统 OTU 更精确 |
| 宏基因组 | 样本中全部微生物 DNA 的测序 |
| mNGS | 病原宏基因组测序，用于感染病原诊断 |
| α / β 多样性 | 样本内多样性 / 样本间差异 |
| 组成性数据 | 只反映相对比例的数据，统计方法需专门处理 |
| 定植 | 微生物存在但不引起感染 |
| FMT | 粪菌移植 |
