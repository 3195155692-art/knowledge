# 表观组学（Epigenomics）

> **一句话定位**：表观组学研究的是"DNA 序列不变的前提下，基因如何被开关控制"——甲基化、组蛋白修饰、染色质开放程度。它回答的是"为什么两个 DNA 相同的人/细胞表现完全不同"。
> **它不回答**：序列本身有没有突变（→ 基因组）、基因转录出多少 RNA（→ 转录组）。表观改变常是**结果**而非原因，判读时要区分因果。

---

## 一、这项技术能回答什么问题

| 临床/科学问题 | 需要测什么 | 常用方法 |
| --- | --- | --- |
| 某基因是否被甲基化沉默？ | DNA 甲基化 | 甲基化芯片、WGBS、靶向甲基化检测 |
| 肿瘤属于哪种表观亚型？ | 全基因组甲基化谱 | 850K 芯片 |
| 血液里能否早筛出肿瘤？ | cfDNA 甲基化特征 | 靶向甲基化测序、WGBS |
| 哪些调控区在疾病中变活跃？ | 染色质可及性 | ATAC-seq |
| 某个转录因子在这些细胞里结合在哪里？ | 蛋白-DNA 结合 | ChIP-seq、CUT&RUN |
| 缺失/重复患者的致病区域怎么定位？ | 甲基化状态 + 拷贝数 | MS-MLPA、甲基化芯片 |
| 染色体结构如何重排导致基因异常激活？ | 三维基因组 | Hi-C |

## 二、基本原理

### 2.1 DNA 甲基化：亚硫酸氢盐转化

哺乳动物中最主要的表观修饰是 CpG 位点上胞嘧啶的 5-甲基化（5mC）。检测它的经典原理是**亚硫酸氢盐转化**：

- **未甲基化的 C 会被转变成 U**（测序时读作 T）；
- **甲基化的 C 保持不变**（仍读作 C）。

于是"有没有甲基化"就被翻译成了"C 还是 T"的序列差异，用测序或芯片都能读出。**转化率是这类检测的生命线**——转化不彻底，会把未甲基化误读为甲基化。

> 补充：5-羟甲基化（5hmC）与 5mC 在常规亚硫酸氢盐法中无法区分，需要氧化法（如 oxBS-seq）或专门的化学标记方法。研究层面常被忽略，临床解读场合一般不必展开。

### 2.2 组蛋白修饰与染色质结合：抗体富集

组蛋白的化学修饰（甲基化、乙酰化等）会改变染色质的开放状态。检测思路是：**用特异性抗体把携带某种修饰的 DNA 片段拉下来，再测序**（ChIP-seq）。因此结果质量**高度依赖抗体特异性**——抗体不专一，整批数据都不可信。

CUT&RUN 与 CUT&Tag 是新一代替代方案：用酶（或转座酶）在抗体定位处就地切割/标记，**起始细胞量低、背景噪音小**，适合稀有样本（如少量细胞、穿刺标本）。

### 2.3 染色质可及性：Tn5 转座酶

ATAC-seq 利用**Tn5 转座酶**优先插入开放染色质的特性，直接标记并读取"暴露在外"的 DNA 区域。它不需要抗体，操作快，是当前最常用的染色质状态检测方法。由于核小体阻挡插入，片段长度会呈现**规律性周期**——这一点本身就是质控指标。

### 2.4 三维基因组：Hi-C

先用甲醛交联固定空间上相互接触的 DNA，再酶切、连接、测序，统计不同区域之间的接触频率，从而推断拓扑结构域（TAD）、增强子-启动子互作等。临床意义主要在解释结构变异如何"劫持"增强子导致基因异常激活。

### 2.5 由此决定的三条判读规则

1. **甲基化差异常常是细胞组成差异，而不是细胞内在改变。** 一块组织里细胞比例不同，甲基化谱就会不同。这是表观研究中最常见的假阳性来源，必须做细胞组成校正。
2. **修饰水平高低 ≠ 基因表达高低。** 启动子高甲基化通常对应沉默，但基因体甲基化与表达的关系完全不同方向，不能一概而论。
3. **可及性/结合信号是"群体平均"。** 一个峰变强，可能是更多细胞在该位点开放，也可能是少数细胞开放得更彻底。要分辨必须做单细胞层面验证。

## 三、技术平台怎么选

| 方法 | 检测对象 | 分辨率 | 适用场景 | 取舍 |
| --- | --- | --- | --- | --- |
| 甲基化芯片（450K/850K EPIC） | 预设 CpG 位点 | 单碱基（特定位点） | 大样本队列、临床分型 | 便宜稳定，但只覆盖预设位点 |
| WGBS（全基因组重亚硫酸氢盐测序） | 全基因组 CpG | 单碱基 | 发现性研究 | 最全面，但贵、数据量大 |
| RRBS（简化代表性） | CpG 富集区 | 单碱基 | 成本敏感的甲基化研究 | 只覆盖 CpG 密集区 |
| 靶向甲基化（如 MS-MLPA、甲基化特异 PCR） | 特定基因 | 位点级 | 印记疾病、MLH1 甲基化等临床检测 | 便宜快捷，是**临床常规**首选 |
| cfDNA 甲基化测序 | 血浆游离 DNA | 位点/区域级 | 早筛、复发监测 | 检测限受肿瘤负荷限制 |
| ChIP-seq | 蛋白-DNA 结合 | 峰级 | 机制研究 | 需抗体、需对照 |
| CUT&RUN / CUT&Tag | 同上 | 峰级 | 稀有样本 | 起始量低、背景低 |
| ATAC-seq | 染色质可及性 | 峰级 | 调控图谱、肿瘤表观 | 不需抗体，性价比高 |
| Hi-C | 三维接触 | TAD/互作级 | 结构变异机制、发育 | 数据量大，分析门槛高 |

## 四、实验设计与样本要求

### 4.1 样本与用量

| 方法 | 样本要求 | 备注 |
| --- | --- | --- |
| 甲基化芯片 | 基因组 DNA 200 ng–1 μg | 绝大多数临床样本可用 |
| WGBS | 高质量 DNA，量较宽裕 | 降解样本甲基化数据会有偏倚 |
| ATAC-seq | 活细胞为佳，常用 5 000–50 000 个细胞 | 冻存/FFPE 样本需专门方案 |
| ChIP-seq | 需较多细胞量 | 抗体必须经过验证 |
| CUT&RUN / CUT&Tag | 可低至数百至数千细胞 | 稀有样本优选 |
| cfDNA 甲基化 | 血浆 2–10 mL | 专用保存管，避免溶血 |

### 4.2 必须有的对照

- **ChIP-seq 必须有 input 对照**（不做富集的同批 DNA），用于区分"真结合"与"染色质开放或拷贝数带来的假信号"；
- **抗体验证**：需有 knockout/敲低验证或公认的验证数据，实验室应保存验证记录；
- **技术重复**：ChIP/ATAC 的实验变异较大，重复比 RNA 更必要；
- **细胞组成信息**：保留病理评估或流式结果，用于后续校正混杂。

### 4.3 送检前必须问清楚的五个问题

1. 要回答的是"某个位点"还是"全基因组"？（决定用靶向检测还是芯片/测序）
2. 样本里有哪些细胞？比例大概是？（决定是否需要细胞组成校正）
3. 是用新鲜细胞、冻存组织还是 FFPE？（决定可行的方法）
4. 有没有 input 对照与抗体验证记录？
5. 阳性结果用什么方法验证？（焦磷酸测序、靶向甲基化、qPCR）

| 格式 | 用于 | 说明 |
| --- | --- | --- |
| IDAT | 甲基化芯片原始文件 | 芯片下机文件，需用软件转为 β 值 |
| β 值（0–1） | 甲基化水平 | 0 完全未甲基化，1 完全甲基化 |

## 六、标准分析流程

### 6.1 甲基化芯片（临床与队列最常用）

```
IDAT → ① 预处理与质控（minfi/sesame）
      → ② 标准化与过滤（去除检测失败探针、性染色体、交叉反应探针）
      → ③ 细胞组成校正
      → ④ 差异甲基化位点 DMP（limma）与区域 DMR（DMRcate/bumphunter）
      → ⑤ 功能注释与可视化
```

### 6.2 甲基化测序（WGBS / 靶向）

```
FASTQ → 比对（Bismark/bwa-meth）→ 甲基化提取（每个 CpG 的比例）
      → 覆盖率过滤 → DMR 识别 → 注释与可视化
```

### 6.3 ChIP-seq / ATAC-seq

```
FASTQ → 质控与修剪 → 比对（bowtie2/BWA）→ 去重与过滤
      → 峰识别（MACS2 / SEACR / Genrich）
      → （有 input 对照时）做差异比较
      → 峰注释（ChIPseeker）→ 覆盖度与热图（deepTools）→ 可视化
```

| 步骤 | 常用工具 | 关键点 |
| --- | --- | --- |
| 芯片预处理 | minfi、sesame | 探针过滤规则必须写进报告 |
| 测序比对 | Bismark（甲基化）、bowtie2/BWA（ChIP/ATAC） | 甲基化数据必须用支持 C→T 的比对器 |
| 峰识别 | MACS2、SEACR、Genrich | 有/无 input 对照决定参数选择 |
| 差异分析 | limma、DMRcate、DiffBind | 需校正细胞组成与批次 |
| 注释与可视化 | ChIPseeker、deepTools、IGV | 热图、TSS 富集图是标准产出 |

## 七、质量控制指标

| 方法 | 指标 | 常用要求 | 不达标的含义 |
| --- | --- | --- | --- |
| 甲基化测序 | 亚硫酸氢盐转化率 | 通常要求 >99% | 转化不完全会系统性高估甲基化 |
| 甲基化芯片 | 检测 P 值、样本相关性 | 剔除失败探针与离群样本 | 数据不可用 |
| ChIP-seq | FRiP（落在峰内的 reads 比例） | 转录因子常 ≥1%，组蛋白修饰更高 | 信号弱、抗体不佳 |
| ChIP-seq | 峰数与峰宽 | 与已知生物学一致 | 抗体不特异或过富集 |
| ChIP-seq | 与 input 的差异 | 必须有明显富集 | 无 input 无法判断真假 |
| ATAC-seq | TSS 富集分数 | 常用门槛 ≥5 | 低提示开放区信号弱、样本质量差 |
| ATAC-seq | 片段长度分布 | 应呈现核小体周期性 | 无双峰提示酶切失败 |
| ATAC-seq | 线粒体 reads 比例 | 过高提示细胞核提取不佳 | 有效数据减少 |
| 通用 | 重复间相关性 | 同组样本应高相关 | 批次或真异质性 |

## 八、结果怎么读（临床视角）

### 8.1 β 值怎么理解

β 值 0–1 表示该位点上被甲基化的等位基因比例。要记住：**它反映的是整块样本的平均值**。β = 0.5 可能是"全部细胞都半甲基化"，也可能是"一半细胞全甲基化、另一半完全未甲基化"，两种情况临床含义完全不同。

### 8.2 差异甲基化的三种常见误读

1. **忽略细胞组成**：整体 β 值变化常由细胞比例变化导致，需用参考数据集做细胞组成校正后再下结论；
2. **把统计差异当功能差异**：|Δβ| 很小的差异（如 0.05）即使 P 值很显著，生物学意义也往往有限，通常要求 Δβ ≥ 0.1–0.2 才考虑功能影响；
3. **把相关性当因果**：甲基化变化可能是转录变化的**结果**（如基因沉默后甲基化累积），不能反过来当作致病原因。

### 8.3 峰（peak）怎么读

峰的强度、宽度与位置都要看：**启动子区（尤其 TSS 附近）的峰变化通常解释力最强**；增强子区（远端）需要结合染色质互作数据解释；峰的变化也可能是测序深度或拷贝数变化造成的假象（有拷贝数变化时必须校正）。

### 8.4 结果验证

关键的甲基化结论必须换方法验证：**焦磷酸测序**（金标准）、**靶向甲基化特异 PCR**、或亚硫酸氢盐克隆测序。不同方法对同一区域的定量结果可能有系统差异，报告里应写明方法。

## 九、临床应用场景（表观组是临床转化最实在的方向之一）

### 9.1 肿瘤诊断与分型

- **G-CIMP**（胶质瘤 CpG 岛甲基化表型）：与 IDH 突变相关，是独立的预后亚型；
- **MGMT 启动子甲基化**：胶质母细胞瘤中预测替莫唑胺疗效的经典临床标志物，已进入常规检测；
- **MLH1 启动子甲基化**：用于区分**散发性错配修复缺陷肿瘤**与**林奇综合征**（结合 BRAF V600E 状态判断），直接影响是否需要做胚系检测——这是表观标志物影响临床路径的典型例子；
- **肿瘤起源不明**：用甲基化谱做组织溯源分类（分子病理的重要方向）。

### 9.2 早筛与复发监测（cfDNA 甲基化）

血浆 cfDNA 甲基化特征被用于多癌种早筛（如基于 cfDNA 的多癌种检测）与单癌种筛查（如 SEPT9 甲基化用于结直肠癌筛查）。判读要点：**特异性较高但敏感性依赖肿瘤分期与肿瘤负荷**，阴性结果不能排除早期病变，阳性结果需要影像或内镜确认。

### 9.3 遗传性疾病的表观诊断

- **印记疾病**：Prader-Willi 综合征与 Angelman 综合征均由 15q11-13 区域印记异常导致，临床首选 **MS-MLPA** 或甲基化特异 PCR，可直接检出甲基化异常，而不必先做测序；
- **脆性 X 综合征**：FMR1 基因 5′ 区甲基化状态与临床表型相关；
- **表观突变（epimutation）**：序列正常但甲基化异常导致疾病，常规测序会漏检。

### 9.4 药物相关

去甲基化药物（阿扎胞苷、地西他滨）用于骨髓增生异常综合征等。这里有一个常被误讲的点：**这类药物的疗效机制并不完全等同于"去甲基化"**，其细胞毒与核酸掺入效应同样重要，因此不能简单地用"甲基化降下来了"来解释疗效。

### 9.5 年龄与风险

甲基化年龄时钟（Horvath、Hannum 等）可估计生物学年龄，与衰老相关疾病和死亡风险相关。目前主要用于队列研究，**尚未作为个体化临床决策工具**。

## 十、局限与常见陷阱

| 陷阱 | 错在哪 | 怎么避免 |
| --- | --- | --- |
| 不做细胞组成校正 | 把比例差异当表观差异 | 用参考数据集去卷积后再分析 |
| 用过小的 Δβ 下结论 | 统计显著但缺乏生物学意义 | 同时要求 Δβ 绝对值 ≥ 0.1–0.2 |
| 忽略转化率 | 系统性高估甲基化 | 必查转化率与对照 |
| ChIP 无 input 对照 | 真假结合无法区分 | 同批 input 对照 + 抗体验证 |
| ATAC 用死细胞或冻存样本 | 信号极差 | 用活细胞，或采用专门方案 |
| 把 ATAC/ChIP 峰当"基因表达" | 开放/结合 ≠ 表达 | 与转录组数据联用 |
| 忽略拷贝数对信号的干扰 | 重复区域的"高信号"是拷贝数造成 | 校正拷贝数 |
| 单次实验即下结论 | 表观实验变异大 | 生物学重复 + 换方法验证 |
| 用亚硫酸氢盐法谈 5hmC | 该法无法区分 5mC 与 5hmC | 需要氧化法或专门方法 |
| 忽略组织异质性 | 同一"正常"组织的表观谱也不同 | 用同一部位、同一取材方式 |

## 十三、术语速查

| 术语 | 含义 |
| --- | --- |
| CpG 位点 | 胞嘧啶后接鸟嘌呤的序列位点，甲基化主要发生地 |
| 5mC / 5hmC | 5-甲基胞嘧啶 / 5-羟甲基胞嘧啶 |
| 亚硫酸氢盐转化 | 把未甲基化 C 转为 U 的化学处理，甲基化检测的基础 |
| β 值 | 甲基化比例，取值 0–1 |
| DMP / DMR | 差异甲基化位点 / 差异甲基化区域 |
| FRiP | 落在峰内的 reads 比例，ChIP 质量核心指标 |
| input 对照 | 未做抗体富集的对照样本 |
| 染色质可及性 | 染色质被调控蛋白访问的难易程度 |
| 印记基因 | 依父母来源不同而表达不同的基因 |
| 表观突变 | 序列正常但甲基化异常导致疾病 |
| 去卷积 | 由整体甲基化谱推断细胞组成 |
