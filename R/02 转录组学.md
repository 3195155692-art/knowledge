# 转录组学（Transcriptomics / RNA-seq）

> **一句话定位**：转录组测的是"此时此刻哪些基因在表达、表达多少"，回答的是**功能状态**问题——同样的 DNA，为什么肿瘤细胞和正常细胞行为不同。
> **它不回答**：DNA 本身有没有突变（→ 基因组）、蛋白质实际有多少（RNA 与蛋白并不总是一一对应）、基因是否被甲基化关闭的直接机制（→ 表观组）。

---

## 一、这项技术能回答什么问题

| 临床/科学问题 | RNA-seq 的答案形式 | 备注 |
| --- | --- | --- |
| 哪些基因在两组之间表达不同？ | 差异表达基因列表（log2 倍数变化 + 校正后 P 值） | 最基础、最常见的用途 |
| 这批肿瘤属于哪种分子亚型？ | 亚型标签（如乳腺癌 PAM50、结直肠癌 CMS） | 与预后和用药相关 |
| 有没有可靶向的融合基因？ | 融合转录本（如 ALK、ROS1、NTRK、RET） | 直接决定靶向治疗 |
| 肿瘤里有哪些免疫细胞、免疫活性如何？ | 免疫浸润比例与免疫评分 | 需注意去卷积的局限 |
| 组织内不同细胞的差异是什么？ | 需升级到单细胞测序 | → [[04 单细胞分析]] |
| 治疗后是否有排斥或感染迹象？ | 基因表达特征评分 | 已用于心脏移植排斥监测等场景 |

## 二、基本原理

### 2.1 核心逻辑

RNA 在细胞中不稳定，无法像 DNA 那样直接大量读取，因此标准流程是：**提取 RNA → 反转录为 cDNA → 建库 → 测序 → 把 reads 归回基因或转录本 → 计数**。最终得到的是每个基因/转录本的 **reads 计数**。

### 2.2 建库的两条主要路线

| 路线 | 原理 | 适用 | 注意 |
| --- | --- | --- | --- |
| **poly(A) 富集** | 用寡聚 dT 捕获带 polyA 尾的成熟 mRNA | 真核常规样本、新鲜组织 | RNA 降解后 polyA 尾丢失，会严重偏倚 |
| **rRNA 去除** | 用探针去除核糖体 RNA，保留其余 RNA | 降解样本（FFPE）、非编码 RNA、原核样本 | 保留前体 RNA 与部分非编码 RNA，解释时需注意 |

### 2.3 三个影响判读的技术细节

1. **链特异性**：若不保留链方向信息，就无法区分正义链与反义链转录本（在重叠基因与 lncRNA 场景会直接读错）。标准建库应保留链信息，并在质控中确认。
2. **分子标签（UMI）**：给每条原始 RNA 分子贴唯一标签，从而区分真实分子与 PCR 复制品，显著改善低表达基因的定量准确性。
3. **长读长与异构体**：短读长只能匹配转录本片段，**异构体（isoform）层面的定量可靠性有限**；需要明确异构体差异时应使用长读长测序。

### 2.4 由此决定的三条判读规则

1. **RNA-seq 是相对定量。** 每个样本的总 reads 有限，某个基因占比升高就意味着其他基因占比被"挤低"。因此**绝对水平无法跨样本直接比较**，只能比较组间相对变化。
2. **组织表达变化可能只来自细胞比例变化。** 一块肿瘤组织里免疫细胞变多，会让免疫相关基因"看起来上调"，但每个免疫细胞内部的表达其实没变。判断"细胞内在表达改变"需要去卷积或单细胞数据。
3. **read 落在哪里取决于注释与文库类型。** 参考基因组/注释版本、是否包含内含子 reads、是否保留链信息，都会影响计数结果，报告必须写明。

## 三、技术方案怎么选

| 方案 | 分辨率 | 适用场景 | 取舍 |
| --- | --- | --- | --- |
| Bulk RNA-seq（短读长） | 组织平均值 | 差异表达、分子分型、融合基因 | 成本适中、成熟，但受细胞比例混淆 |
| Bulk RNA-seq（长读长） | 转录本/异构体 | 异构体、复杂融合 | 贵，通量低 |
| 单细胞 RNA-seq | 单细胞 | 异质性、微环境 | 贵、分析复杂 → [[04 单细胞分析]] |
| 靶向表达谱（nCounter、RT-PCR 阵列） | 预设基因集 | 临床级签名（如复发评分） | 稳定、可重复性好，但范围固定 |
| 3′ 端计数测序 | 基因水平 | 大样本差异表达、成本敏感 | 便宜，但拿不到异构体与融合信息 |

**临床级签名的共同点**：都用固定基因集 + 标准化流程 + 明确的临床终点验证（见第 9 节）。常规临床决策几乎不用"全转录组自由挖掘"的方式。

## 四、实验设计与样本要求

### 4.1 样本与质量要求

| 样本 | 关键要求 | 风险 |
| --- | --- | --- |
| 新鲜冷冻组织 | 液氮速冻，避免反复冻融 | 质量最好，成本较高 |
| FFPE 组织 | 关注 **DV200**（片段 >200 nt 的比例） | 降解导致 3′ 偏倚，融合基因检测可靠性下降 |
| 血液（全血/白细胞） | 采血后尽快处理 | 处理延迟会显著改变表达谱 |
| 培养细胞 | 活性与状态一致性 | 传代次数、汇合度都会影响结果 |
| 血浆 cfRNA | 专用管、冷链 | 处于起步阶段，标准化不足 |

**RIN 值**（RNA 完整性指数）要正确理解：RIN 低主要影响 **3′ 偏倚与定量准确性**，并不必然使差异表达分析失效——只要有足够的生物学重复，降解样本仍可用于组间比较；但它**不适合做异构体分析和依赖转录本全长的定量**。

### 4.2 重复数与批次（最关键的设计问题）

- **生物学重复至少 3 个/组**。这是差异表达分析的常规底线；少于 3 个时统计功效与假阳性控制都难以保证，效应小或样本异质性大时需要更多。
- **技术重复不能替代生物学重复**。技术重复只说明操作稳定，不能反映个体差异。
- **批次必须与分组解耦**。若"对照组第 1 批、实验组第 2 批"，批次效应与真实效应完全混杂，事后无法挽回——**这是组学研究中最不可逆的设计错误**。
- 常见可用协变量：性别、年龄、取样时间。

### 4.3 送检前必须问清楚的五个问题

1. 样本是新鲜组织还是 FFPE？DV200 多少？
2. 每组几个生物学重复？批次安排是否与分组解耦？
3. 用 polyA 富集还是 rRNA 去除？是否需要链特异性信息？
4. 研究对象是"组织整体"还是"某类细胞"？（决定要不要做单细胞或去卷积）
5. 差异结果打算怎么验证？（独立队列？qPCR？蛋白水平？）

## 五、数据产出与文件格式

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| FASTQ | 原始 reads 与碱基质量 | 分析起点 |
| BAM | 比对结果 | 可视化、覆盖度检查 |
| 计数矩阵 | 基因 × 样本的 reads 计数 | 差异表达分析的输入 |
| 转录本定量（TPM/FPKM） | 标准化表达值 | 作图、样本内比较 |
| 差异表达表 | log2FC、P 值、校正后 P 值 | 结果核心 |

**关于 TPM/FPKM**：它们是**样本内**的标准化值，适合同一基因在不同样本外的场景使用、以及作图；**跨样本比较请使用计数矩阵 + 负二项模型**（DESeq2/edgeR），不要把 TPM 直接送进 t 检验。

## 六、标准分析流程

```
FASTQ
  ↓ ① 质控与修剪（FastQC + fastp/Trim Galore + MultiQC）
  ↓ ② 比对或伪比对（STAR / HISAT2 / Salmon / kallisto）
  ↓ ③ 计数（featureCounts / tximport）
  ↓ ④ 样本级质控与聚类（PCA、相关性热图）
  ↓ ⑤ 差异表达（DESeq2 / edgeR / limma-voom）
  ↓ ⑥ 功能富集（GSEA / GO / KEGG / 通路打分）
  ↓ ⑦ 专项分析（融合基因、免疫浸润、分子分型、去卷积）
  ↓ ⑧ 结果验证与可视化（火山图、热图、独立队列验证）
```

| 步骤 | 目的 | 常用工具 | 关键点 |
| --- | --- | --- | --- |
| ① 质控 | 去接头、去低质量碱基 | FastQC、fastp、Trim Galore、MultiQC | rRNA 比例、接头污染、碱基质量 |
| ② 比对/伪比对 | 定位 reads 或直接估计丰度 | STAR、HISAT2（比对型）；Salmon、kallisto（伪比对型） | 必须使用与注释版本匹配的参考基因组 |
| ③ 计数 | 得到基因水平计数 | featureCounts、tximport | 链特异性参数设置错误会大幅改变计数 |
| ④ 样本级质控 | 发现离群样本 | PCA、样本相关性、层次聚类 | 离群样本先查原因，不要直接删 |
| ⑤ 差异表达 | 找组间差异基因 | DESeq2、edgeR、limma-voom | 计数数据用负二项模型，不用正态检验 |
| ⑥ 功能富集 | 把基因列表变成生物学含义 | GSEA、clusterProfiler、MSigDB | 同时看方向（上调/下调）与通路冗余 |
| ⑦ 专项分析 | 回答具体临床问题 | STAR-Fusion、Arriba、CIBERSORT、ESTIMATE | 方法假设要写进报告 |
| ⑧ 验证 | 排除偶然发现 | RT-qPCR（按 MIQE 规范）、独立队列、蛋白验证 | 无验证的差异基因不能称为标志物 |

### 关键参数怎么读

| 参数 | 含义 | 判读意义 |
| --- | --- | --- |
| log2 倍数变化 | 组间表达比值取对数 | 1 表示翻倍；绝对值 <0.58（1.5 倍）通常属微弱变化 |
| P 值与校正后 P 值 | 差异的统计学显著性 | **报告应看校正后 P 值**，否则假阳性泛滥 |
| 标准化计数 | 校正测序深度后的计数 | 只有它才能跨样本比较 |
| 离散度估计 | 负二项模型中的变异参数 | 样本量少时估计不稳，结论需保守 |
| 测序深度 | 每个样本的总 reads | 深度不足会漏检低表达基因 |

## 七、质量控制指标

| 指标 | 常见参考范围 | 异常提示 |
| --- | --- | --- |
| 碱基质量 Q30 | ≥85% | 测序质量差 |
| 比对率 | 通常 >70–80%，成熟流程常 >90% | 污染、接头残留、参考基因组不匹配 |
| rRNA 比例 | polyA 文库一般 <5% | 富集失败，有效数据被浪费 |
| 外显子 reads 比例 | 通常 >60–70% | 基因组 DNA 污染或注释问题 |
| 重复率 | 与表达谱复杂度有关 | 过高提示起始量不足或扩增偏倚 |
| 链特异性 | 应与建库方案一致 | 参数设错会导致计数错误 |
| 样本间相关性 | 同组样本通常较高 | 低相关性提示离群样本或批次问题 |
| 测序饱和度 | 随深度趋平 | 未饱和说明深度不足，低表达基因不可靠 |
| DV200（FFPE） | 越高越好 | 过低影响 3′ 偏倚与融合基因检测 |

## 八、结果怎么读（临床视角）

### 8.1 判读差异表达表的四个动作

1. **看校正后 P 值**（padj/FDR < 0.05），不看原始 P 值；
2. **看倍数变化大小**，常用门槛 |log2FC| ≥ 1（2 倍）；
3. **看基础表达量**：低表达基因的"巨大倍数变化"往往是噪音；
4. **看是否有独立验证**：只有内部数据、没有验证的差异基因，只能算"发现阶段"结果。

### 8.2 区分"细胞比例变化"与"细胞内在表达变化"

这是 bulk RNA-seq 最容易被过度解读的地方。看到"免疫相关基因整体上调"时，必须先问：免疫细胞是不是变多了？解决办法：

- 用**去卷积**（CIBERSORT、xCell、MCP-counter、ESTIMATE）估计细胞组成；
- 或升级到**单细胞测序**直接比较同类细胞；
- 或在病理切片上用免疫组化验证。

### 8.3 分子分型怎么用

分子分型是 RNA-seq 最成熟的临床转化方向。判读要点：分型应来自**经过临床终点验证的固定基因集与算法**（如乳腺癌 PAM50、结直肠癌 CMS），而不是自己在小样本里聚类得到的新分型——后者只能作为研究假设。

### 8.4 融合基因报告的注意事项

融合基因（ALK、ROS1、NTRK、RET 等）直接决定靶向用药，但 RNA 层面检测融合有三个前提：**RNA 质量足够**（FFPE 降解样本易漏检）、**工具的已知融合库足够新**、以及**阳性结果用 FISH/IHC 或 RT-PCR 确认**（不同方法的灵敏度与特异性差异明显）。

### 8.5 需要警惕的三句话

- "表达上调提示该通路被激活"——表达量与通路活性不是一回事；
- "该基因高表达提示预后不良"——多为小样本回顾性研究，需看是否独立验证并校正混杂；
- "未检出融合"——不能排除，取决于 RNA 质量与分析工具的覆盖范围。

## 九、临床应用场景

### 9.1 已进入临床决策的产品（成熟度最高）

| 产品/签名 | 应用 | 关键证据 |
| --- | --- | --- |
| Oncotype DX（21 基因复发评分） | 早期激素受体阳性乳腺癌是否需要化疗 | TAILORx 随机试验 |
| MammaPrint（70 基因） | 早期乳腺癌复发风险 | MINDACT 随机试验 |
| Prosigna（PAM50） | 乳腺癌分子亚型与复发风险 | 多项前瞻性验证研究 |
| 融合基因检测 | NSCLC、甲状腺癌、肉瘤的靶向治疗 | 相关癌种 NCCN/ESMO 推荐 |
| 移植排斥监测（如 AlloMap） | 心脏移植后排斥风险评估 | IMAGE 等前瞻性研究 |

### 9.2 研究阶段但临床关注度高

- 肿瘤免疫微环境评分与免疫治疗响应预测；
- 治疗前后配对样本的耐药机制研究；
- 感染性疾病的宿主反应分型（发热待查、脓毒症鉴别）；
- 药物疗效相关表达标志物探索。

### 9.3 公共数据再挖掘

TCGA、GTEx、GEO 是临床研究者成本最低的起点：用 TCGA 做发现、GEO 做验证、GTEx 提供正常组织基线。使用规范见 [[12 公共数据库与资源速查]]，统计与设计要点见 [[11 临床研究设计与统计要点]]。

## 十、局限与常见陷阱

| 陷阱 | 错在哪 | 怎么避免 |
| --- | --- | --- |
| 用 TPM 直接做检验 | 不满足检验假设，假阳性高 | 用计数矩阵 + DESeq2/edgeR |
| 只做 2 个重复 | 统计功效不足 | 至少 3 个生物学重复 |
| 批次与分组混杂 | 效应不可分离 | 设计阶段随机化、组内混批 |
| 忽略细胞比例 | 把比例变化误读为表达变化 | 去卷积或单细胞验证 |
| 循环论证 | 用同一批数据筛选又验证 | 独立队列、留出法、交叉验证 |
| 多重检验未校正 | 上万基因中必然出现假阳性 | 报告 padj/FDR |
| 只看 P 值不看效应量 | 微小差异被过度解读 | 同时报告倍数变化与置信区间 |
| 把 RNA 当蛋白 | 忽略转录后调控 | 关键结论加做 IHC 或免疫印迹 |
| 低质量 RNA 做融合检测 | 假阴性 | 先看 DV200，必要时改 DNA 层面检测 |
| 单样本或单细胞直接成组比较 | 无法区分个体差异 | 必须设生物学重复 |

## 十三、术语速查

| 术语 | 含义 |
| --- | --- |
| FPKM / TPM | 表达量标准化值，仅适合样本内比较 |
| 计数矩阵 | 基因 × 样本的 reads 计数，差异分析的正确输入 |
| log2FC | 两组表达比值的以 2 为底对数，1 表示翻倍 |
| padj / FDR | 多重检验校正后的 P 值 |
| 去卷积 | 由组织整体表达推断细胞组成比例 |
| 融合基因 | 两个基因拼接形成的异常转录本，常为肿瘤驱动事件 |
| RIN / DV200 | RNA 完整性指标；DV200 更适用于 FFPE 样本 |
| 异构体（isoform） | 同一基因经可变剪接产生的不同转录本 |
| 批次效应 | 由实验批次而非生物学差异引起的系统性偏差 |
