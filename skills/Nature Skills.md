# Nature Skills

> 面向 Nature 系投稿的中文友好技能库：精读、写作、润色、审稿、返修、绘图、PPT、专利。

## 作用

围绕「投稿前—投稿中—投稿后」的实际动作组织，最常用的是四类：

- **读**：中英对照全文精读、单篇深度解读（论文卡片）、文献发现流水线、引文核验。
- **写**：Nature 风格写作、润色 / 翻译、统计报告审查、数据可用性声明。
- **投**：审稿人视角模拟审稿、审稿意见回复信（多位审稿人互相隔离，避免串味）。
- **做图做稿**：科研绘图（Python / R）、图片转可编辑 PPT、论文转中文 PPT、论文转专利、实验日志。

## 调用方法

- 中文触发词很丰富，说人话就行：「把这篇论文做成中英文对照的全文精读」「把这篇论文做成中文 PPT」「帮我模拟审稿」「润色这段摘要」。
- 点名调用：`$nature-reader`、`$nature-figure`、`$nature-reviewer`、`$nature-response`、`$nature-paper2ppt` 等。

| 技能                           | 作用                                                                                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `nature-academic-search`     | 多源文献检索（PubMed / CrossRef / arXiv / Scopus / ScienceDirect，走 MCP）＋引文核验、严格他引审计、文章级引用指标表、引用者画像与引用语境提取、MeSH 检索式、引文文件互转（.nbib/.ris/.bib）与参考文献管理。 |
| `nature-citation`            | 给正文加严格 Nature/CNS 引用：把长段落拆成可引用片段，只在 Nature 系、Science 系、Cell 系刊物中检索，按发表时间过滤，默认导出一份可直接导入文献管理软件的结果。                                            |
| `nature-data`                | 撰写、审查或修改符合 Nature 要求的数据可用性声明、数据仓库方案、数据集引用和 FAIR 元数据清单。                                                                                      |
| `nature-downloader`          | 合法获取学术全文：CNKI 机构访问、英文 OA 检索、出版商 API、机构订阅的浏览器兜底，以及补充材料下载。                                                                                    |
| `nature-experiment-log`      | 标准化实验日志记录——直接上传或读取本地图片、语音和文字，产出带 YAML frontmatter 的 Markdown；可选集成飞书 CLI 与 Obsidian。                                                         |
| `nature-figure`              | 用 Python（matplotlib/seaborn）或 R（ggplot2/patchwork/ComplexHeatmap）制作投稿级科研配图：多面板图、论文插图、期刊要求的 SVG/PDF/TIFF 导出；另有一条 AI 路线专门生成图形摘要与机制示意图。        |
| `nature-image2ppt`           | 把幻灯片图片、截图、扫描 PDF、纯图片 PPT/PPTX 还原成高保真、对象级可编辑的 PPT：语义分区混合重建、流程图与知识图谱还原、原生节点与连接线、单对象箭头、备注保留和渲染质检。                                              |
| `nature-literature-pipeline` | 全自动文献发现流水线：多源检索 → 六维打分 → 精读 → 格式化交付 → 归档；可与飞书、Telegram 等消息渠道联动做每日推送。                                                                        |
| `nature-paper-card`          | 为单篇论文、预印本、PDF、DOI、arXiv 页面或粘贴文本生成有来源依据的深度精读卡片，固定 01–16 节：文献定位、研究问题、背景路线、痛点、核心洞见、方法与模块逻辑、关键公式、实验到结论的证据链、结论边界、作者自述局限、批判性分析、知识连接与可检验的研究想法。     |
| `nature-paper-to-patent`     | 把论文、学位论文、技术报告、源码、配图或发明人笔记转成有证据支撑的中文专利草稿与面向代理师的技术交底书：挖掘专利点、现有技术对比、Office 材料转换、逐项权利要求特征溯源、公式保留为可编辑公式、生成与权利要求对应的流程图、论文与已有专利比对、支撑度审查。           |
| `nature-paper2ppt`           | 从论文、预印本、PDF、图表说明或精读笔记生成完整的 Nature 风格中文 PPTX：判断论文类型、搭建证据驱动的叙事、挑选关键图、撰写中文幻灯片内容与讲稿、直接产出 .pptx，并对图片裁切、对齐和文字溢出做质检。                               |
| `nature-polishing`           | 把学术文字润色、重构或翻译成简洁的 Nature 风格英文，同时保留事实、证据边界、术语和引用意图；也可用于压缩臃肿的 Results、在正文／图注／补充材料之间分配证据、抑制返修带来的内容膨胀。                                          |
| `researchwrite`              | 「论证先行」的科研写作流水线（触发名 researchwrite，仓库目录名 nature-proposal-writer），适用于基金申请书、开题报告和研究计划的撰写、修改与审查：三种模式（撰写／修改／混合）＋四层质检，强调证据先于文字、论证先于章节、契约先于段落。      |
| `nature-reader`              | 把期刊或会议论文（PDF / DOI / arXiv / 出版商 HTML / 粘贴文本）做成中英文对照的全文精读 Markdown：图文表公式各就各位、公式渲染而非裸露 LaTeX、每个块都保留原文锚点。                                     |
| `nature-ref-verifier`        | 对学术文献逐条执行多源交叉验证，逐字段对比作者、标题、年份、卷期、页码， 标记卷年/DOI年冲突、作者顺序异常、页码偏差等问题，输出结构化验证报告。                                                                  |
| `nature-response`            | 起草、审查或修改 Nature 风格返修材料：逐点回复信、反驳信、返修说明信、LaTeX 回复模板与标红修改稿；多位审稿人互相隔离，不让一位审稿人看到另一位的意见、编号、推荐结论或作者回复，并优先用替换、压缩或移入补充材料来避免返修稿膨胀。                    |
| `nature-reviewer`            | 以审稿人视角模拟 Nature 风格或通用的投稿前评审：输出有证据支撑的主要问题、次要意见和阻断性风险；多审稿人彼此隔离、各自报告冻结后再做综合。                                                                   |
| `nature-statistics`          | 审查、修改或起草面向 Nature 及高影响力期刊的统计报告：p 值、置信区间、样本量、生物学重复与技术重复、随机化、盲法、多重比较校正、模型假设、图注统计措辞与审稿人统计意见。                                                   |
| `nature-writing`             | 根据作者提供的结论、结果、图表、笔记或中文草稿，起草、重构或规划 Nature 风格各章节与首次投稿材料：摘要、引言、相关工作、方法、结果、讨论、结论、标题，以及投稿信、标题页、亮点、作者贡献、声明文本和推荐审稿人。                                |

## 注意事项

- `nature-shared` 是共享支持包，被其他技能读取，**不要单独当技能调用**。
- 部分技能要额外环境，按需再装：`nature-academic-search` 走 MCP（PubMed / CrossRef 等，需要邮箱和凭据）、`nature-paper-to-patent` 有 requirements.txt、启用国知局检索还要装 Playwright 的 Chromium。
- 仓库自带 Codex 同步脚本，后续更新重跑即可（同步 skills/ 下全部技能，不覆盖无关技能）。
