## 一、先搞清楚：UMAP 在单细胞分析里干嘛用？

**场景**：接上一篇，PCA 把 8000 个 GBM 细胞从两万维压到了 20 个主成分。但 20 维人还是没法看。你想在一张二维图上直观看到：
- 哪些细胞是同一类（聚成一团）
- 肿瘤细胞、免疫细胞、胶质细胞怎么分布
- 对照组和治疗组的细胞位置有没有变化

UMAP（Uniform Manifold Approximation and Projection，均匀流形近似与投影）就是把这 20 维进一步**压到 2 维（或 3 维）**，同时尽量保留"谁和谁是邻居"的关系，画出那张五颜六色的细胞散点图。

它是目前单细胞论文里最常见的可视化方法，基本取代了 t-SNE。

---

## 二、为什么 PCA 不够、还需要 UMAP？

### 1. PCA 是线性的，压不下"弯曲"的结构

细胞分化、细胞状态变化常常发生在**弯曲的曲面（流形）**上，就像地球表面是弯的。线性方法像硬把一张弯地图拍平，远处的关系会失真。

### 2. 要保留局部邻里关系

我们最关心的是"相似的细胞挨在一起"。UMAP 优先保证：在高维里是邻居的细胞，在 2 维图上也尽量挨着。

### 3. 可视化需要 2 维

PCA 保留几十维是给算法用的，人眼只需要一张 2 维图。

---

## 三、核心原理：先画"邻里地图"，再在纸上摊平

### 直觉：把一团毛线摊平在桌面上

想象高维空间里的细胞像一团揉皱的毛线，每个细胞和周围几个细胞连着短线。UMAP 做两件事：

1. **在高维里先确定"谁和谁是邻居"**，连出一张邻里关系网
2. **把这张网尽量保持连接关系、摊平到二维桌面上**——原本连着的点尽量还挨着、不连的点别硬凑

### 第 1 步：构建邻居图（高维）

对每个细胞，找出距离最近的 k 个邻居，并给每条边一个"连接强度"（距离越近越强）。这一步用的是高维空间里的真实距离，通常跑在 PCA 结果上。

### 第 2 步：低维布局（优化）

在二维上随机摆放这些点，然后反复调整：
- 高维里连着的点，在二维上被"拉近"
- 高维里不连的点，被"推开"
- 经过很多轮，得到一张尽量还原邻里关系的平面图

数学上 UMAP 基于"模糊单纯形集"和交叉熵优化，你不需要推导，记住"**高维建图、低维摊平**"这八个字即可。

### 两个关键参数（直接影响图的样子）

| 参数 | 含义 | 调大/调小的效果 |
|---|---|---|
| `n_neighbors` | 每个细胞参考多少个邻居 | 大：看全局结构、细节被抹平；小：盯局部、可能碎片化 |
| `min_dist` | 二维上点允许挤多近 | 大：点分得开、成团松散；小：点紧密聚成块 |
| `metric` | 高维用什么距离 | 单细胞常用 euclidean/correlation |

## 四、用一个迷你图理解"摊平"

不做数字计算，用 5 个细胞的关系图理解：

高维里的邻居关系（连线=邻居）：

```
A — B — C
        |
        D — E
```

UMAP 摊到二维时，会让 A、B、C 挨在一起，C、D 挨着，D、E 挨着；而 A 和 E 没有直接连线，就不会被硬凑。

最终二维图上你看到的是一条大致连续的点链，而不是把 5 个点随机散开。**这就是 UMAP 保留"局部结构"的含义——它忠实的是连接关系，而不是原始的绝对距离。**

## 五、UMAP vs t-SNE vs PCA

| | UMAP | t-SNE | PCA |
|---|---|---|---|
| 类型 | 非线性、流形 | 非线性、流形 | 线性 |
| 主要用途 | 可视化 | 可视化 | 降维供计算 |
| 速度 | 快 | 慢 | 极快 |
| 全局结构 | 保留较多 | 保留弱 | 完整（但线性） |
| 可重复性 | 较稳定 | 种子影响大 | 确定 |
| 距离/簇大小 | 不能直接定量 | 不能 | 可解释 |
| 当前地位 | 主流 | 逐渐减少 | 基础步骤 |

**最重要的一条红线**：UMAP（和 t-SNE）是**可视化工具**，图上两点的距离、簇的大小、簇之间的"空隙"都不能直接当定量证据。聚类、差异分析要在 PC 空间和原始数据上做。

## 六、代码（R / Seurat + Python / scanpy）

Seurat 里在选定的 PC 上跑 UMAP：

```r
library(Seurat)
obj <- RunUMAP(obj, reduction = "harmony", dims = 1:20,
               n.neighbors = 30, min.dist = 0.3)
DimPlot(obj, reduction = "umap", group.by = "celltype", label = TRUE)
DimPlot(obj, reduction = "umap", group.by = "group", split.by = "group")
```

直接用 umap 包（任意高维矩阵）：

```r
library(umap)
emb <- umap(pca_scores, n_neighbors = 30, min_dist = 0.1)
plot(emb$layout, pch = 16, col = labels)
```

Python（scanpy）：

```python
import scanpy as sc
sc.pp.neighbors(adata, n_neighbors=30, use_rep='X_pca')
sc.tl.umap(adata, min_dist=0.3)
sc.pl.umap(adata, color=['celltype', 'group'])
```

## 七、论文里怎么写

**方法**：

> 基于前 20 个主成分（或 Harmony 校正后的嵌入），以 30 个近邻、min_dist=0.3 运行 UMAP，将细胞投影至二维空间用于可视化。细胞类型注释与聚类在高维/PC 空间独立完成，UMAP 仅用于结果展示。

**结果**：

> UMAP 显示细胞按主要类型清晰分离，共形成 X 个转录组簇；同一细胞类型在对照组与治疗组中位置一致，提示批次/分组未造成人为分离。

## 八、最常见的坑

1. **在 UMAP 上量距离、比簇大小下结论。**
   非线性嵌入不保留真实距离，簇大小和间距没有定量意义。

2. **参数靠默认值不验证。**
   n_neighbors、min_dist 会明显改变图形，要在合理范围比较、固定随机种子。

3. **把 UMAP 当聚类结果。**
   图上"看起来成团"不等于统计聚类，聚类要用 FindClusters/Louvain。

4. **每次重跑图形都变却不固定种子。**
   UMAP 有随机性，发表前固定 seed 并保存最终嵌入。

5. **在原始两万维直接跑 UMAP。**
   应先 PCA 去噪、在 PC 空间跑，否则慢且受噪声主导。

6. **用 UMAP 推断分化方向。**
   看轨迹/拟时序要用专门的轨迹分析方法，不能凭 UMAP 上的位置排列硬说谁分化成谁。

## 九、判断清单

用 UMAP 前问：

1. 目的是不是**可视化**（而非定量计算）？
2. 是否先做了 PCA、在 PC/Harmony 空间跑？
3. n_neighbors、min_dist 设了吗、随机种子固定了吗？
4. 聚类和注释是否独立完成、不依赖 UMAP 视觉？
5. 有没有避免在图上做距离/轨迹的过度解读？

**一句话总结**：UMAP 先在高维（通常是 PC 空间）构建细胞的邻居关系图，再把这张图尽量保持连接、摊平到二维，从而直观展示细胞类群；它是单细胞最主流的可视化工具，但图上的距离和簇大小不能定量，真正的聚类、差异和轨迹分析必须在高维空间完成。
