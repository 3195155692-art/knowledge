## 一、先搞清楚：PCA 在单细胞分析里干嘛用？

**场景**：你做了一批胶质母细胞瘤（GBM）肿瘤微环境的单细胞测序，质控后剩下 8000 个细胞，每个细胞测了 20000 个基因的表达量。

这意味着每个细胞是一个**两万维**的点。直接在两万维上做聚类、画图、计算，又慢又乱，而且大部分基因是"背景噪声"（管家基因、不表达的基因），真正区分细胞类型的信息只占一小部分。

PCA（Principal Component Analysis，主成分分析）就是**降维**：把两万维的信息，压缩成几十个"浓缩的新维度"（主成分），同时尽量不丢失区分细胞的关键信息。

它是单细胞标准流程里的关键一环：

```
标准化 → 高变基因 → 【PCA 降维】→ Harmony/聚类 → UMAP 可视化
```

UMAP、聚类、Harmony 几乎都建立在 PCA 的结果上，所以 PCA 是理解单细胞分析的基础。

---

## 二、为什么需要降维？

### 1. 维度灾难

维度越高，点与点之间的距离越趋向"都差不多"，细胞之间的远近关系失效，聚类和最近邻算法会失灵。

### 2. 噪声多于信号

两万基因里，真正随细胞类型变化的基因可能就一两千个。其余基因要么不表达、要么随机波动，带着它们反而干扰判断。

### 3. 计算和可视化

两万维没法画图，人眼最多看 2–3 维；高维矩阵运算也慢。

### 4. 相关性冗余

很多基因是"一起涨一起跌"的（比如同一通路上的基因），它们携带的信息高度重复，没必要各算一维。

PCA 用一个巧妙的视角解决：**不按原来的基因看数据，而是重新找几根"信息量最大"的新坐标轴。**

---

## 三、核心原理：重新找"最能拉开差距"的坐标轴

### 直觉：旋转相机，找到最佳拍摄角度

想象你在拍一群人，正面拍时大家挤在一起分不清谁是谁；你把相机转一个角度，高个子、矮个子立刻拉开了。

PCA 就是在"旋转观察角度"：
- 原来的坐标轴是一个个基因（两万根轴）
- PCA 旋转出一组新轴，**第 1 根轴（PC1）对准"细胞之间差异最大、最能拉开"的方向**
- 第 2 根轴（PC2）对准"和 PC1 垂直、差异第二大"的方向
- 以此类推

### 方差 = 信息

怎么衡量一个方向"信息量大不大"？看细胞在这个方向上的**方差**（分散程度）：
- 方差大：细胞沿这个方向被拉开，说明这里有区分度，是信号
- 方差小：细胞挤成一团，没区分度，是噪声

所以 PCA 本质是：**按方差从大到小，依次找出互相垂直的新方向。**

### 特征向量与特征值（看懂即可）

数学上，PCA 对基因的**协方差矩阵**做分解，得到：
- **特征向量（eigenvector）**：每一根新坐标轴的方向，也就是主成分
- **特征值（eigenvalue）**：这根轴上的方差大小，衡量它有多重要

你不需要会算，只要建立对应：
- 特征向量 = 新轴的朝向
- 特征值 = 这根轴的"信息量"
- 主成分 = 细胞在新轴上的坐标

### 方差解释比例

每个主成分能解释总方差的百分比，把前若干个的比例累加：

$$
\text{解释比例}(PC_k) = \frac{\lambda_k}{\sum_{j=1}^{p}\lambda_j}
$$

$\lambda_k$ 是第 k 个特征值。前 20 个 PC 若累计解释 80% 方差，说明用 20 维就保留了八成信息。

## 四、手算一个 2 维迷你 PCA

为了看清楚，用最简单的两个细胞、两个基因（实际数据量大得多，机制相同）。

细胞在两个基因上的表达（已标准化、均值归零）：

| 细胞 | 基因 A | 基因 B |
|---|---:|---:|
| 细胞 1 | 1 | 1 |
| 细胞 2 | -1 | -1 |

注意两个基因完全同步（A 涨 B 也涨），信息其实只有 1 维。

### 第 1 步：找方差最大的方向

数据点 (1,1) 和 (-1,-1) 都落在 45° 对角线上。沿这条对角线，细胞被拉得最开（差异最大），所以 **PC1 对准这条 45° 方向**。

### 第 2 步：把细胞投影到 PC1

PC1 方向的单位向量是 $(1/\sqrt{2}, 1/\sqrt{2})$。细胞 1 的投影：

$$
PC1_1 = 1\times\frac{1}{\sqrt{2}} + 1\times\frac{1}{\sqrt{2}} = \sqrt{2} \approx 1.41
$$

细胞 2：

$$
PC1_2 = -1\times\frac{1}{\sqrt{2}} + (-1)\times\frac{1}{\sqrt{2}} = -1.41
$$

### 第 3 步：看 PC2

和 PC1 垂直的方向（另一条对角线）上，两个细胞的投影都是 0，没有任何区分度，所以 PC2 方差为 0，可以直接丢掉。

**结论**：原本 2 维、且两个基因高度冗余的数据，用 1 个主成分就完整表达了。这就是"降维但不丢信息"的直观含义。

## 五、单细胞里 PCA 具体怎么用

### 1. 先挑高变基因

不会拿全部两万基因做 PCA，而是先选 2000 个"高变基因"（细胞间表达差异最大的基因），它们最可能区分细胞类型，也能减少噪声。

### 2. 缩放后跑 PCA

对高变基因标准化（z-score），再做 PCA，得到每个细胞在几十个 PC 上的坐标。

### 3. 选多少个 PC？

不是越多越好，也不是越少越好：
- **ElbowPlot（碎石图）**：画每个 PC 的方差，找"拐点"——拐点之后 PC 方差骤降、多为噪声
- 常用 15–30 个 PC 做后续聚类和 UMAP
- 选太少：丢信息、稀有细胞类型被合并；选太多：引入噪声

### 4. 后续步骤都用 PC

- Harmony 在 PC 空间去批次
- 聚类（KNN + Louvain）在 PC 空间算邻居
- UMAP 把 PC 进一步压到 2 维画图

## 六、PCA vs UMAP vs t-SNE

| | PCA | UMAP | t-SNE |
|---|---|---|---|
| 类型 | 线性降维 | 非线性降维 | 非线性降维 |
| 用途 | 去冗余、供后续计算 | 可视化为主 | 可视化 |
| 保留 | 全局方差 | 局部+部分全局结构 | 主要局部结构 |
| 输出维度 | 几十维 | 通常 2 维 | 2 维 |
| 稳定性 | 确定性结果 | 较稳定 | 受随机种子影响大 |
| 距离含义 | 可解释 | 谨慎解读 | 不能直接比距离 |

**关键**：PCA 是"工作用"的中间表示（后续算法跑在上面），UMAP/t-SNE 是"给人看"的 2 维图。不要在 UMAP 图上用"两点距离"下定量结论。

## 七、代码（R / Seurat）

标准流程里 PCA 就一行，但要配合高变基因：

```r
library(Seurat)
obj <- NormalizeData(obj) |>
  FindVariableFeatures(nfeatures = 2000) |>
  ScaleData() |>
  RunPCA(npcs = 50)

# 看每个 PC 解释的方差，找拐点
ElbowPlot(obj, ndims = 50)

# 看是哪些基因主导了 PC1/PC2
VizDimLoadings(obj, dims = 1:2, reduction = "pca")
DimHeatmap(obj, dims = 1:15, cells = 500, balanced = TRUE)
```

独立用 R 做 PCA（非单细胞场景）：

```r
pca <- prcomp(X, center = TRUE, scale. = TRUE)
summary(pca)              # 各 PC 方差解释比例
scores <- pca$x           # 样本在 PC 上的坐标
loadings <- pca$rotation  # 各变量对 PC 的贡献
```

Python（scanpy / sklearn）：

```python
import scanpy as sc
sc.tl.pca(adata, svd_solver='arpack')
sc.pl.pca_variance_ratio(adata, log=True)
```

## 八、论文里怎么写

**方法**：

> 质控后，对 2000 个高变基因进行标准化并执行主成分分析（PCA）。依据碎石图（Elbow plot）选取前 20 个主成分（累计解释约 80% 方差），用于后续批次校正、基于 KNN 的聚类及 UMAP 可视化。

**结果**：

> 前 20 个主成分累计解释 81.2% 的方差；PCA 显示不同细胞类型在 PC1/PC2 空间已呈现分离趋势，提示主要细胞类群间存在显著的转录组差异。

## 九、最常见的坑

1. **没标准化就做 PCA。**
   表达量数值范围差异大，高表达基因会主导结果。先标准化、z-score。

2. **用全部基因而不是高变基因。**
   大量管家基因和不表达基因会稀释信号、引入噪声。

3. **PC 数量拍脑袋。**
   看 ElbowPlot 拐点，结合数据实际；太少合并稀有细胞、太多带进噪声。

4. **把 UMAP 当 PCA 用。**
   聚类、Harmony 应在 PC 空间做，不是在 2 维 UMAP 上。

5. **在 UMAP/t-SNE 上比距离下结论。**
   非线性嵌入的距离和簇大小不能直接定量，只用于可视化。

6. **把主成分当具体生物学实体。**
   PC 是数学组合，要结合 loadings（哪些基因贡献大）才能谨慎解释，不能直接说"PC1 就是某通路"。

## 十、判断清单

用 PCA 前问：

1. 数据是不是高维、且存在大量冗余/噪声？
2. 特征标准化了吗？
3. 单细胞是否先选了高变基因？
4. 用 ElbowPlot 确定 PC 数量了吗？
5. 后续聚类/整合是否在 PC 空间进行？
6. 可视化是否另用 UMAP，而不是直接画 PC 当最终图？

**一句话总结**：PCA 通过旋转坐标轴，按方差从大到小找出少数几个"最能拉开细胞差异"的主成分，把上万维压缩到几十维且尽量不丢信息；在单细胞流程里它是高变基因之后、Harmony/聚类/UMAP 之前的关键降维步骤，主要服务于后续计算，而不是直接拿来当最终展示图。
