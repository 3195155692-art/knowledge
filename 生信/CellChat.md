## 一、先搞清楚：CellChat 在单细胞分析里干嘛用？

**场景**：你的 GBM 肿瘤微环境里有肿瘤细胞、小胶质细胞、巨噬细胞、T 细胞、星形胶质细胞、内皮细胞等。它们不是各干各的，而是不断"发信号"：比如肿瘤细胞分泌某种配体，结合到巨噬细胞表面的受体，把巨噬细胞"策反"成促进肿瘤生长的状态。

CellChat 是一个 R 包，专门从单细胞表达数据里**推断细胞类型之间的通讯（cell-cell communication）**，核心是基于**配体-受体（ligand-receptor, L-R）互作**，量化"谁在向谁发信号、信号有多强、走的是哪条通路"，并比较对照组和治疗组之间通讯网络的变化。

它回答的问题：
- 哪些细胞类型之间存在显著通讯？
- 涉及哪些配体-受体对、哪些信号通路？
- 治疗后哪些通讯被增强或削弱？

---

## 二、为什么要做细胞通讯分析？

### 1. 单细胞注释只告诉你"有什么细胞"，不告诉你"它们怎么互动"

肿瘤微环境的关键机制往往在**互作**里（免疫抑制、血管生成、肿瘤-神经互作），单看每个细胞的表达谱看不到这种关系。

### 2. 找机制和潜在干预靶点

一条异常增强的配体-受体通路，可能就是治疗靶点（阻断该信号）。

### 3. 解释治疗如何重塑微环境

比较治疗前后通讯网络，能说明药物是通过切断哪条"信号线路"起效的。

---

## 三、核心原理：配体-受体 + 表达量加权

### 直觉：无线电收发

把每个细胞类型想成一个电台：
- **配体**是发送方发出的信号（发送方要表达配体基因）
- **受体**是接收方的天线（接收方要表达受体基因）
- 只有"发得够强、收得到"，这条通讯才算成立；信号强度由双方表达量共同决定

### 第 1 步：依赖配体-受体数据库

CellChat 内置经过整理的 L-R 互作数据库（含受体复合物、协同因子、信号通路注释）。只有数据库里记录的互作才会被评估，避免凭空配对。

### 第 2 步：计算通讯概率（强度）

对每一对"发送细胞群 → 接收细胞群"和每个 L-R 对，结合：
- 发送群配体的平均表达
- 接收群受体的平均表达
- 受体复合物（多个亚基要同时表达，取"短板"）
- 协同刺激/抑制因子

用一个概率模型算出一个通讯强度值。直觉上可简化理解为：

$$
\text{通讯强度} \propto \text{配体表达（发送方）} \times \text{受体表达（接收方）}
$$

### 第 3 步：统计显著性与网络构建

用置换/背景模型判断哪些通讯显著高于随机，把所有细胞群连成一张有方向、有权重的通讯网络。

### 第 4 步：通路级和全局分析

- **incoming（接收）/ outgoing（发送）**：每个细胞群收信号、发信号的强弱
- 按信号通路汇总（如 SPP1、CXCL、TGF-β 通路）
- 网络层面的角色（分泌者、接收者、中介）

## 四、迷你图解：算一条通讯

假设肿瘤细胞发配体 L，巨噬细胞带受体 R，用简化的表达均值（已标准化）：

| 细胞群 | 配体 L 表达 | 受体 R 表达 |
|---|---:|---:|
| 肿瘤细胞 | 3.0 | 0.2 |
| 巨噬细胞 | 0.5 | 2.0 |

"肿瘤 → 巨噬"这条 L-R 通讯，简化强度：

$$
P_{L\to R} = \text{配体}_{\text{肿瘤}} \times \text{受体}_{\text{巨噬}} = 3.0 \times 2.0 = 6.0
$$

反方向"巨噬 → 肿瘤"：

$$
P_{R\to L} = 0.5 \times 0.2 = 0.1
$$

**解读**：肿瘤→巨噬方向的信号（6.0）远强于反向（0.1），说明主要是肿瘤在向巨噬发信号。这与"肿瘤策反巨噬"的生物学假设方向一致。实际 CellChat 还会加复合物、协同因子和统计校正，数字更复杂，但"双方表达相乘、有方向性"的核心直觉不变。

## 五、常见图表与输出

| 图表 | 展示什么 |

| Circle plot（圆圈图） | 细胞群围成圈，箭头粗细=通讯强度，最经典 |

| 组间对比 | 治疗 vs 对照通讯强度差异、通路富集差异 |

## 六、CellChat vs 其他通讯工具

| 工具 | 特点 | 强项 | 注意 |
|---|---|---|---|
| CellChat | 概率模型、通路级分析、可视化丰富 | 网络/角色分析、组间比较 | 依赖内置数据库 |
| CellPhoneDB | 复合物受体处理好 | 受体复合物、统计检验 | Python 生态 |
| NicheNet | 结合下游靶基因表达 | 预测配体对接收细胞的调控 | 侧重"配体→靶点" |
| SingleCellSignalR | 简单快速 | 大规模、易上手 | 模型较简单 |
| NicheNet/Cellinker | 多数据库整合 | 互作覆盖广 | 需核对来源 |

**选择原则**：要做完整网络、通路角色和组间对比 → CellChat；想预测配体如何改变接收细胞的下游转录 → 叠加 NicheNet。

## 七、代码（R / CellChat）

```r
library(CellChat)
# 输入：Seurat 对象 + 细胞类型注释
cellchat <- createCellChat(object = obj, group.by = "celltype")
CellChatDB <- CellChatDB.human          # 小鼠用 CellChatDB.mouse
cellchat@DB <- CellChatDB

# 计算表达、通讯概率、显著性
cellchat <- subsetData(cellchat) |>
  identifyOverExpressedGenes() |> identifyOverExpressedInteractions() |>
  computeCommunProb(raw.use = TRUE) |>
  filterCommunication(min.cells = 5) |>
  computeCommunProbPathway() |>
  netAnalysis_computeCentrality()

# 经典可视化
netVisual_circle(cellchat@net$count, weight.scale = TRUE)
netVisual_heatmap(cellchat, measure = "weight")
netVisual_bubble(cellchat, sources.use = 1, targets.use = c(2,3))
```

对照组 vs 治疗组比较（各建一个对象后合并）：

```r
cellchat_merged <- mergeCellChat(list(ctrl = cc_ctrl, treat = cc_treat),
                                 add.names = c("ctrl", "treat"))
netVisual_diffInteraction(cellchat_merged, weight.scale = TRUE)
compareInteractions(cellchat_merged, show.legend = FALSE)
```

## 八、论文里怎么写

**方法**：

> 基于细胞类型注释，使用 CellChat（内置配体-受体数据库）推断细胞间通讯。结合发送群配体与接收群受体（含复合物及协同因子）的表达计算通讯概率，经置换检验筛选显著互作，并在信号通路层面分析各细胞群的发送/接收角色。分别在对照组与治疗组构建网络并比较通讯强度差异。

**结果**：

> 共识别出 X 条显著配体-受体互作。肿瘤细胞→巨噬细胞的 SPP1 信号在治疗组显著减弱（权重由 a 降至 b），提示该治疗可能通过削弱肿瘤对巨噬细胞的招募/极化信号重塑微环境。

## 九、最常见的坑

1. **把推断当因果证据。**
   CellChat 给的是"基于共表达的相关性推断"，不能证明真实发生了信号传导，需实验（共培养、阻断、空间邻近）验证。

2. **物种数据库选错。**
   人源用 CellChatDB.human、小鼠用 CellChatDB.mouse，基因命名（MT-/mt-）也要对应。

3. **忽略受体复合物。**
   多亚基受体要所有亚基都表达，单看一个亚基会高估通讯。

4. **细胞类型注释错误传导。**
   通讯建立在注释上，注释错了网络全错；先保证注释可靠。

5. **只看强度不看显著性和样本量。**
   小细胞群的高强度可能不稳定，要结合 min.cells、p 值和重复样本。

6. **组间比较不做归一化。**
   两组细胞数、测序深度不同，需用 CellChat 的合并/标准化流程再比，不能直接比原始计数。

7. **忽视空间前提。**
   单细胞解离后丢失位置信息，两个细胞群可能根本不在解剖上相邻；重要结论最好结合空间转录组或共定位分析。

## 十、判断清单

用 CellChat 前问：

1. 细胞类型注释是否可靠、物种数据库选对了吗？
2. 是想描述"通讯网络"，还是要做因果/靶点推断（后者需实验）？
3. 受体复合物、协同因子是否被正确处理？
4. 组间比较是否走了合并归一化流程？
5. 关键通讯是否计划用空间/共定位或功能实验验证？
6. 是否避免了仅凭共表达就下"必然互作"的结论？

**一句话总结**：CellChat 基于配体-受体数据库，用发送方配体和接收方受体的表达量加权计算有方向的通讯概率，构建并比较细胞间信号网络，擅长揭示肿瘤微环境中"谁在向谁发信号、走哪条通路、治疗后如何变化"；但它是基于共表达的相关性推断而非因果证据，关键结论需结合空间邻近和功能实验验证。
