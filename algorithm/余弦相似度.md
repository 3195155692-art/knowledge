## 一、先搞清楚：余弦相似度在医学里干嘛用？

**场景 1**：你有一位患者的基因表达谱（测了 20000 个基因的表达量），想知道他和数据库里哪一种已知的癌症亚型最像，从而辅助诊断。

**场景 2**：你做了一张胸部 CT，AI 提取了 1024 维影像特征，想找数据库里最相似的病例来辅助诊断。

**场景 3**：你在做文本挖掘，想找和某篇综述主题最相关的 100 篇论文。

这些问题的本质都是：**两个"特征向量"有多相似？**

余弦相似度就是衡量两个向量相似度的最常用指标之一。

---

## 二、什么是"向量"？

先别被"向量"吓到。在医学数据里：

- 一个患者的 5 个化验值（HbA1c、BMI、血压、LDL、肌酐）= 一个 5 维向量
- 一张病理切片提取的 1024 个特征 = 一个 1024 维向量
- 一篇论文的 TF-IDF 词频 = 一个几万维向量

向量就是"一串数字"，代表一个对象的特征。

---

## 三、余弦相似度到底在干嘛？

想象你站在原点，两个向量是两根箭头。余弦相似度看的是：**这两根箭头的夹角有多小？**

- 夹角 0°（两根箭头同向）：余弦 = 1，完全相似
- 夹角 90°（垂直）：余弦 = 0，完全不相关
- 夹角 180°（反向）：余弦 = -1，完全相反

**关键洞察：余弦相似度只看方向，不看长度。**

这和欧氏距离很不一样：
- 欧氏距离：两个点离得越远越不相似
- 余弦相似度：两个向量方向越一致越相似，不管长度

举个医学例子：

| 患者 | HbA1c | BMI |
|---|---:|---:|
| 张三 | 8 | 30 |
| 李四 | 9 | 33.75 |
| 王五 | 6 | 20 |

李四的数值是张三的 1.125 倍（方向一样，只是整体偏高），王五方向就不一样了。

余弦相似度：
- 张三 vs 李四：cos ≈ 1.0（方向几乎一样）
- 张三 vs 王五：cos ≈ 0.97（方向有差异）

这在基因表达里特别有用：两个患者基因表达谱"模式相似"，哪怕一个整体表达高、一个整体表达低，余弦相似度依然很高。

## 四、具体算一遍

两个向量：

$$
A = (a_1, a_2, ..., a_n)
$$
$$
B = (b_1, b_2, ..., b_n)
$$

余弦相似度公式：

$$
\cos(\theta) = \frac{A \cdot B}{\|A\| \|B\|} = \frac{\sum_{i=1}^{n} a_i b_i}{\sqrt{\sum a_i^2} \sqrt{\sum b_i^2}}
$$

不用记公式，软件一行就算出来。但你要知道分子分母在干嘛：
- 分子：两个向量对应位置相乘再相加（点积）——衡量"同向程度"
- 分母：两个向量各自的长度相乘——用来归一化，消除长度影响

### 手算一个简单例子

患者 A：(HbA1c=8, BMI=30)
患者 B：(HbA1c=9, BMI=33.75)

分子：
$$
8 \times 9 + 30 \times 33.75 = 72 + 1012.5 = 1084.5
$$

分母：
$$
\|A\| = \sqrt{8^2 + 30^2} = \sqrt{964} \approx 31.05
$$
$$
\|B\| = \sqrt{9^2 + 33.75^2} = \sqrt{1229.06} \approx 35.06
$$
$$
\|A\| \times \|B\| \approx 31.05 \times 35.06 \approx 1088.6
$$

余弦相似度：
$$
\cos(\theta) = 1084.5 / 1088.6 \approx 0.996
$$

非常接近 1，说明两个患者的特征模式几乎一样。

## 五、余弦相似度的取值范围和解释

| 余弦相似度 | 含义 |
|---:|---|
| 1.0 | 完全同向，模式完全一致 |
| 0.9–1.0 | 高度相似 |
| 0.7–0.9 | 中等偏上相似 |
| 0.5–0.7 | 中等相似 |
| 0.3–0.5 | 弱相似 |
| 0.0 | 完全不相关（垂直） |
| <0 | 方向相反（负相关） |

注意：余弦相似度在医学里几乎都是正数（因为特征值都是正数，比如基因表达量、影像特征强度），所以范围通常在 0–1 之间。

## 六、余弦相似度 vs 欧氏距离：什么时候用哪个？

| | 余弦相似度 | 欧氏距离 |
|---|---|---|
| 衡量什么 | 方向（模式） | 绝对距离 |
| 对"整体缩放"敏感吗 | 不敏感（A 和 2A 完全相似） | 敏感（A 和 2A 距离很远） |
| 对数值大小敏感吗 | 不敏感 | 敏感 |
| 典型场景 | 基因表达谱、文本相似度、推荐系统 | 患者直接比较、K-means 聚类 |

**什么时候用余弦？**

- 你关心的是"模式像不像"，不是"数值大不大"
- 高维稀疏数据（比如文本词频，大部分词是 0）
- 两个样本整体表达水平不同，但变化趋势相似

**什么时候用欧氏距离？**

- 你关心的是"两个患者差多少"
- 特征已经标准化了，每个维度都有实际意义
- K-means 聚类（默认用欧氏距离）

## 七、医学里的具体应用

### 1. 基因表达亚型分析

对每对患者算基因表达谱的余弦相似度，画热图（similarity matrix）。相似度高的患者会聚在一起，提示可能属于同一分子亚型。

### 2. 影像组学相似病例检索

患者拍了 CT，AI 提取影像特征向量，在数据库里找余弦相似度最高的 N 个病例，给医生参考"这个病灶和以前哪些病例像"。

### 3. 文献检索 / 论文推荐

把论文和 query 都转成向量，算余弦相似度，按相似度排序返回最相关的论文。PubMed、Google Scholar 背后都有类似机制。

### 4. 推荐系统

"和你相似的患者也用了这个药……"——本质就是算患者特征向量的余弦相似度。

## 八、R 和 Python 怎么算

### R

```r
# 两个向量
A <- c(8, 30)
B <- c(9, 33.75)

# 余弦相似度函数
cosine_sim <- function(a, b) {
  sum(a * b) / (sqrt(sum(a^2)) * sqrt(sum(b^2)))
}

cosine_sim(A, B)
# [1] 0.9996
```

批量算患者两两相似度：

```r
# df 是矩阵，每行一个患者，每列一个特征
library(lsa)
sim_matrix <- cosine(t(df))  # t() 转置因为 cosine() 按列算
# 输出一个 n×n 的相似度矩阵
```

画热图：

```r
library(pheatmap)
pheatmap(sim_matrix, show_rownames = FALSE, show_colnames = FALSE)
```

### Python

```python
from sklearn.metrics.pairwise import cosine_similarity
import numpy as np

A = np.array([8, 30]).reshape(1, -1)
B = np.array([9, 33.75]).reshape(1, -1)

cosine_similarity(A, B)
# array([[0.9996]])
```

批量：

```python
# X 是 n_samples × n_features 的矩阵
sim = cosine_similarity(X)
# sim[i][j] 就是第 i 个和第 j 个样本的余弦相似度
```

## 十、最常见的坑

1. **特征没标准化就直接算余弦。**
   虽然余弦对整体缩放不敏感，但不同量纲的特征（比如 HbA1c 在 5–10，BMI 在 18–40）混在一起还是会让数值大的特征主导结果。建议先标准化或归一化。

2. **把余弦相似度当"相关系数"。**
   余弦相似度和 Pearson 相关系数在某些情况下很像，但不完全一样。Pearson 是中心化后的余弦相似度。不要混用。

3. **高维数据直接算余弦，没考虑稀疏性。**
   文本、基因表达这种几万维的数据，大部分是 0。余弦相似度在这种稀疏数据上效果很好，但如果 dense 数据（比如临床检验值），欧氏距离或相关系数可能更合适。

4. **相似度高就以为是"同一种病"。**
   余弦相似度只说明特征模式像，不说明病理机制一样。必须结合临床和病理验证。

## 十一、一张表总结

| 问题 | 答案 |
|---|---|
| 余弦相似度衡量什么 | 两个向量方向的夹角 |
| 取值范围 | -1 到 1（医学数据通常 0 到 1） |
| 1 意味着什么 | 方向完全一致 |
| 0 意味着什么 | 完全不相关（垂直） |
| 对整体缩放敏感吗 | 不敏感 |
| 典型医学场景 | 基因表达谱相似、影像特征检索、文献推荐 |
| 和欧氏距离的区别 | 余弦看方向，欧氏看绝对距离 |
| 和相关系数的区别 | 余弦不中心化，Pearson 中心化后再算余弦 |
