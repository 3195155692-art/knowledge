## 一、先搞清楚：随机森林干嘛用？

**场景**：你要建一个临床预测模型，比如根据年龄、血压、肌酐、心电图等指标，预测患者住院期间是否发生急性肾损伤。数据有缺失、变量间关系复杂、还可能有交互，单一 Logistic 回归未必捕捉得好。

随机森林（Random Forest，RF）是一种**集成学习**算法：它训练很多棵决策树，再让所有树"投票"决定最终结果。它对表格数据稳健、能处理非线性和交互、自带特征重要性，是临床预测和特征筛选中非常常用的模型，也常作为 XGBoost 之外的强基线。

可做分类，也可做回归。

---

## 二、先理解决策树（随机森林的基本单元）

决策树像一连串"是非题"，每个节点按一个变量和阈值分裂：

```
肌酐 > 133？
├─ 是 → 年龄 > 70？
│        ├─ 是 → 高风险
│        └─ 否 → 中风险
└─ 否 → 低风险
```

### 分裂准则：Gini 不纯度

分类时衡量节点"混杂程度"：

$$
\text{Gini} = 1 - \sum_{k} p_k^2
$$

$p_k$ 是该节点中第 k 类的比例。
- 纯节点（全是一类）：Gini = 0
- 两类各半：Gini = 0.5

每次分裂选让 Gini 下降最多的变量和阈值。

### 单棵树的问题

决策树容易**过拟合**：树长得太深，会把训练集的噪声也学进去，换一批数据就不稳。

## 三、随机森林核心：Bagging + 随机特征

### 直觉：专家会诊投票

与其相信一位容易固执己见的医生（单棵树），不如请来几百位医生，每位看的病例和侧重点略有不同，最后集体投票——个别医生的偏差会被多数票抵消，整体更稳更准。

### 两大"随机"

1. **样本随机（Bootstrap/Bagging）**：每棵树从原始数据中有放回地抽取同样数量的样本训练，于是各棵树看到的数据略有不同。
2. **特征随机**：每次分裂时，只从全部变量里随机抽一小部分候选（如 $\sqrt{p}$ 个），避免所有树都被同一个强变量主导、长得太像。

### 投票/平均

- 分类：所有树投票，取多数类
- 回归：取所有树预测的平均

### 为什么泛化更好

树之间因"样本+特征"双重随机而**去相关**，集成后方差显著下降；即使单棵树过拟合，平均后也能抵消，整体对噪声更鲁棒。

## 四、手算迷你例子

### 例 1：Gini 不纯度

一个节点有 10 个患者，5 个发病、5 个未发病：

$$
\text{Gini} = 1 - (0.5^2 + 0.5^2) = 1 - 0.5 = 0.5
$$

若按某变量分裂后，一个子节点全是发病（100%）：

$$
\text{Gini} = 1 - 1^2 = 0
$$

**解读**：分裂把混杂节点变成纯节点，Gini 从 0.5 降到 0，这正是一次"好分裂"。

### 例 2：三棵树投票

假设 3 棵树对同一患者的分类结果：

| 树 | 预测 |
|---|---|
| 树1 | 发病 |
| 树2 | 发病 |
| 树3 | 未发病 |

多数票 2:1，最终预测"发病"。随机森林不会因单棵树的偶然判断而翻转结果。

### OOB 袋外样本

每棵树用 Bootstrap 抽样时，约 36.8% 的样本没被抽到（袋外，OOB），可直接用来评估这棵树，无需额外划分验证集，这是随机森林自带的近似无偏误差估计。

## 五、关键概念与输出

| 概念 | 含义/用途 |
|---|---|
| `n_estimators` | 树的数量，越多越稳，边际收益递减 |
| `max_depth` | 树深，限制深度可防过拟合 |
| `min_samples_leaf` | 叶节点最小样本数 |
| `max_features` | 分裂时候选特征数，控制随机性 |
| 特征重要性 | 基于该变量带来的 Gini/不纯度下降，用于筛选 |
| OOB score | 袋外误差，内部验证 |
| 近邻距离/Proximity | 可用于异常检测、缺失填补 |

## 六、随机森林 vs Logistic vs XGBoost

| | 随机森林 | Logistic 回归 | XGBoost |
|---|---|---|---|
| 类型 | Bagging 树集成 | 线性模型 | Boosting 树集成 |
| 非线性/交互 | 自动捕捉 | 需手动构造 | 自动捕捉 |
| 可解释性 | 中等（重要性） | 强（OR、系数） | 中等 |
| 概率校准 | 一般，需校准 | 天然概率 | 需校准 |
| 过拟合倾向 | 低（平均） | 低 | 可调、较强 |
| 缺失值 | 可处理 | 需填补 | 原生处理 |
| 适用 | 稳健基线、筛选 | 可解释建模 | 高精度竞赛/预测 |

## 八、论文里怎么写

**方法**：

> 采用随机森林（500 棵树，每节点分裂候选变量为 $\sqrt{p}$，叶节点最小样本数 5），以袋外误差评估性能并输出变量重要性。模型预测概率经校准后用于风险评估，区分度以 AUROC 衡量。

**结果**：

> 模型在验证集 AUROC 为 0.90（OOB 估计 0.88），肌酐、年龄与收缩压为最重要的三个预测变量；校准曲线显示预测与实际事件吻合良好。

## 九、最常见的坑

1. **概率不校准就当风险值。**
   随机森林投票产生的概率可能偏离真实频率，需 Platt/等温/校准曲线处理。

2. **不限制树深、小样本过拟合。**
   虽有平均保护，单棵树过深仍可能降低泛化，调 max_depth、min_samples_leaf。

3. **特征重要性被高基数/相关变量误导。**
   连续变量、类别多的变量重要性易偏高；相关变量会分摊重要性，可结合置换重要性。

4. **忽略超参调优。**
   全用默认值未必最优，至少调 n_estimators、max_features、叶节点样本数。

5. **数据泄漏。**
   预处理、特征选择要在训练折内做，否则 OOB/CV 结果虚高。

6. **当因果推断工具。**
   特征重要性只说明预测贡献，不等于因果效应，不能据此下"致病"结论。

7. **类别不平衡不处理。**
   需 class_weight、分层抽样或重采样，否则模型偏向多数类。

## 十、判断清单

用随机森林前问：

1. 是不是表格数据、且关系可能非线性/有交互？
2. 是否需要稳健基线或特征重要性？
3. 树数、深度、候选特征数等超参调了吗？
4. 概率是否校准、类别不平衡处理了吗？
5. 特征重要性是否用了更稳健的置换重要性？
6. 是否避免把预测重要性当因果证据？
7. 预处理是否在训练折内完成、防止泄漏？

**一句话总结**：随机森林通过"样本有放回抽样 + 分裂时随机选特征"训练大量去相关的决策树，再投票或平均，显著降低单棵树的方差和过拟合，能自动处理非线性与交互、自带 OOB 误差和特征重要性，是表格临床数据的稳健基线；但它的概率需校准、重要性不等于因果，且要注意超参调优和数据泄漏。
