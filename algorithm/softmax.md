## 一、先搞清楚：softmax 干嘛用？

**场景**：Logistic 回归只能回答"是/否"两类问题。但临床上你常要分多类，比如根据影像和检验，把肺结节判断为**良性 / 原发肺癌 / 转移瘤**三类；或把心电图心搏分成**正常 / 室早 / 房早 / 束支阻滞**多类。

神经网络在多分类时，最后一层会先输出几个原始分数（logits，可正可负、没有范围），**softmax 函数把这些分数转换成一组概率**：每个类别一个 0 到 1 之间的数，且全部加起来等于 1。

它是多分类神经网络（包括 Transformer、CNN 分类头）输出层的标准选择。

---

## 二、为什么需要 softmax？

### 1. 原始分数不能当概率

logits 可能是 [2, 1, 0]，也可能是负数，不满足"概率在 0–1 之间、总和为 1"的要求，没法直接解释成"有多大把握"。

### 2. 要同时表达"相对倾向"

softmax 不是孤立看每个分数，而是让所有类别**互相比较**后分配概率，突出最可能的类别。

### 3. 可导，便于训练

它是平滑函数，梯度可以回传，能和交叉熵损失配合做反向传播。

---

## 三、核心原理与公式

对一组 logits $z_1, z_2, \dots, z_K$，第 i 个类别的 softmax：

$$
\sigma(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}
$$

- $e^{z_i}$：指数函数，保证结果恒为正，并**放大分数差距**（分数越高，被指数放大得越多）
- 分母：所有类别指数之和，做归一化，保证总和为 1

### 直觉：考试排名换算成"信心百分比"

把 logits 想成几个候选人的原始得分，softmax 像按"指数加权"把总分（归一化分母）切成百分比：得分最高的候选人拿走最大一块，且领先优势会被指数放大；但只要不是碾压，其他人仍分到非零概率。

### 为什么用指数而不是直接用原分数？

1. 原分数可能为负，指数恒正；
2. 指数让"差距"对概率更敏感，区分更明显；
3. 数学性质好、可导，且与交叉熵、最大似然天然对应。

### 数值稳定性：先减最大值

当 logits 很大时，$e^{1000}$ 会溢出。利用"分子分母同减一个常数结果不变"：

$$
\sigma(z_i) = \frac{e^{z_i - c}}{\sum_j e^{z_j - c}}, \quad c = \max_j z_j
$$

实际框架内部都这么做，你不用手动处理，但要知道为什么。

## 四、手算迷你例子

三分类，网络输出 logits：

$$
z = [2, 1, 0]
$$

### 第 1 步：取指数

$$
e^2 = 7.39,\quad e^1 = 2.72,\quad e^0 = 1
$$

### 第 2 步：求分母

$$
\sum = 7.39 + 2.72 + 1 = 11.11
$$

### 第 3 步：归一化

$$
p_1 = \frac{7.39}{11.11} = 0.665,\quad p_2 = \frac{2.72}{11.11} = 0.245,\quad p_3 = \frac{1}{11.11} = 0.090
$$

**结果**：概率 [0.665, 0.245, 0.090]，总和 1.0。模型对类别 1 最有把握（66.5%），但并不绝对，类别 2 仍有 24.5%。

### 对比：放大差距会怎样

若 logits 变成 [10, 1, 0]，指数差距极大，$p_1$ 会接近 1.0。这说明**softmax 对分数差距非常敏感**，logits 拉开后概率会变得很"自信"。

---

## 五、softmax 与相关概念

| 概念 | 关系 |
|---|---|
| argmax | 直接取最大分数对应的类别（硬、不可导）；softmax 是"软版 argmax"，给概率 |
| Logistic/sigmoid | 二分类；两类时 softmax 与 sigmoid 等价 |
| 交叉熵损失 | 多分类标配，衡量 softmax 概率与真实标签的差距 |
| 温度 T | $\sigma(z_i/T)$，T 大分布变平滑、T 小更尖锐（蒸馏常用） |

交叉熵（单个样本）：

$$
L = -\sum_{i=1}^{K} y_i \log(p_i)
$$

$y_i$ 是真实标签的 one-hot（真实类别为 1，其余 0），所以实际只惩罚"真实类别的预测概率太低"。

## 六、代码（PyTorch）

```python
import torch
import torch.nn as nn

logits = torch.tensor([[2.0, 1.0, 0.0]])

# 方式一：分开调用
probs = nn.Softmax(dim=1)(logits)
print(probs)                 # tensor([[0.665, 0.245, 0.090]])

# 训练时通常直接用 CrossEntropyLoss（内部已含 softmax，不要再手动加）
criterion = nn.CrossEntropyLoss()
target = torch.tensor([0])   # 真实类别索引
loss = criterion(logits, target)
```

R 实现：

```r
softmax <- function(z) exp(z) / sum(exp(z))
softmax(c(2, 1, 0))          # 0.665 0.245 0.090
```

## 七、论文里怎么写

**方法**：

> 网络末端全连接层输出 K 个 logits，经 softmax 函数归一化为类别概率，取概率最大者作为预测类别；模型以交叉熵为损失函数训练。

**结果**：

> 模型对该样本预测为类别"原发肺癌"的概率为 0.83，第二可能类别"转移瘤"为 0.11，预测置信度较高。

## 八、最常见的坑

1. **重复 softmax。**
   `nn.CrossEntropyLoss` 内部已含 softmax，若先手动 softmax 再传进去，相当于做两次，损失异常。训练时直接喂 logits。

2. **把 softmax 概率当校准过的置信度。**
   深度网络的 softmax 概率往往过度自信，0.95 不代表真实正确率 95%，需要校准（温度缩放/可靠性图）。

3. **忽略数值溢出。**
   自己实现时要先减最大值，否则大 logits 得 NaN。

4. **类别不平衡时不处理。**
   softmax 会偏向多数类，需加权损失、重采样等。

5. **误以为概率小=不可能。**
   0.09 仍有 9% 可能，高风险临床场景不能只看 top1，要结合 top2 和阈值。

6. **在需要互斥多标签时用错。**
   一个样本可同时属于多个非互斥类别时，应改用多个 sigmoid 而不是单个 softmax。

## 九、判断清单

用 softmax 前问：

1. 是不是**互斥的多分类**问题（多标签则用 sigmoid）？
2. 训练损失是否用交叉熵、且没有重复 softmax？
3. 自实现是否做了减最大值防溢出？
4. 概率是否需要校准后再当置信度解释？
5. 类别不平衡处理了吗？
6. 临床决策是否关注了 top2/top3 而非只看 top1？

**一句话总结**：softmax 用指数归一化把一组任意实数 logits 变成总和为 1 的类别概率，放大高分项、恒正且可导，是多分类神经网络输出层的标准选择，常与交叉熵配合训练；但它给出的概率常过度自信、需要校准，且训练时不要再手动叠加 softmax。
