## 一、先搞清楚：K-means 在医学里干嘛用？

**研究场景**：你手上有 200 例 2 型糖尿病患者，每人测了一堆指标：
- HbA1c（糖化血红蛋白）
- BMI
- 空腹血糖
- HOMA-IR（胰岛素抵抗指数）
- 病程

你想知道：**这些患者能不能自然分成几种"亚型"？** 比如是不是有人"瘦但胰岛素抵抗"，有人"胖但胰岛功能还行"？

这种"事先不知道分组，让数据自己聚成几类"的方法，叫**聚类分析**。K-means 是最经典、最常用的一种。

和回归的区别：
- 回归：事先知道 Y（比如有没有并发症），找 X 和 Y 的关系
- K-means：事先不知道分组，让 X 自己聚成几堆

---

## 二、K-means 到底在干嘛？

一句话：**把数据点分成 K 堆，让同一堆里的点尽量近，不同堆之间尽量远。**

"K"就是你事先指定要分几类。"Means"是每一堆的中心点（均值）。

### 算法步骤（超通俗版）

1. **你先指定 K**：比如 K=3，想分成 3 型。
2. **随机放 3 个中心点**：在数据空间里随便放 3 个点当"临时中心"。
3. **给每个患者归类**：算每个患者离哪个中心最近，就归到哪一类。
4. **重新算中心**：每一类里所有患者的均值，作为新的中心点。
5. **重复 3–4 步**：中心点会一点点挪位置，直到不再变（收敛）。

就像在操场上让学生站队：先随便放 3 个班长，学生跑向离自己最近的班长；然后每个班重新选班长（全班平均位置）；学生再跑向新班长……直到大家不动了，站队完成。

## 三、具体算一个超简单的例子

假设只有 5 个患者，只有 2 个指标：HbA1c 和 BMI。

| 患者 | HbA1c (%) | BMI (kg/m²) |
|---|---:|---:|
| A | 7.0 | 22 |
| B | 7.2 | 23 |
| C | 9.5 | 32 |
| D | 9.8 | 33 |
| E | 7.1 | 24 |

一眼看上去就分两堆：A、B、E 是一堆（HbA1c 低、BMI 低），C、D 是一堆（HbA1c 高、BMI 高）。

假设 K=2：

1. 随机选 A 和 C 当初始中心：中心1=(7.0, 22)，中心2=(9.5, 32)
2. 算每个人离哪个中心近：
   - B：离中心1近 → 归到类1
   - D：离中心2近 → 归到类2
   - E：离中心1近 → 归到类1
3. 重新算中心：
   - 类1（A、B、E）：HbA1c=(7.0+7.2+7.1)/3=7.1，BMI=(22+23+24)/3=23
   - 类2（C、D）：HbA1c=(9.5+9.8)/2=9.65，BMI=(32+33)/2=32.5
4. 再算一遍距离，发现没人需要换组了，收敛。

结果：
- **类1**：A、B、E（低 HbA1c、低 BMI）
- **类2**：C、D（高 HbA1c、高 BMI）

## 四、K 怎么选？——这是最关键的问题

K-means 最大的坑：**你必须事先指定 K（分几类）**。但临床上你哪知道分几类？

常用方法：

### 1. 肘部法（Elbow Method）

画一条曲线：横轴是 K（从 1 到 10），纵轴是"类内距离总和"（SSE，类内点到中心的距离平方和）。

K 增大时，SSE 会一直下降。但下降到某个点后，下降速度突然变慢——那个拐点就像手臂的"肘部"，对应的 K 就是比较合理的选择。

比如 K=2→3 时 SSE 从 100 降到 50（降了 50），K=3→4 时只从 50 降到 42（降了 8），那 K=3 可能就合适。

### 2. 轮廓系数（Silhouette Score）

轮廓系数范围 -1 到 1，越接近 1 说明聚类越好。

对每个 K 算一个轮廓系数，选最大的那个。

### 3. 临床可解释性最重要

统计指标只是参考，**分出来的类必须在临床上说得通**。

比如肘部法说 K=4 最好，但你分出来 4 类中有一类只有 5 个患者，而且和另一类临床特征差不多——那不如选 K=3。

**医学研究里，聚类结果一定要回到临床去解释：这几型患者在预后、治疗反应上有没有真的差别？** 如果分出来的型和结局没关系，分了也白分。

## 五、距离怎么算？——为什么要标准化

K-means 靠"距离"归类。但问题来了：

- HbA1c 范围 5–12，数值在 7 左右
- BMI 范围 18–40，数值在 25 左右
- 空腹血糖范围 4–15，数值在 8 左右

如果直接算距离，BMI 数值大，对距离的影响就比 HbA1c 大——这等于让 BMI"说了算"，不公平。

**解决办法：标准化（Standardization）**

把每个变量转换成"均值 0，标准差 1"的标准分：

$$
Z = \frac{X - \bar{X}}{SD}
$$

这样每个变量都在同一尺度上，谁也不占谁便宜。

**K-means 之前必须标准化！** 这是新手最常忘的一步。

## 六、K-means 的输出怎么读？

假设你对 200 个糖尿病患者做了 K=3 的 K-means 聚类，结果：

| 特征 | 类1（n=80） | 类2（n=70） | 类3（n=50） |
|---|---:|---:|---:|
| HbA1c (%) | 7.2 | 8.5 | 9.8 |
| BMI (kg/m²) | 23 | 30 | 26 |
| 空腹血糖 (mmol/L) | 8.0 | 9.5 | 12.0 |
| HOMA-IR | 1.5 | 4.2 | 2.8 |
| 病程（年） | 3 | 5 | 10 |

你给三型起个临床名字：
- **类1**："轻度代谢型"——HbA1c 低、瘦、病程短
- **类2**："肥胖胰岛素抵抗型"——BMI 高、HOMA-IR 高
- **类3**："重度胰岛功能衰竭型"——HbA1c 很高、病程长、BMI 中等

然后你可以进一步分析：这三型患者后续糖尿病肾病、视网膜病变的发生率有没有差异？治疗反应有没有差异？

这就是"糖尿病亚型分型"的经典思路。

## 七、K-means 的假设和局限

### 1. 假设类是"球形"的

K-means 默认各类是大小差不多的球形。如果真实数据是月牙形、环形，K-means 就分不好。这时候可以考虑 DBSCAN、层次聚类。

### 2. 对初始中心敏感

不同的随机初始中心，可能分出不同结果。所以实践中要跑很多次（比如 100 次），选 SSE 最小的那次。

### 3. 对异常值敏感

一个极端值会把中心点拉偏。先看看有没有异常值，必要时去掉或用鲁棒聚类。

### 4. 必须事先指定 K

这是最大的局限。肘部法、轮廓系数只是辅助，最终要结合临床判断。

## 八、SPSS 和 R 具体操作

### SPSS

路径：

> Analyze → Classify → K-Means Cluster

设置：
- Variables：选要聚类的变量（HbA1c、BMI、空腹血糖、HOMA-IR、病程）
- Number of Clusters：填 K（比如 3）
- Iterate：迭代次数，默认 10
- Save：勾选 Cluster membership（把每个患者的类别存成新变量）
- Options：勾选 Initial cluster centers、ANOVA table

注意：SPSS 的 K-means 不会自动标准化，你要先在 Descriptives 里把变量标准化，把 Z 分数放进聚类。

### R

```r
# 选要聚类的变量
vars <- df[, c("HbA1c", "BMI", "FBG", "HOMA_IR", "duration")]

# 标准化
vars_scaled <- scale(vars)

# 选 K（肘部法）
set.seed(123)
wss <- numeric(10)
for (k in 1:10) {
  km <- kmeans(vars_scaled, centers = k, nstart = 25)
  wss[k] <- km$tot.withinss
}
plot(1:10, wss, type = "b", pch = 19,
     xlab = "K", ylab = "类内距离总和 (WSS)")

# 正式聚类，K=3
set.seed(123)
km <- kmeans(vars_scaled, centers = 3, nstart = 25)

# 每个患者的类别
df$cluster <- km$cluster

# 各类别大小
table(df$cluster)

# 各类别中心（原始尺度）
aggregate(vars, by = list(cluster = km$cluster), mean)
```

轮廓系数：

```r
library(cluster)
sil <- silhouette(km$cluster, dist(vars_scaled))
plot(sil)
```

## 九、论文里怎么写

**方法部分**：

> 采用 K-means 聚类分析对 2 型糖尿病患者进行亚型分型。纳入 HbA1c、BMI、空腹血糖、HOMA-IR 和病程 5 个变量，所有变量先标准化为 Z 分数。基于肘部法和轮廓系数并结合临床可解释性，确定最佳分类数为 3。聚类重复运行 25 次以避免局部最优。

**结果表格**：

| 特征 | 亚型1（n=80） | 亚型2（n=70） | 亚型3（n=50） | P 值 |
|---|---:|---:|---:|---:|
| HbA1c, % | 7.2 (0.8) | 8.5 (0.9) | 9.8 (1.1) | <0.001 |
| BMI, kg/m² | 23.1 (2.5) | 30.2 (3.1) | 26.4 (2.8) | <0.001 |
| 空腹血糖, mmol/L | 8.0 (1.2) | 9.5 (1.5) | 12.0 (2.0) | <0.001 |
| HOMA-IR | 1.5 (0.5) | 4.2 (1.0) | 2.8 (0.8) | <0.001 |
| 病程, 年 | 3 (2–5) | 5 (3–8) | 10 (7–15) | <0.001 |

**文字**：

> K-means 聚类将 200 例 2 型糖尿病患者分为 3 个亚型：亚型1（n=80，40%）为轻度代谢型，特点是 HbA1c 较低、BMI 正常、病程短；亚型2（n=70，35%）为肥胖胰岛素抵抗型，BMI 和 HOMA-IR 显著升高；亚型3（n=50，25%）为重度胰岛功能衰竭型，HbA1c 最高、病程最长。三型患者 3 年糖尿病肾病发生率分别为 5%、15% 和 30%（P<0.001）。

## 十、最常见的坑

1. **不标准化就聚类。**
   数值大的变量（比如 BMI、费用）会主导距离，数值小的变量（比如评分）被忽略。先 scale。

2. **K 随便选一个。**
   K=2、K=3、K=4 都跑一遍，看肘部图、轮廓系数，再回到临床解释。不要拍脑袋。

3. **分完类就不管了。**
   聚类只是第一步。分出来的类必须和临床结局（并发症、治疗反应、预后）挂钩才有意义。否则只是"数据里能分堆"，临床上没用。

4. **把聚类当分类。**
   K-means 是无监督学习，没有"正确答案"。你不能说"聚类准确率是 90%"——没有金标准。

5. **异常值不处理。**
   一个住 100 天的极端值会把中心拉飞。先看分布，去掉或 winsorize。

6. **只用一次随机初始值。**
   K-means 结果可能因初始值不同而变。nstart=25 或 nstart=100，跑多次选最优。

## 十一、K-means vs 其他聚类方法

| 方法 | 特点 | 医学场景 |
|---|---|---|
| K-means | 快、简单、需要指定 K | 患者分型、基因表达分群 |
| 层次聚类 | 不用指定 K、出树状图、慢 | 小样本（<200）、探索性分析 |
| DBSCAN | 自动发现任意形状的类、不怕异常值 | 影像特征聚类、异常检测 |
| 高斯混合模型（GMM） | 软聚类（每个点属于各类的概率） | 不确定患者属于哪型时 |

新手从 K-means 入门够用了。

---

## 十二、最后给你一个清单

做 K-means 聚类时：

1. 选好要聚类的变量，每个变量都要有临床意义。
2. 标准化所有变量。
3. 用肘部法 + 轮廓系数选 K，但最终听临床判断。
4. nstart 设大一点（25 或 100），避免局部最优。
5. 描述每一类的临床特征，起个好记的名字。
6. 验证：不同类别在结局上有没有差异？
7. 有条件做外部验证（另一队列重复出来）。
8. 论文里写清楚变量、标准化方法、K 的选择依据。
